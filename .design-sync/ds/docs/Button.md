# Button — кнопка

Действие. В ряду **залита только главная** кнопка, остальные белые с цветной подписью (ADR-027) —
иначе экран превращается в светофор и глаз не находит основное действие.

**Тона:** `primary` (по умолчанию, залита), `secondary`, `danger`, `warning`, `success`, `info`, `ghost`.
**Размеры:** обычный 38 px (`--control-h`), `sm` 30 px, `xs` 24 px. Ниже 36 палец промахивается на
планшете, выше 40 кнопка не помещается в строку таблицы.

Загрузка — **словом на кнопке**, не крутилкой: `disabled` плюс текст «Сохраняю…», «Выполняю…».

```tsx
<Row>
  <Button onClick={checkIn}>Заселить</Button>
  <Button tone="secondary">Переселить</Button>
  <Button tone="danger">Отменить бронь</Button>
</Row>
<Button disabled>Сохраняю…</Button>
```

Необратимое действие кнопка не выполняет сразу — сначала `ConfirmDialog` с суммой и последствием.
