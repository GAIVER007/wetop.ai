# Page — каркас экрана

Один `main` на страницу, `h1` — ровно та строка, которая называет экран. Справа — контекстные
действия. Ссылок на другие разделы здесь нет: они в навигации.

**Ширины:** `narrow`, `medium`, `wide`, `full`.

```tsx
<Page
  title="Брони"
  subtitle="9 бронирований на 20 сент., статус «Проживают»"
  actions={<Button>Новая бронь</Button>}
>
  <Panel>…</Panel>
</Page>
```

Подзаголовок — предложением о том, что за выборка на экране, а не рекламный текст (DESIGN.md §14).
