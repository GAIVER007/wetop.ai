# Stat — плитка показателя

Число смены: подпись, значение, при нужде — подсказка со сравнением. Цвет только у значения и только
когда нужно действие: `tone="alarm"` — долг, `tone="warn"` — внимание. Ровный показатель — чёрный.

**Размеры:** `size="big"` — главная плитка, `size="compact"` — в плотном ряду.

```tsx
<Stats min={180}>
  <Stat label="Загрузка" value="79,5 %" hint="+4,1 п.п. к прошлой неделе" />
  <Stat label="Начислено" value="9,66 млн ₸" testId="c-revenue" />
  <Stat label="Не собрано" value="164 000 ₸" tone="alarm" hint="7 броней" hintTone="warn" />
</Stats>
```
