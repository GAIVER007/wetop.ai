# ToastRegion — уведомления о результате

Отвечает на «сделал — и что?»: после «Заселить» карточка перерисовывается молча, уведомление
говорит «Гость заселён, R01». Правый верх под шапкой, 360 px, `aria-live="polite"`, полоса тона
слева 4 px.

Держится 4 секунды; **ошибка (`danger`) — до закрытия рукой**. Не заменяет `role="alert"` в форме:
уведомление рассказывает об итоге, форма — о том, что не так с вводом.

```tsx
<ToastRegion
  items={[
    { id: 1, text: 'Гость заселён, R01', tone: 'success' },
    { id: 2, text: 'Продлено до 19 сент.', tone: 'info' },
    { id: 3, text: 'Ячейка 6 уже занята', tone: 'danger' },
  ]}
  dismiss={dismiss}
/>
```

В приложении оболочку даёт `ToastProvider`, а вызов — хук `useToast().toast({ text, tone })`.
