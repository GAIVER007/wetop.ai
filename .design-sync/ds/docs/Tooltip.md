# Tooltip — подсказка

Замена нативному `title`, который недоступен с клавиатуры и не открывается на планшете. Открывается
наведением **и фокусом**, закрывается Escape, до 280 px.

В подсказку идёт уточнение, а не единственное слово статуса: смысл не должен держаться на том, что
видно только при наведении (DESIGN.md §1 п. 4).

```tsx
<Tooltip text="Остаток считается по счёту брони на конец выбранных суток">
  <button className="btn btn--secondary btn--sm">к оплате</button>
</Tooltip>
```

Ребёнок — один элемент, принимающий фокус: кнопка, ссылка или `span` с `tabIndex`.
