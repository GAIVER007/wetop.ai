# CLAUDE.md: только то, что касается одного Claude Code

Первая строка подключает `AGENTS.md`: общие правила для всех агентов (Claude Code, Codex, Hermes) живут там, с
порядком чтения (§20), записями о работе и решениями (§21), техническими правилами (§22) и контрольными числами
(§23). Здесь ничего общего не дублируется: правило, которое действует для всех, пишется в `AGENTS.md`.

- `.env`, `secrets/` и реальные выгрузки закрыты от чтения правилами `.claude/settings.json` (`SECURITY.md` §3). Не
  обходить через Bash или скрипты.
- `.claude/settings.local.json` в git не едет.
- Сторонние навыки дизайна стоят глобально на Mac владельца и решений проекта не знают: при расхождении прав
  `DESIGN.md` (`AGENTS.md` §22).
