## 5. Жёсткие технические правила

| Правило | Почему |
|---|---|
| Деньги — **integer minor units** (тиын). Никаких float | ADR-008. Расхождение в копейках ломает сверку |
| Stay dates — `DATE` в timezone объекта (Asia/Almaty). События — UTC `timestamptz` | AGENTS.md §13 |
| Каждое внешнее событие: external ID, received_at, статус, retry, audit trail | ADR-007. Дубль или потеря OTA-брони недопустимы |
| Channex SDK и vendor ID — только внутри `packages/integrations` | ADR-004. Домен не знает про Channex |
| Ничего не выводить из номера единицы | Нумерация в архивный источник не сплошная: 1–4 номера, 5–40 койки, 41–48 номера, 49–84 койки, 85–88 номера |
| Integration code — только по документации из `/docs` | AGENTS.md §5. Нет документации → STOP → вопрос |
| Red before green | AGENTS.md §6. Тест, который не был красным, не доказательство |
| В тестах только вымышленные гости | ADR-010. Реальные ФИО, паспорта, телефоны запрещены |
| Секреты только через env / secret storage | `SECURITY.md`. `.env` в gitignore |
| Задача не закрывается словом "done" | Нужен тест, скриншот, отчёт сверки или ответ из sandbox |
| `.env`, `secrets/`, реальные выгрузки закрыты от чтения агентом (`.claude/settings.json`) | `SECURITY.md` §3. Не обходить через Bash или скрипты. Значения ключей вписывает только владелец |
| Коммит — только своих файлов, явным списком. `git add -A` и `git commit -a` запрещены | В одном дереве параллельно работают другие сессии: их правки уезжают в чужой коммит, история врёт |

Историю не переписывали: ветка общая, `rebase` оборвал бы работу той сессии |
| Перед большой правкой — коммит текущего состояния. Испорченный файл возвращать из истории (`git restore --source=<коммит> -- <файл>`), не переписывать по памяти | Откат возвращает только то, что было закоммичено |
| Незавершённое слияние или rebase, маркеры `<<<<<<<` / `>>>>>>>` в `CLAUDE.md` или `AGENTS.md` — разобрать до любой другой работы | Файл правил грузится как инструкция, обе версии станут правилом. Незавершённое слияние отклоняет каждое следующее, а в скрипте или хуке ошибка теряется |

| Тесты — только через `npm run test:record -- <набор>`; до прогона — `npm run test:status`. Лог и строку журнала коммитить вместе с правкой | Журнал с логами едет в репозиторий: доказанное на том же коде не гоняется повторно, упавшее разбирается по логу (`TESTING.md`) |
