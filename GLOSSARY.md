# GLOSSARY

| Термин | Значение |
|---|---|
| **Property** | Объект размещения. |
| **Accommodation Type** | Продаваемая категория размещения. |
| **Physical Room** | Физическая комната. |
| **Bed** | Физическое койко-место. |
| **Inventory Unit** | Минимальная физическая единица, куда можно назначить гостя (ROOM или BED). |
| **Reservation** | Коммерческая бронь. |
| **Reservation Item** | Одна продаваемая позиция внутри брони. |
| **Allocation** | Назначение фактической комнаты/койки. |
| **ARI** | Availability, Rates, Inventory / Restrictions. |
| **CTA** | Closed to Arrival — запрет заезда в эту дату. |
| **CTD** | Closed to Departure — запрет выезда в эту дату. |
| **Stop Sell** | Запрет продажи. |
| **Min Stay / Max Stay** | Минимальный / максимальный срок проживания. |
| **Folio** | Финансовый счёт проживания. |
| **Charge** | Начисление. |
| **Payment** | Оплата. |
| **Refund** | Возврат. |
| **No-show** | Гость не приехал. |
| **In-house** | Гость сейчас проживает. |
| **Walk-in** | Заселение без предварительной брони. |
| **Room move** | Переселение. |
| **Early check-in** | Ранний заезд. |
| **Late checkout** | Поздний выезд. |
| **OTA** | Online Travel Agency. |
| **Channel Manager** | Инфраструктура синхронизации PMS и OTA. |
| **Channex** | Конкретный channel manager, первый provider MVP. |
| **Exely** | Действующая PMS объекта, с которой мигрируем. |
| **eQonaq** | Государственная система РК: уведомление о прибытии иностранцев. |
| **Smart Bridge** | Канал интеграции с eQonaq. |
| **Fiscal receipt** | Фискальный чек онлайн-ККМ. |
| **Source of Truth** | Система, данные которой считаются первичными. Для нас — PostgreSQL PMS. |
| **Reconciliation** | Сверка двух источников. |
| **Cutover** | Момент переключения со старой PMS на новую. |
| **Rollback** | Заранее описанная процедура возврата на старую систему. |
| **Idempotency** | Свойство: повторная обработка того же события не создаёт дубль. |
| **Minor units** | Минорные единицы валюты (тиын). Формат хранения денег. |
| **Gate** | Контрольная точка проекта; без её прохождения следующий этап не начинается. |
| **Slice** | Вертикальный срез функциональности, доводимый до доказуемого результата. |
| **Parallel day** | День двойного ввода: Exely + новая PMS одновременно. |
| **Единица продажи** | То, что продаётся отдельно. На объекте их 88: 16 номеров + 72 койки. Не равно числу комнат и не равно числу мест (92). |
| **Room stay / проживание** | Одна позиция внутри брони в терминах Exely. Бронь на 2 койки = 2 проживания и (в Exely) 2 счёта. У нас — `ReservationItem`. |
| **ADR (метрика)** | Average Daily Rate, средняя цена за ночь. Не путать с ADR-решением в `DECISIONS.md`. |
| **Единице-сутки** | Единица × сутки. База расчёта загрузки: 88 × 31 = 2728 за август. |
| **Тариф на канал** | Способ ценообразования на объекте: у каждого канала свой тарифный план вместо наценки. |
