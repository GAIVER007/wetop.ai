# Справочник ошибок платформы

> 🔴 Это **данные, а не код**. Файл правит владелец платформы, выкатка
> для этого не нужна: бот перечитывает его сам, как только меняется файл.
>
> 🔴 Здесь не должно быть ни адресов серверов, ни ключей, ни персональных
> данных пользователей. Файл целиком уходит в базу знаний и в ответы бота.
>
> Ниже — образец из нескольких записей. Остальное добавляет владелец
> по разбору обращений: пришло третье одинаковое обращение — появилась
> запись.

### Как заполнять

Одна ситуация — один заголовок второго уровня, дальше шесть полей
ровно в этом виде:

```
## Короткое имя ситуации
- **Код:** (пусто, у платформы кодов пока нет)
- **Раздел:** Брони
- **Что видит человек:** что показала платформа, точный текст — в кавычках «ёлочках»
- **Причина:** почему так вышло
- **Что делать:** что сделать человеку
- **Состояние:** ожидаемое поведение
```

**Код** необязателен: у платформы кодов ошибок нет, API отдаёт только
тексты по-русски. Поле оставлено на будущее — заведёт коды, поиск станет
точным. Пока ищем по тексту, поэтому **точный текст платформы берите
в кавычки-ёлочки**: по нему и находится запись.

**Состояние** — одно из четырёх: `ожидаемое поведение` · `известный дефект`
· `чинится` · `исправлено`.

Запись без «Что видит человек», «Причина» или «Что делать» пропускается:
отвечать по ней нечем.

Текст в фигурных скобках — заготовка. 🔴 Поле с незаменённой заготовкой
считается ПУСТЫМ, и запись целиком пропускается: иначе бот ответил бы
человеку «причина: {заполните после разбора}», то есть выдумкой в обёртке.
Не знаете причину — напишите так и словами: «причина ещё выясняется».

---

## Не сохраняется бронь: «adults — целое ≥ 1»

- **Код:** (пусто, у платформы кодов пока нет)
- **Раздел:** Брони
- **Что видит человек:** сообщение «adults — целое ≥ 1» при сохранении брони
- **Причина:** в поле «Гостей» пусто или ноль
- **Что делать:** укажите хотя бы одного взрослого и сохраните снова
- **Состояние:** ожидаемое поведение

## Не сохраняется тариф: «categoryCodes: непустой список кодов категорий»

- **Код:** (пусто, у платформы кодов пока нет)
- **Раздел:** Тарифы
- **Что видит человек:** сообщение «categoryCodes: непустой список кодов категорий» при сохранении
- **Причина:** не выбрана ни одна категория размещения
- **Что делать:** отметьте хотя бы одну категорию и сохраните снова
- **Состояние:** ожидаемое поведение

## Раздел не открывается: бесконечная загрузка

- **Код:** (пусто, у платформы кодов пока нет)
- **Раздел:** любой раздел
- **Что видит человек:** страница раздела не открывается, значок загрузки крутится и не пропадает
- **Причина:** причина ещё выясняется, это известный дефект
- **Что делать:** обновите страницу; если повторяется — напишите сюда, специалист посмотрит
- **Состояние:** известный дефект

## Изменения в форме пропадают после сохранения

- **Код:** (пусто, у платформы кодов пока нет)
- **Раздел:** любой раздел
- **Что видит человек:** форма закрылась без сообщения, но значения вернулись к прежним
- **Причина:** причина ещё выясняется, дефект уже в работе
- **Что делать:** повторите правку по одному полю; если повторяется — напишите сюда
- **Состояние:** чинится
