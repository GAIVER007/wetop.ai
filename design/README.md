## Как снять скриншоты текущих экранов

Без `.env`, без базы и без Channex — только синтетический API из `scripts/preview/fixture-api.ts`
с флагом `showcase` (крайние случаи: статусы `TENTATIVE` / `CANCELLED` / `NO_SHOW`, шесть каналов, стойка и
сайт, проживание без ячейки и ночь сверх мест, блокировки с причиной, три статуса уборки, длинные имена
латиницей, кириллицей и с казахскими буквами, неделя 88 из 88, входящая ревизия с ошибкой):

```sh
npm run test:record -- e2e --config tests/ui/playwright.config.ts tests/ui/design-reference.spec.ts --workers=1 --note "скриншоты экранов для дизайн-системы"
```

Нужны Node 24 и Google Chrome; в окружении с Playwright Chromium — `UI_BROWSER_CHANNEL=chromium`.
Файлы: `reference/current/<экран>-<light|dark>.png`. Все имена гостей — вымышленные (ADR-010).

## Чего здесь не бывает

- Данных гостей объекта, выгрузок Exely, ключей и `.env`.
- Правок «по вкусу»: значения токенов меняются только по правилу документа или по замечанию смены (ADR-027, ADR-046).
