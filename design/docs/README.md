# Спецификация формата токенов — W3C DTCG 2025.10

План (шаг 1, п. 3) требует держать здесь сохранённую копию спецификации Design Tokens Community Group,
редакция 2025.10: формат файла, цвет, темы — с designtokens.org/tr/2025.10.

**16.09.2026:** агенту доступ к `designtokens.org` закрыт сетевой политикой окружения, скачать не удалось.
`design/tokens.json` записан по известной агенту редакции формата 2025.10:

- файл — дерево групп, лист — объект с `$value` и `$type`, необязательные `$description`, `$extensions`,
  `$deprecated`;
- ссылки на другие токены — строкой в фигурных скобках: `"{color.blue.600}"`;
- цвет — объект `{ "colorSpace": "srgb", "components": [r, g, b], "alpha": 1, "hex": "#rrggbb" }`;
- размер — объект `{ "value": 16, "unit": "px" }`; длительность — `{ "value": 180, "unit": "ms" }`;
- `fontFamily` — строка или массив строк; `fontWeight` — число; `number` — число; `shadow` — объект или
  массив объектов `{ color, offsetX, offsetY, blur, spread }`; `cubicBezier` — четыре числа.

**20.09.2026 — часть спецификации получена и сверена.** Текст редакции 2025.10 с
designtokens.org/tr/2025.10/format прочитан через разрешённый агенту путь; сам файл спецификации сюда
по-прежнему не скачивается (сетевая политика), поэтому ниже выписаны нормативные правила, которые
проверяемы у нас, с итогом сверки `design/tokens.json` на эту дату:

| Правило спецификации | Наш файл |
|---|---|
| Имя токена и группы не начинается с `$` и не содержит `{`, `}`, `.` | 258 токенов, 36 групп — нарушений нет; закреплено тестом |
| `$type` задан явно или унаследован от группы; угадывать тип по значению инструмент не вправе | нарушений нет; закреплено тестом |
| Ссылка `{group.token}` указывает на существующий токен, циклов нет | 147 ссылок, все разрешаются; цикл и битая ссылка уже валили тест |
| Допустимые свойства токена: `$value`, `$type`, `$description`, `$extensions`, `$deprecated` | используются первые четыре |
| Вендорские данные — в `$extensions` с обратной доменной записью | темы лежат в `kz.wetop.themes` |
| Рекомендованное расширение файла `.tokens` / `.tokens.json`, MIME `application/design-tokens+json` | у нас `tokens.json`; переименование ничего не даёт, генератор читает по пути — оставлено как есть |
| В 2025.10 добавлен `$ref` по JSON Pointer для ссылки на часть значения | не используем: наши ссылки целиком на значение |

**Владельцу:** положить сюда `dtcg-2025.10-format.html` (или PDF) с designtokens.org/tr/2025.10/format и
`dtcg-2025.10-color.html` с …/color. После этого отдельный проход (шаг 3) сверяет `tokens.json` с текстом
спецификации, а не с памятью модели. До этого тест формата в `scripts/design/build-tokens.test.ts` проверяет
только внутреннюю согласованность файла: у каждого листа есть `$value` и `$type`, все ссылки разрешаются,
темы объявляют одни и те же имена.
