# 01 · Экран стойки — раскладка (заход 1 из 3)

Используй опубликованную дизайн-систему «WETOP — стойка»: токены `design/tokens.json`, правила `DESIGN.md`,
компоненты со страницы `/design-system` по именам. Новых цветов, радиусов, теней и компонентов не вводить.

Сделай макет рабочего экрана администратора хостела Luxx Aparts (Алматы, 88 мест: 16 номеров и 72 койки в
мужском и женском общих номерах) на 1440×1000, светлая тема. Это экран, на котором смена живёт весь день.

**Два варианта раскладки — В1, нужно выбрать:**

- **В1-а «два экрана»** (как сейчас в WETOP): «Обзор дня» (плитки сводки дня, ближайшие заезды и выезды,
  «Требуют внимания», быстрые действия) и отдельная «Шахматка». Покажи оба экрана рядом.
- **В1-б «сводка над шахматкой»** (как в документе ментора): один экран — компактная сводка дня одной строкой
  плиток над шахматкой, шахматка занимает остальное. Покажи один экран.

**Что должно быть на шахматке (компоненты по именам из DESIGN.md §8):** боковое меню (232 px, сворачивается),
заголовок страницы «Шахматка» с подзаголовком периода, переключатель вида «Неделя / 14 дней / Месяц», выбор
даты с «Сегодня» и стрелками, поиск, выпадающий фильтр по статусу и источнику/каналу, строка «Без ячейки»
(конфликт: проживание без койки), заголовки дат (сегодня выделен, выходные нейтральные), строки категорий
(свёрнутые показывают свободные места по ночам), строки номеров и коек с кодом `R01` / `M03` и статусом уборки
словом, клетки броней с заливкой статуса **и словом статуса**, индикатор синхронизации Channex в углу меню.

**Данные для примера:** вид «Неделя» 14–20 сентября 2026; сегодня 14.09; в мужском общем номере занято
36 из 36 на 14.09 и одно проживание «Без ячейки»; брони: Сериков Арман Болатұлы (R01, ждём, стойка),
Әбдірахманова Гүлнұр Қайратқызы (R06, не подтверждена, Booking.com), Constantinopolous-Wentworth Alexandria
(M03, ждём, Expedia), Ким Дана (F02, заселён, Ostrovok), Smith John (R07, незаезд, Agoda — на шахматке не
показывается), блокировка R09 «ремонт: кондиционер» 14–16.09.

**Ограничения:** текст не мельче 12 px, цели нажатия не меньше 24 px, шахматка без горизонтальной прокрутки на
1280 px, отступы только 4/8/16/24/32/40/48/64, тень только у слоя над страницей, без капса, без градиентов,
без стрелок в конце ссылок, без «A · B · C». Цвет статуса всегда со словом.

Приложение (только для этого промпта, не для системы): скриншот шахматки старой системы Exely с закрашенными
фамилиями — так работает смена сейчас; повторять не нужно, важно не потерять привычные смыслы: «Без номера»,
свёрнутые категории, период.

В конце выполни разбор по `06-review.md` и перечисли проблемы списком.
