# 08 · Разбор макета перед передачей в Claude Code

Прогоняется по каждому макету заходов 1–7 до «Export → Handoff to Claude Code». Результат — список
проблем по пунктам; макет с открытыми пунктами в код не идёт.

## Промпт

Проверь этот макет по DESIGN.md проекта WETOP и ответь списком «пункт → что не так → где на макете →
как по DESIGN.md». Не хвали, не пересказывай макет.

1. **Доступность и контраст.** Текст на фоне ≥ 4,5:1, границы полей и кольцо фокуса ≥ 3:1 в обеих темах
   (§10); у значков без подписи есть имя; порядок фокуса совпадает с порядком чтения.
2. **Иерархия.** Один заголовок 28 px; одна залитая кнопка на экран; число на плитке крупнее подписи;
   ничего не мельче 12 px (§6).
3. **Компоненты не из системы.** Каждый элемент назван компонентом из §8; новых нет; если есть — почему
   нельзя было обойтись существующим.
4. **Смысл только цветом.** У каждого статуса глиф или слово (§9); у каналов — название; у уборки — слово.
5. **Важное только под наведением.** Сумма, статус, канал, причина блокировки видны без курсора; в
   подсказке — уточнение, не единственный носитель (§1 п. 4).
6. **Цели нажатия.** ≥ 24×24 на компьютере, 44 на телефоне (§11); кнопка «⋯» на плашке, клетки шахматки,
   крестики уведомлений.
7. **Пустой вид, загрузка, ошибка, большой объём.** Для каждого экрана есть все четыре (§8, §14, заход 3);
   тексты по правилу «что пусто и что сделать».
8. **Отступы и радиусы.** Только 4/8/16/24/32/40/48/64; радиус по уровню; тень только у слоя над
   страницей (§3, §5).
9. **Тексты и форматы.** 20.09.2026, 12 500 ₸, прочерк, время объекта, глаголы на кнопках, без капса и
   « · » как разделителя смыслов (§14).
10. **Клавиатура.** Всё, что мышью, есть в меню или кнопкой; Escape закрывает и возвращает фокус (§12).
11. **ИИ-слоп** (§15): градиенты, свечение, карточки с тенью ради тени, значки в цветных квадратах,
    английские надписи, «01/02» не для шагов.
12. **Данные.** Имена вымышленные, цифры правдоподобные для объекта (88 ячеек, цены 4 500–24 000 ₸).

В конце — «готов к передаче: да / нет» и три главных правки.
