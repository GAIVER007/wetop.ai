# Промпты макетов для Claude Design (шаг 6 плана дизайн-системы)

Промпты документа ментора, переписанные под наши имена, виды и данные. Владелец прогоняет их в Claude Design в
проекте «WETOP — стойка» (шаг 5), выбирает вариант и пишет в чат решение с причиной; четыре действия показывает
управляющему. Порядок — как пронумерованы файлы. Каждый промпт заканчивается разбором из `06-review.md`.

| Файл | Что | Заходов |
|---|---|---|
| `01-desk-layout.md` | Экран стойки: раскладка | 1 |
| `02-desk-statuses-actions.md` | Экран стойки: статусы и действия | 1 |
| `03-desk-states-volumes.md` | Экран стойки: состояния и объёмы | 1 |
| `04-channex-screens.md` | Три рабочих экрана для показа Channex: цены и ограничения, журнал интеграции, приём брони | 3 |
| `05-manager-actions.md` | Четыре действия управляющего | 4 |
| `06-review.md` | Разбор макетов перед передачей — список проблем по пунктам | после каждого |

## Что вставить в каждый промпт

- Первой строкой — «Используй опубликованную дизайн-систему WETOP — стойка: токены `design/tokens.json`, правила
  `DESIGN.md`, компоненты со страницы `/design-system` по именам». Новых цветов, радиусов и компонентов не вводить.
- Данные — только вымышленные: имена из `design/reference/current/*.png` (Әбдірахманова Гүлнұр Қайратқызы,
  Constantinopolous-Wentworth Alexandria, Сериков Арман Болатұлы, Ким Дана, Smith John), номера броней вида
  `20260913-SHOWTN`, ячейки `R01…R16`, `M01…M36`, `F01…F36`, даты сентября 2026.
- Скриншоты Exely с закрашенными фамилиями (`design/reference/exely/`) прикладываются владельцем **только к
  промптам 01–03 как «так сейчас у стойки в старой системе, повторять не надо»**; в опубликованную систему они
  не попадают (Д7).

## Отличия от промптов документа ментора

- Виды шахматки «Неделя / 14 дней / Месяц» (ADR-039), а не «День / Месяц».
- «Без ячейки» вместо «Без номера».
- Фильтры — только статус и источник/канал: способа гарантии и тегов в системе нет (Q-131).
- Блок задач — «Требуют внимания», считается из данных дня; задач со сроками нет (Q-132).
- В документе главный экран — сводка дня вместе с шахматкой; у нас это два экрана, «Обзор дня» и «Шахматка».
  Вариант выбирается в первом заходе (`01-desk-layout.md`, вопрос В1).
- Отдельного экрана «для сертификации» нет: Channex прямо отклоняет такой приём
  (`docs/channex/site/api-v.1-documentation/pms-certification-tests.md`, «Anti-patterns we reject»).
