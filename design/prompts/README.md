# Промпты для макетов в Claude Design (план, шаг 6)

Промпты документа ментора от 14.09.2026, переписанные под наши имена, виды и данные. Прогоняет владелец в
проекте Claude Design «WETOP — стойка» **после** загрузки дизайн-системы (шаг 5, `design/claude-design-manifest.md`).
Каждый промпт — один файл, порядок ниже. Результат каждого захода владелец записывает в чат одним
сообщением: какой вариант выбран и почему; агент переносит решение в `DESIGN.md` §18.

## Правила для всех промптов

- Компоненты и токены — только из `DESIGN.md` и страницы `/design-system`; у каждого элемента на макете —
  имя компонента из §8. Новый компонент — сначала строка в §8.
- Данные вымышленные (ADR-010): гости из `design/reference/current` (Ақбота Әбдіғаппарова, Гость Стойка,
  Constantine-Alexander Featherstonehaugh-Wentworth), номера броней вида `20260916-DSG-…`.
- Объект: 88 ячеек = 16 номеров (R01–R16) + 72 койки (M01–M36, F01–F36); категории «Двухместный
  номер», «Мужской общий номер», «Женский общий номер»; каналы Booking.com, Trip.com, Agoda, Expedia,
  Hostelworld, Ostrovok, плюс стойка и сайт.
- Виды шахматки — «Неделя / 14 дней / Месяц» (не «День / Месяц»). Строка «Без ячейки» (не «Без номера»).
  Фильтры — статус и источник/канал; способа гарантии и тегов нет (Q-136). Блок задач — «Требуют
  внимания» (Q-137).
- Скриншоты архивный источник в Claude Design не загружаются: они лежат у владельца в `design/reference/retired-source/` и
  служат только для того, чтобы владелец сам сравнил макет с тем, к чему привыкла смена.
