# ИИ-агенты WETOP

Единая точка входа для разработчика и оператора. Это карта существующих правил, не замена исполняемой защиты.

- [Безопасность](SECURITY.md): границы доверия, ключи, права и запреты.
- [Бронирование](BOOKING.md): утверждённый сценарий и границы реализации.
- [Настройка и диагностика](RUNBOOK.md): что проверить перед запуском.
- [Приёмка](ACCEPTANCE.md): необходимое доказательство работы.

## Компоненты

| Компонент | Назначение |
|---|---|
| `apps/web/src/app/ai-agents` | Каталог, создание и инструкция конкретного агента |
| `apps/web/src/app/ai-seller` | Настройки, знания, модель, каналы и проверка существующего продавца |
| `apps/api/src/ai-seller` | Права, профили, область организации/агента, синхронизация |
| `apps/api/src/web-booking/bot-quote.controller.ts` | Узкое чтение наличия и котировок |
| `apps/ai-seller/src/ai` | Ответы модели, инструменты, защита и контекст |
| `apps/ai-seller/src/channels` | Приём и доставка сообщений, дедупликация |
