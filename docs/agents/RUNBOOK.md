# Настройка и диагностика

1. Сверить SHA PMS и версию образа бота; healthy означает только доступность процесса.
2. Проверить применённые миграции обеих баз. Для agent scope использовать [runbook SA2.5](../ops/sa25-agent-scope.md). Не запускать новый образ бота вслепую: entrypoint может применить миграцию.
3. Проверить расширение, роли, связь агента с объектом и сохранение его инструкции после перезагрузки.
4. Проверить адрес сервиса, наличие ключа модели и разрешённый бюджет без вывода значений. Генерация инструкции не должна перезаписывать текст без выбора владельца.
5. Выполнить тестовый диалог вымышленного гостя. Проверить краткость, наличие и цену, отказ при недоступном PMS.
6. Сайт: разрешённые домены и установка виджета — разные проверки. WhatsApp: наличие credentials не доказывает доставку; нужен приём подписанного события и ответ в тестовом канале.
7. Запуск записи броней — только после критериев BOOKING/ACCEPTANCE. Не отправлять тесты реальным гостям.
8. Перед deploy прочитать `apps/ai-seller/vykatka.md`, сохранить возможность отката, проверить образ, время старта, health и пользовательский сценарий.
