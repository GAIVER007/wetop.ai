## yauzl

- Версия: `3.4.0`.
- Источник: npm registry, зафиксирован в `package-lock.json`.
- Репозиторий и описание безопасного последовательного чтения ZIP: `https://github.com/thejoshwolfe/yauzl`.
- Лицензия: MIT.
- Типы: `@types/yauzl@2.10.3`, лицензия MIT.

`yauzl` выполняет серверную проверку ZIP-контейнера до передачи данных SheetJS. Чтение использует `lazyEntries` и ограничивает архив 100 записями, 4 МиБ на запись и 8 МиБ суммарно по заявленному и фактически прочитанному объёму. Зашифрованные записи и файлы, которые не являются ZIP/XLSX, отклоняются.

## Ограничения обработки

- Загружаемый файл ограничен 100 КБ, импорт содержит не больше 500 строк данных.
- SheetJS читает первый лист с `sheetRows: 502`, `dense: true`, `cellFormula: true`, `cellHTML: false`, `bookVBA: false`.
- Полный диапазон листа проверяется отдельно, чтобы усечение `sheetRows` не скрыло превышение лимита.
- Ячейки с формулами отклоняются, формулы не вычисляются.
- Парсер подключается только в серверном модуле и не попадает в клиентский bundle.
- Выгрузка создаёт настоящий XLSX. Телефоны записываются текстом, поэтому ведущий `+` сохраняется.
