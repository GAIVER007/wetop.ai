# Окна по центру, журнал салона на весь экран, единый доступ, запись на несколько услуг

Дата: 20.10.2026. Владелец: «окна справа не нравятся, открывать по центру и так везде»; «журнал: не нравится список сотрудников слева, сделай на весь экран»; «логика доступа везде одна, не важно ресторан это или гостиница».

## Решения

1. Окна, которые выезжали справа (`Overlay drawer`), открываются по центру как обычный диалог во всех разделах. Правка в одном месте (`premium.css`, `.ui-drawer`), поэтому действует на все экраны сразу. Свойство `drawer` оставлено: оно задаёт ширину окна, а не место.
2. Журнал салона: левый столбец со списком специалистов убран, сетка на всю ширину. Специалист в шапке своей колонки с числом записей за день, нажатие показывает только его. Свободная клетка при наведении показывает время записи, на сегодняшнем дне линия «сейчас».
3. Блок «Доступ в WETOP» один во всех вертикалях: форма нового сотрудника салона и ресторана и приглашение из «Сотрудников и доступа» гостиницы. Без почты войти нельзя, поэтому пока почта не указана, выбран «Без входа»; с почтой у специалиста по умолчанию «Личный кабинет». Ручной выбор не сбрасывается.
4. Онлайн-запись салона принимает несколько услуг подряд к одному мастеру (до 5): `serviceIds`, строки визита по порядку, цена суммой. «Любой мастер» = тот, кто оказывает все выбранные услуги. Одна услуга работает как прежде, отпечаток повтора не изменился.
5. Настройка салона после обязательных шагов показывает «Дальше»: часы работы, сайт с онлайн-записью, вход для мастеров, оплата труда.
