# Ответ владельца 20.10.2026 «Да окей продолжай»: выкладка «Персонала» и валюты, следующие срезы

Дата: 20.10.2026. Ветка `hermes/personnel-20261020`. Основание: ответ владельца «Да окей продолжай» на отчёт с тремя
решениями (рекомендованные варианты приняты все, как принято у владельца: короткое «да» на список = да на рекомендации).

**Проблема.** После PR #736 (валюта в подписях) и PR #737 (назначение в «Персонале», миграция 138) оставались три
развилки: порядок выкладки, назначение у ресторана, валюта в аналитике гостиницы.

**Варианты и решение.**
1. Выкладка: сначала PR #736 без миграций, затем PR #737; миграцию 138 агент применяет на проде после резервной копии
   (`/root/wetop-mig.sh`), затем `wetop-auto-deploy --migrations-applied`. Принято.
2. Назначение «специалист / другой сотрудник / оба» у ресторана (экран `/employees` для FOOD_SERVICE, API
   `/food-service/employees`): сделать следующим срезом на той же колонке `employees.personnel_kind`, без новой миграции.
   Принято. Правило то же (DATA_MODEL.md, решение 18.10.2026): назначение явное, старые записи «не назначено».
3. Валюта в аналитике гостиницы и в сообщениях об оплате брони: API отдаёт валюту объекта, экран подписывает ею.
   Принято. Это подпись и формат, денежные расчёты не меняются.

**Причина.** Владелец просил одну систему для всех направлений и суммы в выбранной валюте объекта.

**Последствия.** Срезы 2 и 3 идут отдельными PR после выкладки #737. Модель данных не меняется.
