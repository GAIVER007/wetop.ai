# Доступ при добавлении сотрудника: 4 уровня

**Дата:** 20.10.2026. **Решение владельца** (ответы на вопросы агента, 20.10.2026).

**Проблема.** Доступ был разбросан: сотрудника добавляют в «Персонале» без входа; вход даёт отдельное приглашение в
«Сотрудники и доступ» с ролью; в салоне есть ещё «Должности» с галочками; аккаунт потом вручную привязывают к
сотруднику в его карточке. Владельцу непонятно, кто что видит.

**Решение.** В форме «Новый сотрудник» всех трёх направлений один блок «Доступ в WETOP» с четырьмя уровнями и списком
«что увидит»:

1. **Без входа:** человек есть в персонале, расписании и зарплате, в WETOP не входит.
2. **Личный кабинет:** только своё (свои записи или заказы, свой график, своя зарплата, свои отзывы). Новая роль
   членства `EMPLOYEE`, права только `self`.
3. **Администратор:** клиенты, записи и брони, касса, отчёты на просмотр (роль `STAFF`, как было).
4. **Управляющий:** всё, кроме владельческого (роль `MANAGER`). Выдаёт только владелец.

- По умолчанию: специалист (мастер, официант) и «оба» получают «Личный кабинет», другой сотрудник «Без входа».
- Где работает: по умолчанию только текущий филиал (назначение `membership_scopes`). Переключатель «Все филиалы»
  видят только владелец и управляющий без ограничения по филиалам.
- Вход: для уровней 2–4 нужна почта; уходит приглашение, после принятия аккаунт сам привязывается к этому сотруднику
  (`invites.employee_id` → `employees.user_id`), ручной привязки нет.
- Кто кому что выдаёт: владелец все уровни; управляющий «Без входа», «Личный кабинет», «Администратор».

**Схема.** Миграция 139: значение `EMPLOYEE` в `MembershipRole`, столбец `invites.employee_id` (uuid, NULL, FK на
`employees`). Откат: только пока нет членов и приглашений с `EMPLOYEE`.

**Где видно.**

- Салон и ресторан: блок в форме «Новый специалист» / «Новый сотрудник» под «Кто это». Уровень следует за назначением,
  пока владелец не выбрал сам. Сотрудник создаётся, потом уходит приглашение; если приглашение не ушло, форма говорит
  об этом словами, сотрудник остаётся.
- Гостиница: в приглашении «Сотрудники и доступ» под должностью строка «Увидит: …». «Личный кабинет» выдаётся только из
  формы сотрудника (вход привязывается к карточке).
- Человек с «Личным кабинетом» после входа попадает в «Мою работу»; рабочие разделы ему закрыты правами роли.

**Не меняется.** «Должности» салона с галочками остаются для тонкой настройки (если должность назначена, права берутся
из неё). Существующие люди и приглашения не трогаются.
