# Единый вид экранов персонала для всех направлений (вариант A «Рабочая таблица»)

Дата: 20.10.2026. Ветка `hermes/unified-staff-20261020`.

**Проблема.** Владелец 20.10.2026: «че везде все по разному выглядит, ресторан так, гостиницы по другому… сделай 3
варианта, выберем один, и он будет как единый дизайн интерфейса для всех». Салон показывал персонал карточками, ресторан
таблицей с поиском и выбором смены, гостиница таблицей команды со своей шапкой.

**Варианты** (эскизы `~/wetop-sketches/unified-ui/`): A рабочая таблица (плитки сводки, вкладки, поиск, период, одна
строка на человека), B список и карточка рядом, C карточки. Рекомендация агента: A.

**Решение владельца (20.10.2026):** «Да давай ресторан. Сделай так для всех» = вариант A для всех направлений.

**Что одинаково.** Один общий компонент `StaffBoard`, без плиток сводки сверху (см. ниже); карточка с панелью: вкладки по назначению слева, поиск, «День / Неделя / Месяц» справа;
таблица, каждый человек в одну строку (имя и должность, назначение, смена, статус, нагрузка сегодня, «Принёс», рейтинг,
действия кнопками в ряд); под таблицей «деньги без сотрудника» и «Показано N из M». Отличаются только слова
(`Специалисты` или `Сотрудники`, записи, заказы или брони) и колонки, которых у направления нет (у гостиницы нет смены
и рейтинга: колонка не показывается, а не заполняется прочерками).

**Последствия.** Салон теряет карточки-плитки на «Специалистах»: всё то же есть строкой (назначение, смена, записи
сегодня, «Принёс», «Открыть» ведёт на страницу `/employees/<id>/profile`). Гостиница в «Персонал → Сотрудники»
получает ту же раскладку, управление доступом (должность, область, приостановить, отключить) остаётся в строке.
Следом в том же стиле переводятся другие списки (клиенты, услуги, брони) отдельными срезами.

## Плитки сводки убраны (владелец 20.10.2026)

Плитки над таблицей («В персонале», «На смене сейчас», «Принесли за период», «Не назначено») владелец отклонил:
«не нравятся эти поля… не обязательно видеть, сколько сейчас на смене». Предложенная замена (принесли с
сравнением к прошлому периоду, лучший, в среднем, возвраты) тоже отклонена: «нет, фигня, убери вообще». Экран
персонала во всех направлениях начинается сразу с карточки: поиск и период, вкладки, таблица. Число людей видно на
вкладках, «Не назначено» на своей вкладке, деньги в колонке «Принёс» и строке «без сотрудника» под таблицей.
Плитки сюда не возвращать без нового решения владельца.
