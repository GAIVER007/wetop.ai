# 2026-10-21. Главная руководителя на одном экране компьютера

## Проблема
Владелец 21.10.2026 (скриншоты app.wetop.ai/today, ноутбук): «не нравится что так выглядит, не хочу листать верх вниз,
чётко на одном экране с компа, компактно под все вертикали». Шапка занимала три строки («Обзор бизнеса», заголовок,
время, отдельная строка периода), «Куда уходят деньги» стояло отдельной полосой внизу, до него нужно было листать.

## Решение
Эскиз `~/sketches/home` принят ответом «Да окей четко». Для всех трёх направлений (общая Главная, `unified-owner.tsx`):
- шапка одной строкой: «Главная», время обновления, период «Сегодня / 7 дней / Месяц», даты словами, кнопки справа;
- итоги одной полосой (`owner-totals`): выручка, поступления, оплаченные расходы, загрузка; без плиток, пояснения
  расчёта во всплывающей подсказке;
- ниже два столбца: «Динамика по дням» слева (график 200 px вместо 230), справа (`owner-side`) «Требуют решения»
  короткими строками с точкой состояния и ссылкой и «Куда уходят деньги» списком статей с долей;
- отступы на шкале токенов, сжаты до `--space-4` / `--space-2`.

Проверено на стенде branches-ui с `APP_UNIFIED_OWNER_HOME=true`: 1280x720 и 1440x900, салон, отель, ресторан,
пусто и с данными: высота страницы равна высоте окна, горизонтальной прокрутки нет.

## Не входит
Пункты «Требуют решения» остаются прежними двумя (загрузка, учёт расходов). Новые сигналы (неоплаченные записи,
окна у мастеров, остатки склада) требуют расчётов в API и делаются отдельно по согласию владельца.
