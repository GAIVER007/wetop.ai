# 2026-10-21. Первичная настройка салона: вариант B (путь и превью записи)

## Проблема
Обход живого сайта 21.10.2026: экран `/register/setup` салона был длинным списком одинаковых карточек. Не видно, какой шаг
делать сейчас и зачем он нужен; приветствие маленькой карточкой на пустом фоне, служебные фразы («после серверной
проверки»), блок «Дальше» терялся внизу.

## Варианты
Эскизы показаны владельцу (`~/sketches/setup/`):
- A. По шагам: одна карточка текущего шага и полоса из пяти кружков.
- B. Путь и превью: слева пять шагов, справа превью онлайн-записи из данных салона.
- C. Всё на одной странице: услуги чипами, мастера по имени, таблица «кто что делает», часы одной кнопкой.

## Решение
Владелец: «Давай сделай лучший удобнейший вариант», агент выбрал B (рекомендация из сравнения).
- Слева путь: Основные сведения → Услуги → Мастера → Назначить услуги → Рабочее время. Выполненные с галочкой,
  итогом и «Изменить», текущий подсвечен с одной главной кнопкой, остальные приглушены. «Основные сведения»
  заполняются прямо в строке пути.
- Справа «Так клиент увидит онлайн-запись»: услуги филиала с ценой филиала (до 4), мастера филиала (без «других
  сотрудников»), кнопка «Записаться» включается, когда салон готов. Данные из `beautyApi.services/employees`, без новых
  API; если загрузка не удалась или нет прав, превью пустое и шаги работают.
- Сверху прогресс «Выполнено N из 4 обязательных шагов» с полосой; блок «Дальше» списком с иконками.
- На телефоне превью под шагами, кнопка текущего шага во всю ширину.

## Причина
Превью объясняет, зачем каждый шаг (клиент не запишется без услуги, мастера и часов), и меняется сразу по мере
шагов. Шаги и проверки готовности сервера остались прежними: меняется только экран, без нового API и миграций.

## Последствия
- Логика пути и превью: `apps/web/src/app/register/setup/setup-path.ts` (+ тест). Экран `beauty-checklist.tsx`, стили
  `setup.css` (блок «вариант B»).
- Тексты кнопок и заголовков, на которые опираются тесты, сохранены («Настроить салон», «Сохранить и продолжить»,
  «Выполнено N из 4 обязательных шагов», «Завершить настройку», «Перейти к работе», «Открыть календарь» после готовности).
