# Единые поля и формы во всех вертикалях (21.10.2026)

Поручение владельца 21.10.2026: «почему везде разные поля… всё должно быть единым под все системы». Инвентарь по main 6cb5350f6.

Срез 1 (этот PR): сторож `raw-form-control` и `control-size-literal` в `tests/unit/design-slop-rules.ts`, снимок долга в `design-slop.baseline.json`. Вид не меняется.

## Что не так сейчас
1. Основа одна: `Input/Select/Textarea/Field` (класс `.inp`, высота `--control-h` 38px, на телефоне 44px и 17px).
   Её используют 609 полей, но 49 полей сделаны руками (`<input>/<select>/<textarea>`), а 136 подписей — голый `<label>`.
   Больше всего: branches (9 полей, 13 подписей), create/конструктор ассистента (12), login (4), employee-portal, chessboard, marketing/site.
2. 126 CSS-правил в разделах перекрашивают поля по-своему, 38 из них цифрами: высоты 28/34/36/40/44/46px,
   шрифт 13/14px, свои отступы и скругления (reservations 31 правило, общий слой 27, branches 17, inventory, bar, channels, finance, chessboard).
   Отсюда разная высота и шрифт полей в отеле, салоне, ресторане.
3. Одинаковые по смыслу поля называются по-разному: «Имя / Имя * / Имя клиента / Имя гостя / Имя и фамилия»,
   «Комментарий / Заметка / Примечание», «Длительность, минут / Длительность брони, мин», «Цена / Стоимость».
   Звёздочка «*» в тексте подписи вместо `required` у Field.
4. Сторож дизайна (design-slop) не ловит ни «поле руками», ни «высоту поля цифрой», поэтому разнобой растёт с каждым PR.

## Решение
- Одна система полей на все вертикали: только `Field + Input/Select/Textarea/DateField` и три размера по токенам
  (`md` 38px по умолчанию, `sm` для фильтров в панелях, на телефоне всегда 44px/17px). Других высот нет.
- Общие наборы полей по смыслу (доменные адаптеры, не копии): Человек (имя, фамилия, телефон, email, день рождения, заметка),
  Деньги (сумма, валюта), Время (дата, время, длительность в минутах), Позиция каталога (название, цена, длительность/единица).
  Отель/салон/ресторан берут набор и меняют только слово сущности (гость/клиент), а не поля и вид.
- Словарь подписей: Имя, Фамилия, Телефон, Email, Дата рождения, Заметка, Цена, Длительность, мин.
- Сторож: два новых правила с храповиком (baseline): `raw-form-control` и `control-size-literal`.
  Существующие нарушения записаны в снимок и могут только уменьшаться; новые запрещены.

## Порядок (срезами, каждый со скринами 1440/390, светлая и тёмная)
1. Сторож + словарь + наборы полей (без смены вида). Маленький PR.
2. Убрать перекраску полей в разделах: reservations, общий слой, inventory, bar, channels, finance, chessboard → токены.
3. Поля руками → компоненты: branches, create, login, employee-portal, chessboard, marketing/site.
4. Подписи по словарю, «*» → required, по вертикалям.
Миграций нет, бизнес-логика не меняется.
