# 2026-10-22 Гостиница: открытые пункты живого аудита (P1/P2)

Статус: исполнено агентом без новых бизнес-правил (AGENTS.md §15: тексты, ошибки, доступность, UI по принятым решениям).
Ветка `hermes/ahotel-20261022`. Источник: аудит гостиницы на app.wetop.ai 21-22.10.2026.

## Проблема

На живом сайте у гостиницы остались плитки над списками (шахматка, «Гости», «Номерной фонд», «Брони по источникам»),
технические слова («ячейка», RevPAR, ADR, ROMI, CTR/CPM/CPL, Asia/Almaty), ISO-даты в счёте, печати и сообщениях API,
деньги в двух форматах («50 000,00 KZT», «30 000,00 ₸»), английская подсказка браузера в окне расхода.

## Варианты

- Плитки: А) уплотнить плитки; Б) одна строка итогов, как уже сделано в «Финансах» (`money-summary`).
- Даты в счёте: 1) переписать хранимое описание начисления (миграция данных); 2) менять только показ.

## Решение

- Б. Общий компонент `apps/web/src/lib/summary-line.tsx` (+ `app/summary-line.css`): части через запятую, число жирным
  с прежним testid, ссылка там, где была плитка-ссылка. Применён на шахматке (`day-line.tsx`), в «Гостях»
  (`guests-summary.tsx`), «Номерном фонде», отчёте каналов (`channel-totals.tsx`). Стрелки динамики фонда сняты вместе
  с плитками.
- 2. Хранимые описания начислений не меняются (финансы, AGENTS.md §15): `lib/charge-text.ts` показывает
  «22 окт. – 24 окт.» на экране и «22.10.2026» на печати и не повторяет вид начисления.
- «Ячейка» → «номер» в текстах гостиницы и в сообщениях API броней и номеров. Модель и коды не меняются.
- Показатели словами: `lib/metric-words.ts` (Средняя цена ночи, Доход на номер, Окупаемость рекламы, Цена обращения,
  Доля кликов, Цена 1000 показов, Цена клика). CSV-выгрузки оставлены со своими заголовками.
- Деньги: `formatOwnerMoney` Главной и `formatMinorRu` API без копеек, когда их нет, тенге знаком «₸».
- Имя гостя «Имя Отчество Фамилия» (`guestDisplayName`).
- Кнопка календаря поля даты: имя поля перенесено из `aria-label` в `aria-description` (иначе поиск поля по подписи
  находил и поле, и кнопку).

## Не сделано (нужен владелец)

  19.10.2026; общая «Зарплата» для гостиницы это новый модуль (AGENTS.md §16).
