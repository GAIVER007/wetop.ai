# 22.10.2026: личные кабинеты по ролям, официант → бар и кухня, исправления живого аудита D

Решение владельца: голосовое 21.10.2026 и «Давай делай полностью все» 22.10.2026. Это ответ «да» на все четыре
вопроса, заданных после аудита D (`/tmp/personnel/audit/D-platform.md`, `D-roles-inventory.md`).

## Решено

1. **«Личный кабинет» (EMPLOYEE) после входа сам попадает в «Мою работу».** `GET /branches` открыт правом `self`.
   Список и так сужен назначениями сотрудника, карточки бизнесов отдаются только с правом `desk`. Ответ несёт
   `personal`, и `/scope/resolve` ставит его филиал без экрана выбора. Оболочка без выбранного филиала не делает
   EMPLOYEE «администратором», поэтому меню и страницы рабочих разделов с ошибкой 403 он не получает.
2. **Демо брони гостиницы открывается в стойке**, по адресу `/website/booking/demo?site=`. Путь `/w/demo` на адресе
   API туннель наружу не пускает намеренно, поэтому ссылка давала 404. Цены и бронь API принимает с хоста стойки
   (`PUBLIC_APP_URL`/`APP_URL`), только для путей виджета гостиницы.
3. **Карточка «Сайт и SEO» показывает лицензию конструктора**: «Подключает WETOP», «Срок вышел» или «Доступно».
4. **Кабинет мастера и официанта:**
   - зарплата считается так же, как в `/payroll` руководителя;
   - строка «Мой месяц»: смены, выходные, услуги или заказы, столы, гости, выручка, бонусы;
   - отсутствия видны;
   - график мастер только смотрит, меняет его руководитель.
5. **Официант с телефона:**
   - право `orders` у EMPLOYEE в ресторане: заказ только на себя, бронь стола, без кассы и отчётов;
   - миграция 142: станция у категории меню и у строки заказа (KITCHEN/BAR), статус и `ready_at` у строки, статус
     заказа выводится из строк;
   - `restaurant_reservations.employee_id`: кто принял бронь (закрывает Q-CALENDAR-2026-10-17);
   - экран `/waiter` для телефона, а `/kitchen` и `/drinks` показывают только строки своей станции.
6. **Не входит в этот шаг**, нужен отдельный план:
   - кабинет управляющего с урезанным набором разделов (S9);
   - кабинет горничной и ресепшена гостиницы (S10).
