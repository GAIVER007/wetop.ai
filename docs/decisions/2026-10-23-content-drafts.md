# Контент: черновики постов с ИИ без n8n (23.10.2026)

**Проблема.** Экран «Маркетинг → Контент» был заготовкой. У владельца есть рабочая связка n8n «Clony AI MarkVision»
(контент-завод проекта MarkVision): открытый webhook, без лимита расходов и обработчика ошибок, 5 поставщиков ИИ.

**Варианты.** (1) звать n8n MarkVision из WETOP; (2) перенести логику в WETOP по образцу `ad-proposal/0`;
(3) оставить заготовку.

**Решение.** (2). Таблица `content_drafts`, контракт `content-draft/0` в `apps/ai-seller`, API в `apps/api`, домен в
`@pms/domain/marketing/content-draft`. Из MarkVision берутся правила: A/B, CTA на следующий шаг, проверка цифр по
фактам карточки, одна перегенерация. Публикация в соцсети, картинки и видео — следующими срезами.

**Причина.** Один ключ модели и общий бюджет платформы, проверка ответа кодом, без внешнего оркестратора и чужих
учёток; так уже сделан ИИ-таргетолог (ADR-MKT-LAUNCH).

**Последствия.** Новая миграция `content_drafts` (на production отдельным «да»). Порядок PR: домен → контракт бота →
миграция и API → экран. Утверждено владельцем 23.10.2026.
