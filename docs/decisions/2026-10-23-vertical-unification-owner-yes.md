# Решение владельца 23.10.2026: единый вид вертикалей, ответ «Да»

Дата: 23.10.2026. Источник: ответ владельца «Да» в чате Hermes на список решений из разбора
`AUDIT-screens.md` (сравнение гостиницы, салона и ресторана по экранам, 22.10.2026).

## Проблема
У гостиницы, салона и ресторана одинаковые разделы собраны по-разному: расходы на Главной стоят справа,
подписи зарплаты разные, у ресторана финансы и отчёты на своём адресе, карточки клиента у ресторана нет.
Правило владельца: дизайн один, отличаются только слова.

## Решения (принято «Да»)
1. **Главная V4: «Куда уходят деньги» внизу одной полосой, Главная в один экран** (уточнение владельца 23.10.2026:
   «делай как удобно, чтобы было в один экран»). Справа остаётся «Требуют решения»; внизу четыре крупные статьи и
   ссылка на остальные в «Финансах»; график ниже на 40 px, чтобы 1280×720 не листался (PR #792).
2. **Зарплата: одни подписи колонок для всех направлений**: «Удержания» (вместо «Штрафы»),
   «Начислено», «Выплачено», «Осталось». У гостиницы, где выплат из кассы нет, колонки
   «Выплачено» и «Осталось» показывают то, что есть в данных; деньги и расчёт не меняются.
3. **Финансы и отчёты ресторана на общем адресе `/finance` и `/reports`** с адаптером ресторана;
   `/restaurant-finance` остаётся переадресацией, старые ссылки не ломаются.
4. **Карточка клиента у ресторана**, как у салона (история визитов). Нужен API визитов клиента:
   перед кодом короткий план (AGENTS.md §1), модель данных не меняется без DATA_MODEL.md.
5. **«Конкуренты» (`/market`) у всех направлений** (обязательный раздел, правило владельца).
   Что считать «загрузкой соседей» у салона и ресторана и откуда брать данные, остаётся вопросом
   (QUESTIONS.md), до ответа раздел показывает то, что доступно, без выдуманных чисел.

6. **Каталог (номера, услуги, меню): вариант A с подзаголовками категорий из B** (выбор владельца 23.10.2026 по
   эскизам `sketches/catalog`). Один экран «Каталог» для всех: заголовок = пункт меню, вкладки по направлению
   (отель «Номера, Категории, Услуги»; салон «Услуги, Категории»; ресторан «Позиции, Категории, Добавки»),
   строка «поиск, категория, статус», таблица с одними колонками «Название, Категория, свой параметр
   (мест / длительность / выход), Цена, Себестоимость, Статус», при «Все категории» строки разбиты
   подзаголовками категорий; правка в панели справа общими полями; пусто — EmptyState с «Добавить».
   Данные и цены не меняются, только вид; у отеля цена «от» из тарифа, себестоимости нет.
