# Гражданство на заселении: выбор страны, окно на шахматке, правило только для Казахстана

Дата: 24.10.2026. Ветка `fix/checkin-citizenship-20261024`.

## Проблема

Заселение без гражданства основного гостя отклоняется сообщением «Укажите гражданство в карточке гостя — без него
заселение невозможно (eQonaq)». Владелец (24.10.2026) прислал это как проблему бронирования:

1. ошибка всплывает уже на «Заселить», исправить её с шахматки нельзя: нужно идти в карточку брони и открывать
   «Изменить гостя»;
2. гражданство вводится кодом ISO alpha-3 руками (`KAZ`), подпись «ISO alpha-3, напр. KAZ» непонятна стойке;
3. eQonaq есть только в Казахстане, а WETOP подключает гостиницы и салоны других стран (Катар): правило не давало
   заселить там, где регистрации иностранцев через eQonaq нет.

## Варианты

- A. Оставить правило везде, улучшить только ввод.
- B. Правило по стране объекта (`properties.country_code`): Казахстан и объект без страны требуют гражданство,
  другие страны нет. Ввод выбором страны и окно на заселении.
- C. Настройка «требовать гражданство» у каждого объекта.

## Решение

B. Владелец поручил «пройти это всё самому и навести порядок» после предложения именно этих трёх пунктов.

- `@pms/domain`: `CITIZENSHIP_COUNTRIES` (249 стран ISO 3166-1, названия по-русски, частые первыми),
  `citizenshipLabel`, `citizenshipRequiredForCheckIn(countryCode)`: `KZ` и пустая страна → обязательно.
- API: `checkIn` и «Сегодня» на стойке (`blockedReason: 'нет гражданства'`) берут страну объекта.
- Веб: в карточке гостя список стран вместо кода; на шахматке и в карточке брони при отказе заселения окно
  «Укажите гражданство гостя» → «Сохранить и заселить». Гость берётся по номеру брони на сервере
  (`setBookingCitizenshipAction`), не из браузера. В шапке брони и карточке гостя название страны вместо кода.

## Причина

Объект без страны остаётся под правилом: старые казахстанские объекты не теряют проверку молча. Код в базе прежний
(CHAR(3), DATA_MODEL §3), модель данных и миграции не меняются.

## Последствия

- Гостиница с `country_code` не `KZ` заселяет без гражданства. Отправка в eQonaq этим решением не затронута.
- Страна объекта задаётся при настройке: для Катара `QA`.
- Проверки: домен 24, API (заселение Катар/Казахстан, «Сегодня») 62, UI шахматки и карточки брони, RED на каждом слое.
