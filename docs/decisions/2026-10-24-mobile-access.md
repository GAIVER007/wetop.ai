# Mobile access

Дата: 24.10.2026. Локальная реализация по принятому владельцем плану. Регистрация исключена: входят существующие пользователи веба.

Проблема: native приложение не использует браузерную HttpOnly cookie, внутренний API не публикуется напрямую.

Варианты: раскрыть внутренний API; использовать cookie-маршрут сайта; добавить ограниченный Bearer gateway. Выбран последний: статический набор auth/branches действий, DTO-фильтрация, ограничения тела/ответа и таймауты. Cookie и служебные ключи не являются авторизацией. Новый маршрут выключен по умолчанию и требует MOBILE_GATEWAY_ENABLED=1. Публикация и включение отдельно по процессу выпуска.

Native токен хранится через Expo SecureStore, пароль не сохраняется. Web preview использует только память, без localStorage. Контекст подтверждается me со scope. При выходе и смене организации очищается предыдущее состояние, поздние ответы игнорируются. Смена организации ротирует токен по существующему контракту. Навигация закрыта до готового контекста, серверная проверка прав остаётся обязательной.

IP: MOBILE_GATEWAY_TRUSTED_PROXY=cloudflare включать только при доказанном переписывании CF-Connecting-IP и закрытом прямом доступе к Next. Без этого либо без валидного CF-Connecting-IP публичные login/password-reset отклоняются до upstream: API visitorIp для внутреннего соединения без IP не включает лимит. До production проверить архитектуру proxy и лимиты; текущая реализация не заявляет проверенную публичную конфигурацию.

Последствия: подготовлена отдельная точка входа для native, без новых таблиц и миграций. Рабочие данные и операции подключаются следующими срезами. Документация Expo: https://docs.expo.dev/versions/latest/sdk/securestore/ и https://docs.expo.dev/router/advanced/protected/ . Native устройство отдельно проверяет SecureStore и доступность.

Мобильный personal-кабинет при нескольких филиалах предлагает явный выбор, даже если веб /my-work выбирает первое назначение. В приложении есть экран выбора; это следует утверждённому требованию не выбирать первый филиал молча. Выбор запоминается только в текущей сессии, после перезапуска пользователь выбирает снова.
