# Меню профиля и возврат к настройке салона

Дата: 25.10.2026. Статус: утверждено владельцем в чате.

Проблема: выбор языка перегружает меню, а настройку салона трудно открыть повторно.

Варианты: сбрасывать прогресс настройки либо повторно открывать существующий чек-лист.

Решение: убрать выбор языка из меню профиля. Добавить пункт «Настройка салона» для владельца и управляющего по существующему праву settings. Явный переход entry=reopen открывает сохранённый чек-лист, включая уже готовые салоны старой версии. Обычный автоматический вход сохраняет прежние перенаправления. Профиль, моя работа, филиалы, помощь, поддержка, новости и отзыв сессии при выходе сохраняют действующую логику.

Причина: человек должен иметь доступ к настройкам, не теряя уже созданные данные.

Последствия: модель данных, права и прогресс не изменяются. Миграции и сброс production не нужны.
