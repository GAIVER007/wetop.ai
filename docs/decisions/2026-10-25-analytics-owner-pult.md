# Пульт владельца в «Аналитике бизнеса» для салона, ресторана и гостиницы

Дата: 25.10.2026. Ветка: `task/analytics-pult-20261025`.

## Проблема

У салона «Аналитика» показывала два блока: выручку по завершённым записям и записи по статусам. Владелец прислал
скриншот: «очень тускло, пусто». За пустой день это два нуля без подсказки, что делать.

## Варианты

Владельцу показаны три эскиза (`workspace-cleanup-control/owner-home-source-check/salon-analytics-sketch/`):

- A «Пульт владельца»: четыре главные цифры со сравнением, график и «Что сделать сейчас», ниже разборы;
- B «Итоги простыми словами»: одна большая цифра и выводы текстом;
- C «Рабочие вкладки»: полоса цифр и вкладки с таблицами.

## Решение

Владелец 25.10.2026: «да давай вариант а и адаптируй его под все направления и рестораны и гостиницы».

- Салон: плитки «Выручка», «Средний чек», «Загрузка мастеров», «Повторные клиенты» со сравнением с таким же отрезком
  перед периодом; выручка по дням; «Что сделать сейчас»; записи по статусам; клиенты (пришли, повторные, онлайн,
  неявки с суммой, неоплата); оплаты по способам; мастера (выручка, визиты, загрузка); услуги по выручке.
- Ресторан: плитки «Выручка» (с баром), «Средний чек», «Заказов» (с гостями), «Фудкост»; выручка по дням;
  «Что сделать сейчас»; брони по статусам; оплаты; себестоимость и прибыль; блюда, категории, официанты, недостачи.
- Гостиница: прежний «Обзор» (плитки, графики, фильтры) остаётся; рядом с графиком загрузки добавлен блок
  «Что сделать сейчас».
- «Все филиалы» без изменений: короткая сводка по каждому филиалу.

Подсказки считаются по простым порогам и всегда ведут в раздел, где это исправить: неявки (сумма упущенной выручки),
неоплаченные визиты, мастера с загрузкой ниже 40%, мало онлайн-записей (ниже 20%); у ресторана недостачи, фудкост
выше 35%, неявки броней; у гостиницы незаезды, отмены от 15%, загрузка ниже 50%, один канал от 70%, проживания без
номера. Нет проблем: одна строка «Срочных дел нет».

## Расчёт

Только из данных, которые API уже отдаёт журналу и кассе: `GET /beauty/appointments?date=` по дням (записи, строки
услуг, платежи, графики мастеров), `GET /food-service/period-report`, `GET /desk/dashboard`. Новых таблиц, миграций и
маршрутов API нет. Деньги в BigInt минорных единиц. Загрузка мастера: минуты записей без отмен (неявка тоже занимала
окно) к минутам по графику дня, выходной не считается. Прошлый период грузится отдельно; сбой даёт плитки без
сравнения, экран не падает.

## Причина

Владелец видит главное за 5 секунд и сразу что делать, подробности ниже. Один вид для трёх направлений с адаптерами
данных, без копий экранов (правило владельца об общих компонентах).
