# Гостевой счёт на телефоне

Дата: 25.10.2026. Пункт 6 принятого plans/mobile-restaurant-completion-2026-10-25.md.

Отдельный просмотр из карточки открытого заказа показывает номер, стол/стойку, гостей, позиции с количеством и ценой, серверные totalMinor и paidMinor, остаток через BigInt. Итог не восстанавливается из строк: источник истины серверный заказ. Суммы форматируются существующей money с неразрывным пробелом перед валютой; строки итогов допускают перенос целого блока для узкого экрана и большого шрифта.

Варианты: считать показанный счёт актуальным без проверки либо явно обозначить снимок. Выбран снимок с датой изменения и кнопкой обновления через существующее чтение списка заказов. После обновления сотрудник снова открывает нужный заказ. Новый endpoint чтения по ID не добавлен. Отменённый заказ не показывает требование оплаты, отрицательный остаток не превращается в требование возврата: нужно обновить данные. Кнопка счёта показана только у открытых неотменённых заказов.

Это просмотр, не печать, фискальный чек или подтверждение эквайринга. Права, суммы и модель данных не меняются. Удалена устаревшая надпись о недоступности создания/расчёта на телефоне.
