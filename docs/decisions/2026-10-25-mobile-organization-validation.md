# Проверка смены организации в мобильном приложении

Дата: 2026-10-25. Ветка: codex/wetop-mobile.

Проблема: ответ ротации токена и последующий me не сравнивались с выбранной организацией. Технически успешный ответ мог открыть прежний кабинет.

Варианты: довериться ответу ротации или проверить пользователя и выбранную организацию до открытия кабинета. Выбрана проверка обоих ответов. Это уточнение утверждённого требования серверно подтверждённого контекста, без изменения API и модели.

Решение: user ID должен совпадать с текущим пользователем, organization ID с выбранной организацией. Первый me нового токена должен подтвердить эту пару; scoped me продолжает проверять филиал и пользователя. Несовпадение закрывает доступ, удаляет сохранённый токен и инициирует его отзыв. Если проверка после ротации не завершилась, требуется повторный вход; неподтверждённый токен не используется для повторного открытия кабинета. Сетевой отзыв остаётся best effort.

Доказательство: три новых регрессионных случая сначала падали (ready вместо error), затем прошли. Полный mobile: 49/49, mobile-types и mobile lint без ошибок. Нативный запуск этим срезом не проверялся.
