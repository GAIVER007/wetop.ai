# Окно «Новая бронь»: гость слева первым, справа как было (26.10.2026)

**История:** владелец выбрал из эскизов вариант C «весь фонд одной картой» (все номера мелкими квадратами). После
снимков в коде: «раньше же правая часть лучше была» и прислал снимок прежнего окна. Карта отменена во всех трёх
направлениях (салон и ресторан не меняются, PR №878 закрыт).

**Остаётся (гостиница):**
- справа без изменений: свободные номера кнопками по категориям (вариант B, ADR 2026-10-23-booking-window);
- слева сначала гость (имя, фамилия, телефон), потом даты (требование владельца: «слева ФИО, номер, заезд»);
- при одном размещении поля «Категория» и «Номер / койка» скрыты визуально (`sr-only`), их ставит кнопка справа;
  поля остаются в форме для отправки и читалки. При группе поля видны, как раньше. Окно ниже на две строки.

Данные и API не менялись. UI: `tests/ui/booking-fund-map.spec.ts` (1280×800 обе темы, 390), `booking-compact`,
`booking-dates`.
