# Окно «Новая бронь»: весь фонд одной картой (26.10.2026)

**Решение владельца:** из трёх эскизов (вкладки с плитками, список строками, весь фонд картой) выбран вариант C
«Весь фонд одной картой»: «удобней». Требования: окно на один экран без прокрутки, слева ФИО, телефон, заезд,
справа номера.

## Что изменено (гостиница)

- Слева сначала гость (имя, фамилия, телефон), потом даты и быстрые даты, гостей на место, количество мест.
- Поля «Категория» и «Номер / койка» при одном размещении скрыты визуально (`sr-only`), остаются в форме для
  отправки и читалки. Категорию и номер ставит нажатие на карте. При группе поля видны, как раньше.
- Справа карта: категория строкой («свободно N из M»), все действующие места категории квадратами по порядку чисел.
  Свободные нажимаются, занятые серые и отключены (`aria-label` «Номер X, занят»), выбранный синий, неубранный с
  точкой. «позже» назначает номер позже. Легенда снизу.
- Все места категории берутся из уже загружаемого `api.inventoryUnits()` (активные), свободные из прежней проверки
  `reservationsApi.availability`. Модель `room-choices.ts` отдаёт `cells` (свободные и занятые).

Данные, API и проверки сервера не менялись, миграций нет. Создание брони идёт из тех же полей формы.

- UI: `tests/ui/booking-fund-map.spec.ts` (1280×800 светлая и тёмная: гость выше дат, весь фонд и «Создать бронь»

  `booking-compact`, `booking-dates`: 10/10. Снимки `reports/booking-fund-map-2026-10-26/`.

## Салон и ресторан (тот же вид, 26.10.2026)

- **Салон, «Новая запись»:** слева клиент и услуга (длительность, цена); специалист при одной услуге выбирается на
  карте, поле остаётся для читалки. Справа дата и время, под ними карта дня мастеров: строка на мастера, ячейка на
  30 минут от раннего начала до позднего конца смен. Свободная ячейка значит, что визит целиком помещается с этого
  времени (та же `freeSlots`), занятая пересекается с живой записью, остальное закрыто (вне смены, прошлое, визит не
  успевает). Только мастера выбранной услуги. Нажатие ставит мастера первой услуги и время
  (`beauty/master-map.ts`, тест 4/4, красный на заглушке).
- **Ресторан, «Новая бронь»:** справа все столы каждого зала карточками («свободно N из M»); занятые на это время и
  маленькие для компании серые и отключены (`Стол 7, занят` / `мало мест`). Поле «Стол» осталось для ручной посадки.

Данные и API без изменений. UI: `tests/beauty-ui/beauty.spec.ts` «новая запись: свободное время…» и
`tests/food-ui/restaurant.spec.ts` «бронирования: шкала…» дополнены карты и снимками 1280×800.
