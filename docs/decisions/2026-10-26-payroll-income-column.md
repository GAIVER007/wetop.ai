# Зарплата: столбец «Доход» первым

Дата: 2026-10-26. Владелец: «добавь поле самое первое, Доход: на какую сумму сотрудник оказал услуг, чтобы было видно,
с чего считается оплата».

Решение: в таблице «Сотрудники» раздела «Зарплата» (салон и ресторан, `food/payroll-board.tsx`) сразу после имени
столбец «Доход» = `salesMinor` (салон: выполненные записи специалиста за месяц, ресторан: закрытые заказы сотрудника),
та же база, с которой считается «% с записей / заказов». В строке «Итого» сумма дохода по всем. Подсказка столбца
объясняет базу.

Последствия: API и расчёт зарплаты не меняются, поле уже приходило в ответе. Тест
`apps/web/src/app/food/payroll-currency.test.ts`.
