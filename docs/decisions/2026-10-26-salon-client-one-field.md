# Окно записи салона: клиент одним полем «Телефон или имя»

Дата: 2026-10-26. Владелец (скриншоты окна «Новая запись»): «зачем нам тавтология, коряво выглядит; оставь логику: при
вводе имени или номера появляется клиент, если он уже есть в системе».

Было: поиск «Телефон или имя», под ним отдельные поля «Имя клиента», «Фамилия», «Телефон» и три кнопки
(«Гость», «Последний клиент», «+ Новый клиент») столбиком. Одно и то же спрашивалось дважды.

Решение:
- одно поле «Телефон или имя»; при вводе ниже клиенты из базы (тот же `matchesCustomer`), нажатие выбирает клиента чипом;
- если клиента нет, новый создаётся из введённого: номер (от 7 цифр) телефоном, первое слово именем, остальное фамилией
  (`splitCustomerQuery`), под полем строка «Новый клиент: …»; на сервер уходят те же поля `firstName`, `lastName`, `phone`;
- «Гость» кнопкой, «Последний клиент» только когда он есть; «+ Новый клиент» убран (новый клиент получается сам).

Последствия: API и данные не меняются. Тесты: `apps/web/src/lib/customer-query.test.ts` (RED → GREEN),
`multi-service-form.test.ts`, beauty-ui окна записи (11/11 на своей локальной базе).
