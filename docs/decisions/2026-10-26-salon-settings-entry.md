# Единый вход в настройки салона

Дата: 2026-10-26.
Статус: подтверждено владельцем в чате, реализация в PR.

Проблема: отдельный пункт «Салон» открывает большую страницу с часами работы,
напоминаниями и бонусами, хотя эти параметры уже представлены во «Всех настройках».

Варианты: оставить общий экран; удалить формы; оставить единый вход и отдельные формы.

Решение: убрать пункт «Салон» из меню настроек. Адрес `/beauty-settings` без выбранного
параметра ведёт на `/settings`. Ссылки хаба выбирают одну форму через `section`:
`hours`, `reminders`, `bonuses`. Подсказка первоначальной настройки ведёт к часам работы.

Причина: убрать дублирующий вход и перегруженный экран, сохранить существующие функции.
Последствия: модели, права редактирования и бизнес-правила форм не меняются.
