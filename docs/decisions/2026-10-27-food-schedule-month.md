# 27.10.2026: вид «Месяц» у расписания броней ресторана

- Проблема: владелец 26.10.2026 велел каждую правку UI применять во всех вертикалях. Журнал салона получил «Месяц» (#890), у ресторана в расписании были только «Шкала» и «Список» за день.
- Варианты: 1) 35–42 запроса по дню; 2) один запрос диапазона.
- Решение: `GET /food-service/reservations?date&dateTo` (не больше 42 дней, без dateTo как раньше один день); вид «Месяц» по адресу `/table-reservations?view=month`, сетка и классы месяца салона (эскиз А).
- Причина: один запрос, единый вид месяца во всех вертикалях. Данные и права не меняются: официант по-прежнему видит только свои брони (§33.6).
- Последствия: клик по брони открывает её окно, по номеру дня открывается шкала этого дня.
