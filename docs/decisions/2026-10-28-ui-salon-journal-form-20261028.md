# 2026-10-28 ui/salon-journal-form-20261028: окно записи салона, источник клиента, яркие карточки журнала

## Проблема

Владелец 28.10.2026 по скриншотам журнала Kyial:
1. «Карточку цвета поярче, а то как-то тускло»: заливки статусов почти белые, завершённая серая.
2. «Чтобы название нормально влезало, а то обрезано»: имя клиента и мастера резались («MAGDOLEEN(», «Keamogetsw…»).
3. «Окно записи криво, текст улучши»: сводка записи висела строками разной высоты.
4. «Было же лучше, где поля имя и номер телефона, как отдельно, и источник типа Instagram, WhatsApp»: 26.10.2026 поля
   клиента свели в одно «Телефон или имя» (решение `2026-10-26-salon-client-one-field.md`), это оказалось неудобно,
   а источника записи со стойки не было вовсе.

## Решение

- Окно новой записи: «Имя клиента» и «Телефон» двумя полями рядом (на телефоне друг под другом); поиск клиента из
  базы работает по обоим полям, как раньше по одному; «Гость» и «Последний клиент» остаются. Решение от 26.10.2026
  в части одного поля отменено владельцем.
- «Откуда клиент» кнопками: Instagram, WhatsApp, Звонок, Пришёл сам; без выбора «Администратор». Данные:
  DATA_MODEL `APPOINTMENT-SOURCE-20261028`, миграция 168.
- Карточки журнала ярче: заливка тоном статуса гуще, полоса 6 px, завершённая зелёная. Имя клиента своей строкой
  переносится по словам, имя мастера в шапке колонки без троеточия.
- Сводка карточки записи ровной сеткой: подписи слева одной ширины, значения на той же строке, услуга заголовком.

## Последствия

Миграция 168 до выкладки (скрипт сервера сам ждёт). Тесты окна записи переписаны под два поля.
