# 2026-10-28 ui/site-hero-copy-20261028: фраза первого экрана вместо названия, тексты без выдумок

## Проблема

Первый экран нового сайта показывал крупно только название филиала («Lashes Studio»): так не выглядят сайты
агентств. Готовые тексты «Предложить текст» обещали то, чего WETOP не знает: «опыт от 5 лет», стерилизация,
«лучшая цена», «мгновенное подтверждение», свежие продукты.

## Варианты

1. Писать первый экран ИИ при каждом создании: дорого, медленно, без ИИ-лицензии сайт остаётся с названием.
2. Детерминированные фразы под стиль и направление, подзаголовок из фактов; ИИ при сборке по описанию следует
   тому же правилу.

## Решение

Вариант 2 (`packages/domain/src/marketing/hero-copy.ts`):

- Заголовок: короткая фраза под тон стиля (тон по шрифту темы: LUXE/CLASSIC премиальный, BOLD/ROUNDED смелый,
  остальное спокойный) и направление, три варианта на тон, ru/kk/en. У премиального салона фраза по тому, чем он
  занимается (ресницы и брови, ногти, волосы).
- Подзаголовок из фактов: название (для SEO и GEO), разделы услуг или меню, типы номеров, город, способ записи.
- Новый сайт по шаблону сразу с фразой; смена шаблона у готового сайта тексты не трогает.
- «Предложить текст» с фактами берёт фразы первого экрана под текущий стиль; «О нас» переписан без выдумок.
- Промт сборки ИИ (`site_generation.py`, правило 14): заголовок фраза, название в подзаголовке, без стажа, скидок,
  «лучших цен», скорости подтверждения.
- Заголовки переносятся только целыми словами (`text-wrap:balance`, без `overflow-wrap:anywhere`).

## Последствия

Готовые опубликованные сайты не меняются. Тест-сторож `hero-copy.test.ts` запрещает выдуманные обещания во всех
фразах на всех языках.
