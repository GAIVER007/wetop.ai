# Сайт по промту вместо трёх шаблонов («Создать свой сайт»)

Дата: 29.10.2026. Поручение владельца: «сто клиентов, а всего три шаблона: у всех клиентов одинаковые сайты. Переверни
логику генерации сайтов полностью по промту: человек пишет промт, на его основе создаётся сайт, сразу с SEO и GEO;
сайт можно редактировать и опубликовать на наших поддоменах».

## Проблема

Главный путь «Сайт и SEO» был «выбрать один из трёх шаблонов → Создать сайт». У ста салонов было три вида сайта.
Генерация ИИ по описанию была вторым путём и тоже брала оформление из набора; без ключа модели на сервере она не
работала вовсе.

## Варианты

1. Больше шаблонов (10, 20). Дешево, но та же проблема на ста клиентах, а выбор из двадцати картинок тяжелее промта.
2. Дизайн решает только ИИ. Самый гибкий, но без ключа модели, бюджета и бота сайт не создаётся, а ответ модели
   надо проверять на читаемость и схему каждый раз.
3. Дизайн по промту на сервере (домен, без сети) + ИИ по желанию дописывает тексты. Выбран.

## Решение

- `packages/domain/src/marketing/prompt-design.ts`: `sitePromptDesign(prompt, vertical, seed)` читает настроения промта
  (ru, kk, en: тёмный, премиум, яркий, спокойный, эко, минимал, море, тёплый, классика, современный, быстро, команда,
  розовый, золото, синий) и собирает свою тему (фон, акцент, шрифты, углы, плотность), порядок блоков главной и вид
  каждой секции. Зерно из id филиала и текста: тот же промт у того же филиала даёт тот же сайт (превью равно
  сохранённому), два салона с одним промтом получают разные сайты (на 100 салонах с одной фразой не меньше 30 видов,
  тест). Читаемость по правилам валидатора SiteSpec: тёмный фон только с тёмной схемой и светлым акцентом.
- Блоки и тексты по-прежнему из данных филиала (`starterSpecFromFacts`): услуги, цены, мастера, меню, номера, часы,
  контакты, SEO-заголовок и описание, FAQ, карта. Ничего не выдумывается.
- API `POST /marketing/site/from-prompt` `{ prompt }`: как `from-template` (лицензия, scope, 409 `SITE_HAS_VERSION`,
  журнал), документ собирает сервер. В журнал не идёт текст промта (MKT9 §109), только тема и хэш версии.
- Экран «Создать свой сайт»: слева промт с подсказками и диктовкой, справа живое превью ровно того сайта, что сохранит
  сервер; «Создать сайт» заводит сайт и открывает редактор. Если ИИ сайта на сервере включён, сразу ставится правка
  PATCH к первой версии с тем же промтом (ИИ переписывает тексты под пожелания); выключен или отказал: сайт уже готов.
  Готовые стили остались запасным путём в свёрнутом блоке «Или начните с готового стиля».

## Последствия

- Модель данных и миграции не меняются: SiteSpec v0 и его словари те же (`DATA_MODEL.md` §29 без правок).
- Старые сайты не меняются; `from-template` работает как раньше.
- Расширение словарей SiteSpec (свои цвета, а не пресеты) остаётся следующим шагом и потребует правки `DATA_MODEL.md`.
- Публикация на поддомены не тронута: `<slug>.<SITES_BASE_DOMAIN>` (Q-271).
