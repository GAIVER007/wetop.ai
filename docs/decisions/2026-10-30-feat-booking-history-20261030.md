# «История изменений» у брони гостиницы, как у записи салона (30.10.2026)

## Проблема

Владелец 30.10.2026: «давай да, делай как единую систему, лучшее все должно быть в каждом разделе, по порядку».
Сверка журнала салона и календаря гостиницы: у записи салона есть «История изменений» (кто, когда, было и стало,
комментарий), у брони гостиницы вкладка «История» вела только ссылкой в общий журнал, а стойке он закрыт.

## Решение

- API `GET /reservation-history/:number` (право `desk`): строки общего журнала по брони, её местам, счетам и
  оплатам; служебные строки системы скрыты; замок организации; снимки через `safeSnapshot` (без ФИО гостя).
- Вкладка «История» брони показывает ленту: время, действие, раздел, автор, деньги было и стало, комментарий,
  «Подробнее». Ссылка в весь журнал остаётся владельцу и управляющему.

## Дальше по порядку (сверка 30.10.2026)

Салон: «Позвонить» и WhatsApp в карточке записи; ссылка на оплату. Гостиница: ссылка на отзыв после выезда.
