# «Клиенты» Кабинета WETOP: вариант C без цифр Главной (30.10.2026)

## Проблема

Владелец: «в Клиентах дублируется инфа с Главной (MRR и т. д.), что за люди у клиентов, зачем нам это; страны добавь в
Клиенты». Выбран эскиз C («Задачи и таблица»), правка владельца: вместо «Партнёр» показывать, сколько клиент принёс денег.

## Решение

- Сверху четыре плашки «с кем говорить»: кончается пробный (7 дней), под риском, долго не входили (больше 7 дней),
  скоро оплата (14 дней). Убраны «Клиенты», «Люди у клиентов», MRR, средний LTV.
- Фильтры: статус (как было), страна, направление, поиск по имени и почте владельца; выбор в адресе.
- Таблица: клиент, страна (флаг), вид, статус, работа 7 дн., входили, за 30 дней, «Принёс денег» (все оплаты клиента
  WETOP), «Написать». Отток месяца строкой над таблицей.
- API: `GrowthClient.country` из `organizations.country_code` (поле уже есть, база не меняется).

## Проверки

growth.test RED (страны нет), затем 15/15; i18n + design-slop 72/72; tsc web/api 0; eslint 0; UI platform-cabinet
(9 тестов, таблица целиком в 1280).
