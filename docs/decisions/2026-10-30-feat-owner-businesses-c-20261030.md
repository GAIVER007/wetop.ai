# «Все бизнесы» владельца, вариант C (30.10.2026)

## Проблема

Владелец: «на главной владельца… Вячеслав владелец и WETOP, и Luxx Aparts (два филиала)… видеть, перемещаться по
объектам». Из трёх эскизов выбран C («3»): итог, одна таблица бизнесов и филиалов с «Перейти», полгода выручки,
общие «Требуют решения».

## Решение

- `GET /owner/businesses?month=` (`apps/api/src/platform/owner-businesses.controller.ts`, право `self`): филиалы всех
  организаций, где человек OWNER с действующим членством (организация не приостановлена). Номер организации из
  запроса не принимается. Читает служебной ролью базы, как «Платформа»: RLS пускает только в организацию сессии.
- Деньги филиала за 6 месяцев: салон выполненные записи, ресторан закрытые заказы и продажи бара, гостиница
  начисления; расходы кассы филиала. Главному администратору строка WETOP из «Денег» компании (USD).
- Итог только по валютам (QAR и USD не складываются, AGENTS §12). Расчёт `apps/api/src/finance/owner-businesses.ts`.
- Страница `/owner` (право `owner`, пункт «Все бизнесы» в «Настройках» у владельца, у управляющего нет; снимки меню обновлены намеренно). «Перейти»: WETOP в кабинет; филиал
  своей организации обычным выбором филиала; филиал другой организации через `/auth/organization` с подсказкой
  филиала (кука «последний филиал»; `/scope/resolve` выбирает его, только если сервер отдал его новой сессии).
- Без миграций.
