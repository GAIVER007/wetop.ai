# Единая Главная «B» для салона, ресторана и гостиницы (30.10.2026)

## Проблема

Владелец 30.10.2026: «применяй главную и для ресторана и для гостиниц и для салонов, для всех единая главная должна
быть»; «в ресторанах понятно, официанты и бармены; в гостиницах как по сотрудникам, мастером, там нет такого,
давай подумаем что добавить».

## Решение

- Один вид `OwnerHomeB` (три колонки на один экран из #983) для всех направлений, подписи по направлению.
- API `GET /owner-home?month=` (право `reports`) для ресторана и гостиницы, чистый расчёт `buildVerticalHome`:
  - ресторан: выручка закрытые чеки и бар; путь гостя по броням стола (забронировали стол, пришли, вернулись);
    официанты (чеки, оценки гостей) и бармены (кто провёл продажу бара) отдельными строками;
  - гостиница: выручка начисления по дню услуги; путь гостя (забронировали, заехали, оплатили, вернулись);
    вместо мастеров «Номера»: категории номеров с ночами, бронями, выручкой и средней ценой ночи (целыми);
    у источника сумма броней.
- Средний чек целыми, половина вверх, как у салона. Салон без изменений (`GET /beauty/owner-home`).
- Сбой нового API не ломает Главную: остаётся прежний вид.

## Дополнение: загрузка номеров (30.10.2026, «давай делай продолжай»)

У категории номеров колонка «Загрузка» = проданные ночи / (активные номера категории × дни месяца в отчёте, текущий
месяц по сегодня филиала); в заголовке «Номера» общая загрузка гостиницы. Без номеров в базе пусто, не 0%.
