# Главная Кабинета WETOP на один экран ноутбука (30.10.2026)

## Проблема

Владелец прислал снимок живой Главной: «сделай повыше, чтобы не было обрезанного ничего, чётко на экране». На ноутбуке
воронка обрезалась на шаге «Продлили», «Доход по месяцам» уходил под край.

## Решение

Только стили Главной (класс `cabinet-home-page` у оболочки кабинета, другие разделы не меняются): плитки цифр ниже
(значение `--text-2xl`, без пустой высоты), шаги воронки ниже (`--space-10`), проценты шага в строку, графики ниже.
Данные и состав экрана прежние.

## Проверки

UI platform-cabinet:22: новая проверка «на 1440×800 цифры, вся воронка и оба графика целиком на первом экране»
сначала красная («Продлили» видно на 39%), после правки зелёная; на 1280 без прокрутки вбок.
