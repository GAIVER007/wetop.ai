# «Клиенты» Кабинета WETOP: город, тариф, следующий платёж (31.10.2026)

## Проблема

ТЗ владельца «две категории админок» п. 4 (30.10.2026): в списке клиентов город, тариф, дата следующего платежа,
партнёр. Сверка (docs/decisions/2026-10-30-feat-vtop-owner-overview-20261030.md) отметила «частично».

## Решение

- `buildCabinet` отдаёт у клиента `city` (город первого объекта), `plan` (название тарифа подписки),
  `nextPaymentOn` («оплачено до»), `partner`. Нет данных: пусто, не выдумываем. Таблицы денег и партнёров ещё не
  заведены: пусто.
- В таблице колонки «Город», «Тариф», «Платёж» (дд.мм). Колонку «Партнёр» не ставим: 30.10.2026 владелец заменил её
  на «Принёс денег» (docs/decisions/2026-10-30-feat-cabinet-clients-tasks-20261030.md); партнёр в карточке клиента.

## Проверки

cabinet.test RED (полей нет), затем 7/7; platform, i18n 248; UI platform-cabinet 10/10 (колонки, город, без
прокрутки вбок на 1280); tsc 0; eslint 0.
