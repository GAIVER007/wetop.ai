# 01.11.2026 Главная кабинета «C» и Обзор WETOP «A»

**Поручение владельца.** Главная: «верхушка, где выбор даты, там пустое пространство, а чтобы увидеть нижнюю
статистику, нужно свайпать вниз; сделай, чтобы было на одном экране с компа». Обзор: «как-то стрёмно всё выглядит,
улучши дизайн, сделай удобней». Из трёх макетов на вымышленных данных выбраны Главная C и Обзор A.

**Решение.**
1. Месяц со стрелками и «Обновить» перенесены в строку заголовка (`Page actions`), отдельной строки нет.
2. Главная C: сверху «Деньги за месяц» (MRR, оплатившие, средний чек, сумма оплат) и «Пробный период» (регистрации,
   активность, не оплатили); воронка продаж одной строкой из шести шагов с полосками (`SalesFunnelRow`); внизу два
   графика.
3. Обзор A: пять главных цифр (MRR, ARR, доход месяца, прибыль, остаток денег); график «Выручка по месяцам» (тот же
   ряд `growth.income`, что на главной) рядом с «Клиентами» и «Финансами»; внизу «Выручка», «Подписки», «Партнёры».
   Каждая цифра один раз, у блока «подробнее» ведёт в раздел.

**Последствия.** API и данные не меняются. Обе страницы в 1440×900 без прокрутки, проверено UI-тестами.
