# 2026-11-01 Кабинет WETOP вид «Б»: Сайт, РНП, Деньги с расходами, Тарифы

## Проблема
Владелец 01.11.2026: «Сайт wetop.ai» выглядит плохо, в РНП «По дням» неудобно и не всё попадает, «Деньги WETOP»
неудобны, расходы отдельным разделом, «Подписки клиентов» выглядят плохо, называть «Тарифы». Эскизы А/Б/В на каждый
раздел, выбор владельца: Б Б Б Б.

## Решение
- Сайт: полоса цифр (посетители, открыли регистрацию, отправили, новые клиенты, с телефона), таблица по дням
  (сегодня сверху, «Все дни / Только с посетителями», итог месяца внизу), ниже страны, источники, страницы.
  API: `daily[]` дополнен визитами, шагами пути по дню визита, визитами с телефона и источниками дня.
- РНП: колонки группами «Сайт / Клиенты / Деньги», добавлено «Открыли рег.» (`signup_open`), недели с понедельника
  строками, текущая раскрыта по дням, неделя раскрывается кликом (`?week=`), итог месяца тёмной строкой.
- Деньги: вкладки Обзор, Поступления, Расходы, По месяцам; бывший раздел «Расходы» стал вкладкой, адрес
  `/platform/cabinet/expenses` ведёт в неё. Кнопки «+ Оплата» и «− Расход» сверху.
- Тарифы (адрес прежний `/subscriptions`): вкладки «Тарифы» и «Клиенты», цифры (платят, без оплаты, просрочены,
  ожидаем), клиент одной строкой, «Изменить» и доступы в окне, «+ Тариф» в окне.

## Причина
Решения владельца по эскизам; модель данных не меняется, миграций нет.

## Последствия
Старые ссылки на «Расходы» работают переадресацией. Новые поля API необязательные для старого веб-клиента.
