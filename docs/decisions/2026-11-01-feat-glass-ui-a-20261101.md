# Стекло «A» на всей стойке

Дата: 01.11.2026. Владелец выбрал вариант A из трёх макетов по образцу кнопки Apple: «применить ко всем страницам, блокам,
найди где эта функция отвечает за все кнопки».

Проблема: кнопки, вкладки, чипы и блоки цифр нарисованы плоско (DESIGN.md §5 запрещал тени у блоков на странице).

Варианты: (а) переписать стили каждого раздела; (б) одно место поверх общих классов `.btn`, `.tabs`, `.seg`, `.chip`,
`.stat`, шапки и полос кабинета.

Решение: (б). Файл `apps/web/src/app/glass-a.css` подключён в корневом layout после остальных стилей. Цвета и тень
только токенами из `design/tokens.json`: `--glass-a`, `--glass-a-hover`, `--glass-a-line`, `--glint`,
`--shadow-glass-a` (светлая и тёмная тема, контраст и печать без прозрачности). Кнопки «таблеткой»
(`--radius-full`), блик `inset` по верхнему краю, под курсором `scale(1.03)`, при нажатии `scale(0.97)`; при
`prefers-reduced-motion` без движения. Таблицы и панели сплошные: на них читают цифры.

Последствия: правило design-slop `shadow-on-page` пропускает `--shadow-glass-a` (решение владельца). Разделы,
переопределившие вид кнопок своими классами, донастраиваются по снимкам тем же токенами. Проверка
`tests/ui/glass-a.spec.ts`: 11 экранов, кнопка «таблеткой» с бликом, без прокрутки вбок, светлая и тёмная тема.
