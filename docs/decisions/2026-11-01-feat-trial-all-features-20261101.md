# Пробный месяц: доступны все функции

Дата: 01.11.2026. Владелец: «везде нужно сделать пробный период месяц, доступны все функции».

Проблема: пробный организации уже 30 дней (TRIAL_DAYS, ADR TRIAL-MONTH-20261030), но платные расширения (ИИ-продавец,
конструктор сайта филиала) открывались только строкой, которую включает главный администратор.

Варианты: (а) при регистрации заводить строки расширений; (б) считать доступ на лету из статуса организации.

Решение: (б), `effectiveExtension` в `packages/domain/src/accounts/extensions.ts`. Организация на действующем пробном
получает каждое расширение до конца своего пробного; своё расширение, действующее дольше, не трогаем. Миграции нет,
строки не создаются, раздел «Платформа» показывает настоящие строки.

Последствия: после пробного организация без оплаты и без своего расширения теряет доступ, как и вся запись
(READ_ONLY). Применяется в API ИИ-продавца, в конструкторе сайта и его воркере, в списке организаций продавца.
