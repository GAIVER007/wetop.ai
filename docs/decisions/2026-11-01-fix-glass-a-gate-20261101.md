# 2026-11-01 · fix/glass-a-gate-20261101: стекло «A» без смены размеров шапки

**Проблема.** Гейт main 5c1b83ce (release-checks 41340538387) красный после PR1021: «парящая» шапка получила
отступ сверху 8 px и рамку 1 px. Страница стала выше на 8 px («Все бизнесы», «Деньги», «Партнёры», каналы, журнал
салона перестали помещаться в один экран), шапка 89 вместо 88 (branches-ui header-two-rows). Подписи разделов на
стеклянной подложке тёмной темы цветом --muted дали контраст 4,31:1 (axe, beauty-ui positions).
Отдельно chessboard-filters §10/§41 краснел с 1.11 (до стекла): «вчера..+28» 2-го числа = ровно календарный месяц,
а месяц календарь вписывает в экран целиком, поэтому бронь +22 дня уже видна.

**Решение.** Стекло остаётся: шапка карточкой с отступом только по бокам, нижние углы скруглены, кромка кольцом тени
внутри (места не занимает), `--header-h` прежний. Подписи разделов на подложке цветом --text-2. В тесте календаря
период 32 дня (длиннее любого месяца), смысл проверки прокрутки сохранён. Сторож tests/unit/glass-a-header.test.ts.

**Последствия.** Размеры экранов как до стекла; вид «A» сохранён.
