# 01.11.2026 «Партнёры WETOP», вариант A

**Поручение владельца.** «Дизайн страницы партнёры улучши, чтобы там всё работало и дизайн чёткий». Из трёх
макетов на вымышленных данных выбран A («давай а»).

**Что было.** Высокие полупустые итоги, одна кнопка, нет поиска и фильтров, выплат партнёрам не видно, ошибочную
выплату нельзя отменить, клиента партнёру назначали только в карточке клиента.

**Решение.**
1. Итоги одним рядом: партнёров, клиентов привели, доход, начислено, к выплате.
2. Поиск (имя, телефон, почта, клиент) и фильтры «стекло» Работают / К выплате / Все через адрес (`?show=`, `?q=`).
3. Таблица партнёров одной строкой: «Выплатить», «Клиенты», «Изменить».
4. Справа последние 8 выплат с «Отменить» (тот же `POST /platform/expenses/:id/void`) и «Как считается».
5. Окно «Клиенты»: назначить свободного клиента и убрать своего (тот же `PUT /platform/clients/:id/partner`).
6. API `GET /platform/partners` отдаёт ещё `payouts` (расходы «Партнёрам», чтение) и `allClients`.

**Последствия.** Модель данных и миграции не меняются, правила начисления те же (DATA_MODEL §63.2). Страница
целиком в 1440×900, проверено UI-тестом.
