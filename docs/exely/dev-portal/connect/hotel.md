## Get started​

To work with Exely Connect, you need authorization credentials. To obtain them:

Create a connection and select available APIs.

Copy the generated `client_id` and `client_secret`.

To learn how to create an API connection, see the article.

## Work with API​

You can offer your services to properties using Exely Connect. In this case:

The property creates a separate API connection for you in the Exely extranet.

The property provides you with the API connection credentials.

You use API on behalf of the property.

Please note: When using Exely Connect, follow the best practices
and comply with authorization limits.
