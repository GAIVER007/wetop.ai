Exely Connect is a set of application programming interfaces (APIs) that provide access to components of Exely Suite.

Third-party systems (partners) use APIs to integrate with and automate property's data and services.

Exely Connect combines multiple separate APIs, each designed for specific functionality and use cases.

Content API allows you to retrieve photos and descriptions of the property, room types, rate plans, and services

Reference Data API provides reference data: corporate clients, payment methods, property amenity types, and property kinds

Read Reservation API allows you to retrieve booking details from Exely Booking Engine, Exely Channel Manager, and Exely PMS

Search API provides searches for accommodation options with the lowest prices across all available properties (up to 200), as well as offers for a specific property available in Exely Booking Engine

PMS API provides information about bookings, guest profiles, finances, and analytics for integration with Exely PMS

PMS Analytics API provides daily occupancy and revenue statistics for the property

PMS Integration Storage API allows you to retrieve room availability, availability blocks, and bookings without guests’ details from external PMS

# Exely Connect capabilities

APIs allow you to:

retrieve real-time data about bookings, rooms, guests, and other property information

generate reports based on this data

# How Exely Connect works

If you need to access data, for example, about a property or bookings, the property grants you access
in the "API connections" section of the Exely account. You are issued credentials and access rights
for a specific API (for example, Content API), after which you can send requests and retrieve the required information.
