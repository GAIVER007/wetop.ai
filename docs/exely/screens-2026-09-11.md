# Экраны Exely: что где лежит и что там видно

Снято 11.09.2026 из кабинета объекта (владелец вошёл в своём Chrome). Файлов-скриншотов нет: инструмент
браузера не сохраняет снимки на диск, а на экранах имена гостей — поэтому ниже описание структуры и
фактов без персональных данных. Этого достаточно, чтобы сравнивать функции и не гадать про Exely.

Адрес кабинета: `secure.exely.com/secure/`. Левое меню: Помощник · Управление номерами · Настройки
гостиницы · Управление отелем · Менеджер каналов · Аналитика · Репутация · Маркетинг · Документооборот ·
Отчёты · Сравнение цен · Модуль бронирования. Внизу — сопровождающий менеджер Exely с контактами.

## Управление отелем

| Экран | Что видно | Для нас |
|---|---|---|
| **Шахматка броней** (`#/WebPmsReservations`) | Строки — единицы, сгруппированы по категориям с подзаголовком «Без номера» для броней без ячейки; в шапке категории по дням число свободных. Колонки — даты, режимы «День / Месяц». Полоска брони: фамилия и инициал, канал; у части — сумма долга красным. Фильтры: статус, способ гарантии, источник, теги; поиск по номеру брони, гостю, email. Кнопки «Создать бронь», «Создать групповую бронь». Клик по полоске открывает карточку справа | Наша шахматка повторяет строки-единицы и клетки-даты. У Exely есть строка «Без номера» — мы показываем такие брони отдельно списком, стоит добавить строку на сетку |
| **Карточка брони** (правая панель) | Статус, № брони, № подтверждения в канале, компания-агент (ChannelManager: канал), заказчик, телефон, email, комментарий агента; заезд и выезд с временем, дата бронирования, ночей, тариф, категория; взрослые/дети, гости; источник, способ гарантии; сумма за проживание, за услуги, итого, оплачено, к оплате. Кнопки внизу: «Редактировать» и иконки действий (заселить, оплата, печать и т. п.) | Совпадает с нашей карточкой; у нас нет комментария агента канала — стоит показывать `notes` из ревизии Channex |
| **Служба приёма** | Сводка на сегодня: загрузка (занято 75, свободно 13 из 88 на 11.09), гости сегодня (заезды 27 / горящие 0, выезды 26, проживания 70, незаезды 14), состояние номеров (грязно 87, убрано 0, проверено 0, ремонт 1). Вкладки: Заезды · Выезды · Проживания · Группы. Таблица заезда: № брони, заказчик, число гостей, номер комнаты, время заезда, категория, баланс, теги, заметки, комментарий гостя, статус («Опоздание»), действие «Заселить гостей». Экспорт в XLSX | Это наш экран «Сегодня». Статус «Опоздание» = гость не заселён после расчётного часа (Q-097) |
| **Профили гостей** | Плитки: Дни рождения, VIP-гости, Постоянные гости, Новые за сегодня, Похожие профили (дубли), Поиск, Депозит | У нас карточка гостя и история; дубли и «постоянные» — не в MVP |
| **Номерной фонд** | Вкладки «Корпуса и этажи», «Номерной фонд». Таблица: № комнаты, корпус («Основной»), этаж (у всех 2), категория, комментарий. Нумерация 1…88, койки как отдельные строки | Подтверждает: один корпус, один этаж, 88 строк |
| **Обслуживание номеров** | Сводка: свободно 29, занято 59 (67 %), ремонт 0; грязно 87, убрано 0, проверено 1. Таблица по единице: занятость («Занят (4/13)» — день проживания из общего числа), число взрослых/детей, когда освободится, кем будет заселён, ремонт, статус уборки | Наши статусы уборки те же (грязно/убрано/проверено); столбец «день N из M» полезен для стойки |
| **Финансовый учёт** | Период, сальдо кассы (1 222 601,71 ₸ на 12.09), приход 19 526 665,71 ₸ и расход 18 304 064 ₸ за период 12.08–12.09, график по месяцам; операции: «Добавить приход / расход», экспорт | Это касса, не счёт гостя. Наш отчёт «Деньги за период» — аналог приходов по способам |
| **Статистика и отчёты** / **Отчёты** | Отчёты общего назначения: Заезды, Выезды, Занятые номера, Список гостей, Платежи, Способы оплаты, Депозит, Допуслуги (сводный и детальный), Отчёт по питанию, Сводная статистика, Журнал активности пользователей. Ниже «Статистические отчёты» | «Занятые номера» и «Сводная статистика» — источники для сверки загрузки; журнал активности = наш audit |

## Управление номерами

| Экран | Что видно |
|---|---|
| **Категории номеров** | 5 категорий; у каждой сокращённое название, тарифов 6, фото «НЕТ», основных мест 1 (двухместная 2), доп. мест нет. Предупреждение: без 4 фото номера онлайн-продажи хуже |
| **Доступность номеров** | «Основной блок доступности», вкладки Доступность / Календарь, период, легенда: доступность изменена вручную, overbooking, доступность исчерпана, бронь отменена; групповая операция. Подраздел «Расширенное управление доступностью» |
| **Тарифы** | 6 тарифов: Базовый (источники Exely Booking Engine, Exely PMS), Тариф для ОТА +35 % (ChM · 8), Тариф для ОТА в USD +35 % (ChM), Стандартный тариф для Островка, Невозвратный Островок −10 %, B2B Островок (ChM · 1). Наличие цен 30.05.2026 → 31.12.2027, ограничений нет, способы оплаты «Нет». Кнопки «Создать основной / наследуемый тариф», «Обновить ограничения», «Закрыть/Открыть продажи» |
| **Сезоны** | Только «Сезон по умолчанию», сезонов не заведено — подтверждает наше решение не заводить сезоны |

## Настройки гостиницы

| Экран | Что видно | Для нас |
|---|---|---|
| **Ранний заезд / Поздний выезд → Основное правило** | Расчётный час заезда 14:00, выезда 12:00. Ранний заезд: 00:00–05:59 — 100 % цены ночи, 06:00–11:59 — 50 %, 12:00–13:59 не задано (бесплатно); «выделять доступность: да», доплата входит в предоплату. Поздний выезд: 12:01–17:59 — 50 %, 18:00–23:59 — 100 %; «выделять доступность: да», в предоплату не входит. Привязано к 6 тарифам | Перенесено в PMS как правило по времени (ADR-021). Блокировка соседней ночи — следующий шаг |
| **Аннуляция и штрафы** | Основное правило (5 тарифов): стоимость первых суток, 1; Невозвратное правило аннуляции (1 тариф): стоимость первых суток, 1. Кнопка «Приоритеты правил аннуляции» | Совпадает с нашей политикой по тарифам |
| **Услуги** | 9 услуг: Стирка (1 загрузка) 500 ₸, минибар ×8 по 700 ₸; источник продаж Exely PMS, тарифы «все», начисление «за использование» | Импортированы все 9 |
| Остальное в разделе | Общие настройки, Банковские реквизиты, Способы оплаты, Комментарии для гостей, Трансферы, Описание/фото/удобства, Переводы текстов, Промокоды, Правила округления, Подключения API | Способы оплаты и правила округления — посмотреть перед параллельным днём |

## Что не снято

Диалоги внутри карточки брони (редактирование, аннуляция, оплата, возврат), создание брони, блокировки
на шахматке, отчёт по загрузке в деталях, настройки пользователей. Они не блокируют работу: правила
аннуляции, услуги и ранний заезд сняты из настроек, а поведение карточки известно из API.
