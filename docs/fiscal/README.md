Снято 10.09.2026 из открытых источников.

## Что нужно от владельца

1. Выбор провайдера (Q-050): у кого сейчас касса объекта (OBJECT.md: приход августа 17,6 млн ₸ через кассу Exely?) —
   миграция чеков и отчётов зависит от этого.
2. Доступ в тестовый кабинет выбранного провайдера (регистрирует владелец, ключ — только в `.env`).
3. Скачанную документацию (Postman/спецификацию) положить в `docs/fiscal/<provider>/` — после этого пишется адаптер.

## Как это ляжет в PMS

`FiscalProvider.issueReceipt(payment)` вызывается при платеже способами CASH / CARD_TERMINAL / KASPI / HALYK
(DATA_MODEL §9); номер чека сохраняется в `Payment.external_reference`; при ошибке провайдера платёж остаётся
в PMS со статусом «чек не пробит» и попадает в журнал — деньги не теряются, чек допробивается повтором.
