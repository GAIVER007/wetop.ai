# Отправка писем: Resend HTTP API

Нужна для двух писем учётных записей (DATA_MODEL §13 шаг 1, ADR-046, решение владельца 15.09.2026):

1. **приглашение** — «вас добавили в WETOP, задайте себе пароль» со одноразовой ссылкой;
2. **сброс пароля** — та же одноразовая ссылка по просьбе сотрудника.

Позже той же дорогой пойдут письма гостям о брони с сайта (Q-115).

> **Чего здесь нет и почему.** Живой отправки не было ни одной: ключа `RESEND_API_KEY` в проекте нет, его
> вписывает владелец (`SECURITY.md` §3), а из среды агента исходящий трафик к внешним сервисам закрыт
> политикой. Описание ниже составлено по известному виду API и проверено только подставным `fetch` в тестах.
> **Перед первой живой отправкой сверьте поля с resend.com/docs** — если они разошлись, правка нужна в одном
> файле: `packages/integrations/src/mail/resend.ts`.

## Запрос

```
POST https://api.resend.com/emails
Authorization: Bearer <RESEND_API_KEY>
Content-Type: application/json

{
  "from": "WETOP <no-reply@wetop.ai>",
  "to": ["admin@example.kz"],
  "subject": "WETOP: задайте пароль",
  "text": "…"
}
```

- `from` — адрес на подтверждённом домене. Домен `wetop.ai` подтверждается в кабинете Resend записями DNS
  (SPF и DKIM); DNS домена уже в Cloudflare, записи добавляются там же.
- `to` — список адресов; мы всегда отправляем одному.
- `text` — письма только текстом. HTML не отправляем: письмо короткое, а текст не ломается ни в одном
  клиенте и не попадает в спам из-за вёрстки.

## Ответ

- `200` (или `201`) и тело `{"id":"…"}` — принято к отправке. Идентификатор пишем в журнал: он не ПД.
- `4xx` — тело `{"name":"validation_error","message":"…"}`. Сообщение кладём в ошибку **без адреса
  получателя**: почта сотрудника — персональные данные (ADR-018).
- `429` — превышен лимит; повтор не делаем автоматически, письмо отправляется заново по действию человека.
- `5xx` — на стороне сервиса.

## Что письмо не должно содержать

- пароля — ни нового, ни старого: в письме только ссылка с одноразовым токеном;
- данных гостей, сумм и номеров броней;
- срока жизни токена длиннее суток — ссылка живёт 24 часа и работает один раз.

## Переменные окружения

| Имя | Зачем |
|---|---|
| `RESEND_API_KEY` | ключ кабинета Resend. Пусто — отправки нет: приглашение печатает ссылку в консоль CLI, а API отвечает 503 «отправка писем не настроена» |
| `MAIL_FROM` | адрес отправителя, по умолчанию `WETOP <no-reply@wetop.ai>` |
| `PUBLIC_APP_URL` | адрес стойки для ссылки в письме, по умолчанию `https://app.wetop.ai` |
