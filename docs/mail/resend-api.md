# Resend: отправка письма — выдержка из документации

Снято с `resend.com/docs` 16.09.2026. Файл нужен по AGENTS.md §5: код интеграции пишется
только по документации, положенной в `/docs`. Здесь ровно то, что использует наш клиент;
остальное у Resend есть, но нам не нужно.

## Адрес и доступ

| | |
|---|---|
| База | `https://api.resend.com` |
| Отправка письма | `POST /emails` |
| Доступ | заголовок `Authorization: Bearer re_xxxxxxxx` |

Ключ живёт только в переменной окружения `MAIL_API_KEY` и не попадает ни в код, ни в журнал,
ни в текст ошибки (SECURITY.md §3, AGENTS.md §7).

## Тело запроса

Обязательные поля:

| Поле | Тип | Что это |
|---|---|---|
| `from` | строка | Отправитель. Допускает вид `Имя <адрес>` |
| `to` | строка или массив | Получатели, не больше 50 адресов |
| `subject` | строка | Тема |

Из необязательных нам нужно одно:

| Поле | Тип | Что это |
|---|---|---|
| `text` | строка | Простой текст письма |

Поле `html` не отправляем: письмо с кодом должно читаться везде и нигде не выглядеть
подделкой (`login-code-letter.ts`). Если прислать только `html`, Resend сам соберёт `text`;
нам это не нужно, мы шлём текст сразу.

Ещё есть необязательный заголовок `Idempotency-Key`: одинаковый ключ в течение суток не
создаёт второго письма. Нам он пригодится, чтобы повтор при сетевом сбое не слал человеку
два кода.

## Ответ

Успех — код 200 и тело:

```json
{ "id": "49a3999c-0ce1-4ea6-ab68-afcd6dc2e794" }
```

## Ошибки

Тело ошибки содержит `name` и `message`. Коды, которые нас касаются:

| Код | `name` | Повторять? |
|---|---|---|
| 400 | `validation_error` | нет, это наша ошибка в запросе |
| 401 | `missing_api_key`, `restricted_api_key` | нет, ключ не тот или без прав |
| 403 | `invalid_permission`, `suspended_api_key` | нет |
| 422 | `missing_required_field` | нет |
| 429 | `rate_limit_exceeded`, `daily_quota_exceeded` | **да** |
| 500 | `application_error` | **да** |
| 503 | `service_unavailable` | **да** |

## Ограничение частоты

По умолчанию **10 запросов в секунду на команду**, общий на все ключи. Превышение — код 429.

Для нас это не узкое место: наши собственные пределы жёстче. Доменный слой разрешает 5 кодов
в час на адрес и 20 в час на IP (`packages/domain/src/accounts/login-code.ts`), так что до
десяти запросов в секунду мы дойдём только при настоящем наплыве, и тогда 429 надо будет
не обходить, а разбираться, что происходит.

## Чего в этой выдержке нет

Вложения, шаблоны, React-компоненты, рассылки, темы подписок, отложенная отправка, теги.
Всё это в Resend есть и нам не нужно. Если понадобится — дописать сюда из документации,
а не угадывать по памяти.
