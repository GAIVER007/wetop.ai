# Формы сайта: запись к мастеру, бронь стола, заявка без слота (SITE-4, SITE-5)

Статус: **15.10.2026**, срезы SITE-3/4/5 плана `plans/site-seo-flow-2026-10-15.md`, ADR-185. Модель: `DATA_MODEL.md` §11
(`tracked_sites.location_id`), §19 (`appointments.source`, ключ создания), §28 (`WEBSITE` у брони стола), §46
(`site_leads`). Код: `apps/api/src/site-forms/`, разбор форм `packages/domain/src/web-booking/site-forms.ts`, окна
`packages/domain/src/beauty/slots.ts`. Тесты: `tests/integration/site-forms.test.ts`.

Бронь номеров гостиницы остаётся `POST /w/book` (`site-publication-v0.md`, срез 9). Здесь формы, которые сайт салона,
ресторана и любой сайт без слота шлют в API; результат сразу встаёт в календарь своего направления.

## 1. Общее для всех публичных форм

- Адрес API тот же, что у `/w/book` (`publicApiUrl` рантайма сайта). Входа нет (`@Public`, SECURITY.md §11).
- `k`: публичный ключ `TrackedSite` (`pms_` + 12 hex). Сайт должен быть `ACTIVE`. Филиал, организация и направление берутся
  из строки сайта, никогда из запроса.
- Домен: `Origin` (или `Referer`) запроса один из `hosts` сайта или его поддомен; иначе **403** `запрос не с домена сайта`.
  CORS для `/w/beauty/*`, `/w/food/*`, `/w/lead` отдаётся любому действующему сайту (`WidgetCorsMiddleware`).
- Цепочка: филиал и бизнес `ACTIVE`, организация бизнеса совпадает с организацией сайта и может писать. Запись к мастеру
  только у сайта салона (`BEAUTY`), бронь стола только у сайта ресторана (`FOOD_SERVICE`); заявку принимает сайт любого
  направления. Иначе **404** `запись с сайта для этого филиала не подключена`. Неизвестный или приостановленный ключ:
  **404** `сайт не найден или выключен`.
- `requestKey`: UUID v4, его делает браузер один раз на отправку формы. Повтор с тем же ключом и тем же содержимым отдаёт
  тот же результат (тот же код 201) без новой записи, без проверки Turnstile и без места в лимите. Тот же ключ с другим
  содержимым: **409**. Одновременная двойная отправка даёт одну запись.
- `turnstileToken`: токен Cloudflare Turnstile, когда проверка включена (`WEB_BOOKING_TURNSTILE_REQUIRED`, тот же режим и
  ключи, что у `/w/book`, публичный ключ отдаёт `GET /w/config`). Нет токена **400**, неверный **403**, устарел **403**,
  Cloudflare недоступен **503**. Проверяется после разбора формы и раннего повтора.
- `website`: ловушка для ботов, скрытое поле; непустое значение **400** `honeypot`.
- `name` 1–100 символов; `phone` 10–15 цифр, нормализуется (`8…`/`7…` из 11 цифр в `+7…`); `comment` до 1000 символов,
  контакты в нём маскируются, пока база не в РК (ADR-074).
- Лимиты: **5** записей, броней и заявок вместе в час с одного адреса; **30** в час на сайт на все формы вместе (окно в
  памяти процесса) и стойкий предел **30** в час по базе на каждый вид формы (считаются сами записи, перезапуск API его не
  обнуляет); **60** запросов окон в минуту с адреса. Превышение **429**. Повтор и отказ записи место не тратят.
- Ошибки в формате Nest: `{ "statusCode": 409, "message": "Это время уже занято, выберите другое", "error": "Conflict" }`.
  Текст `message` можно показать посетителю.
- Уведомление администратору: отдельного канала (Telegram, WhatsApp, почта филиала) у филиала в системе нет; запись и
  бронь видны в календаре стойки, заявка во «Входящих» (`GET /marketing/site/leads`, счётчик `newCount`). Канал
  уведомлений и подтверждение клиенту: следующий срез.

## 2. Салон: свободные окна

`GET /w/beauty/slots?k=<ключ>&service=<uuid услуги>&date=YYYY-MM-DD[&employee=<uuid мастера>]`

Окна по тому же правилу, что у стойки: запись целиком в одном интервале графика мастера в этом филиале, не в день
отсутствия, не пересекает его записи `BOOKED`/`CONFIRMED`/`DONE` (в любом филиале). Шаг 15 минут от начала интервала,
прошедшее время не предлагается. `date` в поясе филиала. Без `employee`: все мастера филиала, оказывающие услугу.

**200**
```json
{
  "date": "2026-10-19",
  "timezone": "Asia/Almaty",
  "service": { "id": "…", "name": "Маникюр", "durationMinutes": 60, "priceMinor": "800000", "currency": "KZT" },
  "employees": [{ "id": "…", "name": "Алия" }, { "id": "…", "name": "Мадина" }],
  "slots": [
    { "startsAt": "2026-10-19T04:00:00.000Z", "endsAt": "2026-10-19T05:00:00.000Z", "time": "09:00", "employeeIds": ["…", "…"] }
  ]
}
```
Услуга не включена в филиале или нет цены в валюте филиала **404**; мастер не оказывает услугу в филиале **404**.

## 3. Салон: запись к мастеру

`POST /w/beauty/book`, `Content-Type: application/json`
```json
{
  "k": "pms_0123456789ab",
  "serviceId": "uuid услуги",
  "employeeId": "uuid мастера или null (любой свободный)",
  "startsAt": "2026-10-19T10:00:00+05:00",
  "name": "Айгерим",
  "phone": "+7 701 000 00 11",
  "comment": "необязательно",
  "requestKey": "uuid v4",
  "turnstileToken": "токен Turnstile",
  "website": ""
}
```
Запись встаёт в календарь мастера: статус `BOOKED` («Записан»), источник `WEBSITE`, цена снимком по прайсу филиала, автор
пуст. Клиент находится по телефону в организации или заводится (тот же путь, что у стойки); бизнес салона его видит.
«Любой мастер»: первый по имени, кто оказывает услугу, работает в это время и свободен.

**201**
```json
{
  "appointmentId": "…",
  "status": "BOOKED",
  "startsAt": "2026-10-19T05:00:00.000Z",
  "endsAt": "2026-10-19T06:00:00.000Z",
  "service": { "id": "…", "name": "Маникюр" },
  "employee": { "id": "…", "name": "Алия" },
  "priceMinor": "800000",
  "currency": "KZT"
}
```
**409**: время занято (`Это время уже занято, выберите другое`), мастер не работает в это время или в отсутствии, время
прошло, клиент с этим телефоном в архиве, тот же `requestKey` с другим содержимым. **404**: мастер или услуга не этого
филиала.

## 4. Ресторан: бронь стола

`POST /w/food/reserve`
```json
{
  "k": "pms_0123456789ab",
  "date": "2026-10-19",
  "time": "19:00",
  "partySize": 4,
  "name": "Бауыржан",
  "phone": "87010000022",
  "comment": "необязательно",
  "requestKey": "uuid v4",
  "turnstileToken": "токен Turnstile",
  "website": ""
}
```
`date` и `time` в поясе филиала; `partySize` 1–50. Бронь стола: статус `BOOKED` («Забронирован»), источник `WEBSITE`, стол
не назначается (сажает стойка), конец по длительности периода обслуживания, в который бронь помещается целиком. Правила
брони филиала (§43): закрытый день, горизонт, предел гостей.

**201**
```json
{
  "reservationId": "…",
  "status": "BOOKED",
  "date": "2026-10-19",
  "time": "19:00",
  "startsAt": "2026-10-19T14:00:00.000Z",
  "endsAt": "2026-10-19T16:00:00.000Z",
  "partySize": 4
}
```
**409**: нет периода обслуживания на это время (`В это время ресторан не принимает брони`), закрытый день, дальше
горизонта, больше гостей, чем разрешено, время прошло, тот же `requestKey` с другим содержимым. **400**: такого местного
времени нет (перевод часов).

## 5. Заявка без слота («Перезвоните мне»)

`POST /w/lead`
```json
{
  "k": "pms_0123456789ab",
  "name": "Ержан",
  "phone": "8 (701) 000-00-11",
  "comment": "Перезвоните после 18:00",
  "kind": "CALLBACK",
  "source": { "utm_source": "instagram", "utm_campaign": "october", "page": "/rooms" },
  "requestKey": "uuid v4",
  "turnstileToken": "токен Turnstile",
  "website": ""
}
```
`kind`: `CALLBACK` (умолчание) или `OTHER`. `source`: до 10 меток, ключи `[a-z][a-z0-9_]{0,39}`, значения строки до 300
символов. Сайт любого направления.

**201**
```json
{ "leadId": "…", "status": "NEW", "createdAt": "2026-10-15T08:00:00.000Z" }
```

## 6. Заявки во «Входящих» (стойка)

Под входом, указатель филиала `X-Wetop-Scope: business=<id>;location=<id>`, право `dialogs` (владелец, управляющий,
администратор; право организационное: сотруднику с назначениями только на филиалы закрыто, как диалоги ИИ-продавца).
Лицензия конструктора не нужна. Направление филиала: гостиница, салон, ресторан.

`GET /marketing/site/leads?status=NEW&limit=50&cursor=<id>`

**200**
```json
{
  "items": [
    {
      "id": "…",
      "name": "Ержан",
      "phone": "+77010000011",
      "comment": "Перезвоните после 18:00",
      "kind": "CALLBACK",
      "status": "NEW",
      "source": { "utm_source": "instagram", "page": "/rooms" },
      "site": { "id": "…", "name": "Сайт гостиницы" },
      "createdAt": "2026-10-15T08:00:00.000Z",
      "updatedAt": "2026-10-15T08:00:00.000Z"
    }
  ],
  "nextCursor": null,
  "newCount": 1
}
```
Новые сверху; `status` фильтр необязателен; `limit` 1–100.

`PATCH /marketing/site/leads/:id` с телом `{ "status": "IN_PROGRESS" }` (`NEW`, `IN_PROGRESS`, `DONE`, `SPAM`): **200** та же
форма, что элемент списка. Заявка другого филиала или организации **404**; лишние поля и неизвестный статус **400**.
Смена пишет журнал `site.lead.status` (было и стало).

## 7. Что сделано в SITE-3 для конструктора

- `tracked_sites.location_id` (владелец сайта счётчика), `property_id` необязательный; публикация заводит сайт счётчика
  по филиалу (`createTrackedSite`), канонический сайт брони и выбор источника брони по филиалу.
- Лицензия конструктора (`site_builder_entitlements`) и платформа (`/platform/organizations/:id/site-builder`) для
  филиалов любого направления. `siteScope` пускает гостиницу, салон и ресторан.
- Виджет брони номеров (`integrations.booking.mode = WETOP_WIDGET`) и категории номеров в версии требуют объекта
  гостиницы: у салона и ресторана публикация такой версии **409** `NO_PROPERTY`. Рантайм сайтов отдаёт опубликованный
  сайт салона и ресторана без фактов категорий.
- Не сделано здесь (другие срезы): содержимое SiteSpec, бриф и генерация для салона и ресторана (SITE-2), экран стойки.
