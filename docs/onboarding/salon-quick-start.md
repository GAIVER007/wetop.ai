# Первичная настройка салона: короткая анкета

Версия 1, 24.10.2026. Таблица: `docs/onboarding/salon-quick-start.xlsx` (4 вкладки). Это минимум, чтобы салон в
первый день начал записывать клиентов. Всё остальное (бонусы, напоминания, ИИ-продавец, сайт, склад, клиентская
база) донастраиваем потом по полной анкете `salon-onboarding-checklist.md`.

## Что спросить у владельца

**Салон**
1. Название салона.
2. Город и адрес.
3. Телефон для клиентов.
4. Часы работы по дням.
5. Как принимаете оплату: наличные, Kaspi, терминал, перевод.

**Администратор-кассир**
6. ФИО и почта для входа.
7. Может ли он возвращать деньги клиенту (да/нет).

**Мастера** (на каждого)
8. ФИО.
9. Почта для входа, если мастер будет сам смотреть свои записи.
10. Телефон.
11. Какие услуги делает.
12. Дни и часы работы.

**Услуги** (на каждую)
13. Категория, название, сколько длится, цена.

**Доп. услуги**
14. Напитки, закуски, товары: бесплатно или за деньги, цена.

## Как вносим (около часа)

1. Настройка бизнеса: название, страна, валюта, часовой пояс.
2. Филиал: адрес, телефон, часы работы.
3. Услуги: категория, название, длительность, цена.
4. Мастера: ФИО, телефон, услуги, график.
5. Способы оплаты.
6. Приглашения на почту администратору и мастерам.
7. Пробная запись: создать, оплатить, отменить.

## Правила

- У каждого человека своя почта для входа.
- Пароли, паспорта и номера карт не собираем: каждый входит сам по приглашению.
- Фото и данные мастеров публикуем только с их согласия.
