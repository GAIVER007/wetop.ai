# План: страны в кабинете руководителя WETOP (29.10.2026)

Поручение владельца 29.10.2026 (голосом): «чтобы отображалось гео, с какой страны заходят: Казахстан столько-то
посетителей, столько-то регистраций; и какая страна сколько оплачивает, с какой страны доход». Раздел кабинета
главного администратора (`/platform/cabinet`).

## 1. Откуда берём страну

| Число | Источник страны | Есть сейчас |
|---|---|---|
| Посетители wetop.ai | страна по адресу посетителя, которую Cloudflare уже определяет на входе (`CF-IPCountry`, двухбуквенный код) | нет: приёмник её не сохраняет |
| Регистрации | `organizations.country_code`: страна телефона из окна регистрации | да, с 10.10.2026 |
| Платящие, доход, LTV, MRR | та же `organizations.country_code` клиента | да |
| Клиенты без страны (заведены до 10.10 или платформой) | «Страна не указана»; главный администратор может указать в карточке клиента | частично |

IP посетителя не сохраняется (как сейчас): только двухбуквенный код страны. `XX` и `T1` (Tor) идут в «не
определена». Без cookies, персональных данных нет.

## 2. Данные (DATA_MODEL §11, нужно «да» владельца)

- `web_sessions.country` `VARCHAR(2) NULL`: код страны первого запроса сессии. Миграция 169 (номер уточнить при
  слиянии), без бэкфилла: прошлые визиты без страны, «не определена».
- Приёмник `/a/hit` берёт заголовок `CF-IPCountry` только если запрос пришёл через Cloudflare (туннель
  `api.wetop.ai`); иначе `NULL`. Подделка заголовка снаружи Cloudflare невозможна: туннель затирает его.
- Больше ничего: страна клиента уже есть.

## 3. Экраны

1. **«Сайт wetop.ai»** (уже сделан, PR «Сайт wetop.ai»): таблица «Страны»: посетители, открыли регистрацию,
   зарегистрировались, переход в процентах. Сверху 5 стран, остальные «Другие».
2. **Новый раздел «Страны»** в меню кабинета, месяц ‹ ›, одна строка на страну:
   Посетители · Регистрации · Пробные · Первая оплата · Платят сейчас · Доход месяца (USD) · MRR · Средний LTV ·
   переход посетитель → регистрация → оплата. Сортировка по доходу. Итог снизу.
3. **Главная кабинета**: справа под «Сроками» блок «Топ-3 страны по доходу» со ссылкой на раздел.
4. **Карточка клиента**: флаг и страна; если пусто, поле «Страна» (то же окно доступа, пишется в журнал).

Регистрации по стране: по стране телефона организации, созданной в месяце. Посетители и регистрации считаются по
разным источникам (адрес посетителя и телефон клиента), поэтому переход «посетитель → регистрация» по стране
приблизительный; на экране подпись «по стране телефона».

## 4. Порядок срезов

1. Регистрации, платящие, доход, MRR, LTV по стране клиента: без миграции, сразу.
2. Страна посетителя: миграция `web_sessions.country` (после «да»), приёмник, таблица стран в «Сайт wetop.ai» и
   столбец «Посетители» в «Странах».
3. Страна в карточке клиента для старых клиентов.

Каждый срез: тест сначала красный, снимки экрана, отдельный PR.
