# План: кабинет руководителя WETOP, полная версия (29.10.2026)

Поручение владельца 29.10.2026: «полностью проработать личный кабинет руководителя всей компании WETOP: вся аналитика
движения средств, подписки, количество клиентов; где выключать и выдавать доступ; проверка подписок автоматически;
пользователи, посетители сайта, регистрации, пробные, платные, конверсии посетитель → регистрация → пробный → оплата →
продление; LTV, сколько клиент с нами».

Уже есть (срезы 1–2, #916, #918): главная (клиенты, путь клиента, сроки), «Деньги» (доход, расходы, прибыль месяца),
«Подписки» (тарифы, подписка и «оплачено до» каждого клиента), «Команда WETOP». Вход: учётка с отметкой
главного администратора.

## 1. Что видит руководитель (определения чисел)

Период: месяц стрелками ‹ › (как в аналитике стойки), сравнение с прошлым месяцем.

| Число | Откуда | Как считается |
|---|---|---|
| Посетители wetop.ai | счётчик WETOP на своём сайте (наш `pms.js`, сайт своей организации в `tracked_sites`) | уникальные посетители за месяц |
| Регистрации | `users.created_at` | новые учётки за месяц (почта подтверждена) |
| Пробные | журнал `organization.created` | организации, начавшие пробный 7 дней за месяц |
| Платные | `platform_payments` | клиенты с первой оплатой в месяце |
| Продления | `platform_payments` | вторая и следующие оплаты клиента в месяце |
| Конверсии | из строк выше, по когорте месяца | посетитель → регистрация → пробный → первая оплата → продление, в процентах |
| Клиенты сейчас | `organizations` | пробный, платят, «только чтение» (не оплатили), приостановлены |
| MRR | `platform_subscriptions` | сумма месячных цен клиентов, у которых «оплачено до» не прошло |
| LTV клиента | `platform_payments` | сколько клиент заплатил за всё время (без отменённых оплат) |
| Средний LTV | | средний LTV платящих клиентов |
| Сколько с нами | `organizations.created_at` | дней от регистрации; у ушедших до ухода |
| Отток | журнал статусов | клиенты, ушедшие в «только чтение» или приостановку за месяц |
| Пользователи | `memberships` + `users.last_login_at` | всего людей у клиентов и сколько входили за 7 дней |

Деньги в USD (решение владельца 28.10). Брони, гости и выручка самих клиентов не показываются: только счёт строк.

## 2. Экраны

1. **Главная**: 4 KPI (MRR, клиенты платят, пробные, средний LTV), воронка месяца с конверсиями, график дохода по
   месяцам, справа «Сроки» (пробный кончается, ждёт оплаты).
2. **Клиенты**: одна строка на клиента: статус, тариф, «оплачено до», LTV, сколько с нами, последний вход, работа за
   30 дней (счёт броней и записей). Фильтры: все, пробный, платят, не оплатили, ушли.
3. **Карточка клиента** (окно): кто владелец, филиалы, люди, оплаты, журнал. **Доступ**: продлить пробный, «оплата
   получена» (продлевает «оплачено до»), «только чтение», приостановить, вернуть; расширения: ИИ-продавец, конструктор
   сайта (то же окно, что в «Сайт и SEO»). Каждое действие пишется в журнал.
4. **Деньги**, **Подписки**, **Команда WETOP**: уже есть, остаются.

## 3. Автоматическая проверка подписок

Ночная задача API (часовой пояс платформы), без кнопок:
- пробный кончился и оплаты нет → «только чтение» (данные клиента не трогаются, вход остаётся);
- «оплачено до» прошло больше 3 дней назад → «только чтение»;
- оплата получена → снова «работает»;
- за 7 дней и за 1 день до конца клиенту письмо и уведомление в стойке; руководителю строка в «Сроках».
Сейчас «пробный кончился» уже закрывает запись на лету (`writeBlocked`), задача делает статус видимым и считаемым.
