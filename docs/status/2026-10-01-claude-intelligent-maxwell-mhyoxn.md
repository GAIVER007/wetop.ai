## Что осталось после слияния с `main` 15.10.2026

Ветка отстала от `main` на ~1500 коммитов, за это время `main` сам закрыл большую часть PR:

- **WET-02 (гости групповой брони):** `main` уже считает `гостей = места x гостей на место` в сводке и всегда
  подписывает поле «Гостей на место» (`f922d7f74`). Из PR остались: вынос `summarize` в чистый модуль
  `reservations/new/summary.ts` с юнит-тестом, подсказка группы «всего N гостей», UI-спек
  `tests/ui/booking-group-guests.spec.ts` (подпись «Гостей на место» теперь всегда, как на `main`).
- **WET-04 (выключение тарифа):** снят. Раздел «Тарифы и цены» убран решением владельца (ADR-150, 06.10.2026),
  экран `/rates/plans` и кнопка не существуют; производный тариф `main` уже выключает через
  `PATCH /rates/plans/:code/derived { active }` с проверкой броней и сопоставлений каналов (`f922d7f74`,
  ADR-QA-20261004). Вторая ручка `PATCH /rates/plans/:code { active }` с другими правилами
  блокировки дала бы два пути к одному полю, поэтому не перенесена. Удалены `plans-table.tsx`, `actions.ts`,
  `tests/ui/rate-plans.spec.ts`, `tests/integration/rate-plan-active.test.ts`; ADR-146 из этого PR отозван
  (номер занят дважды на `main` другими решениями); Q-270 снят, Q-269 занят другим вопросом.
- **Очистка тестовых записей:** `scripts/ops/retire-test-entities.mjs` сохранён без изменений. На схеме `main`
  проверен на локальной PostgreSQL: dry-run по умолчанию (ROLLBACK, журнал 0), отказ без аргументов, отказ на
  неизвестном коде, отказ на месте с размещениями и на тарифе с бронями, `--apply` пишет `active=false` и строку
  `qa.retireTestEntity` в `audit_logs`, повтор отказывает «уже выключено». Скрипт использует `DIRECT_URL` или
  `DATABASE_URL` из окружения и сам базу не выбирает: запуск на рабочей базе делает владелец по AGENTS.md §9.
- **Спеки под компактную форму брони** (`chooseSource` и правки `tests/e2e`, `tests/ui/workspace.spec.ts`,
  `fund-workspace.spec.ts`): `main` уже починил те же места своим способом, версия `main` взята целиком, помощники
  `booking-form.ts` удалены.
- **Открытый вопрос владельцу (бывший Q-269 этого PR):** что значит «невозвратный тариф»: удержание при любой
  отмене или, как сейчас по Q-103, только при отмене в день заезда и при незаезде. Код и текст панели совпадают
  с Q-103; название тарифа задаёт владелец. Записан в `QUESTIONS.md` как Q-QA-1.
- **Q-203 (архив категории и места):** дополнение PR из QA устарело, категории с 06.10 удаляются или
  архивируются по ADR-150.
