**15.10.2026, ветка `wt/site-ui` (SITE-1 UI, `plans/site-seo-flow-2026-10-15.md` §1 шаги 1–3): первый экран «Сайт и SEO» как у Lovable для всех трёх направлений; у гостиницы сайт создаётся с готовым дизайном без ИИ-подбора.**

Что сделано:

- **Экран** `/marketing/site/editor`, когда сайта нет: слева выбор филиала (направление, статус сайта, текущий отмечен; выбор зовёт тот же `selectBranch`, что шапка, и остаётся на экране) и чат (поле, подсказки-чипы по направлению из `vertical-copy.ts`, «Надиктовать» с языком ru/kk/en, кнопки нет без поддержки браузера); справа «Что WETOP знает о филиале» (адрес, телефон, каталог с ценами `formatMoney` и «ещё K», мастера, часы, фото, отзывы, пробелы со ссылкой «Дополнить»); ниже три дизайна с живым мини-превью тем же рендером, что у сайта (`apps/sites/src/draft-preview`), «Другие варианты», «Подобрать ИИ под мой запрос», «Создать сайт».
- **Готовые дизайны** `packages/domain/src/marketing/design-presets.ts`: 9 направлений в трёх семьях (светлые, глубокие, тёплые), `pickDesignTriple(vertical, page)` даёт по одному из каждой семьи. Тёмной схемы в SiteSpec v0 нет (`colorScheme: ['LIGHT']`), «премиальная» семья на пресете NIGHT; настоящая тёмная тема требует правки `site-spec.ts` и рантайма (вне среза).
- **API**: первая сборка принимает `designPresetId` (`apps/api/src/marketing-site/design-choice.ts`, `generation.service.ts`): направление берётся из набора домена, неизвестный id и смешение с `designRunId` дают 400, в аудит пишется только id.
- **Факты** `apps/web/src/lib/site-facts.ts`: тип `SiteFacts`/`SiteLocation` по контракту соседнего среза API; при 404 эндпоинта факты собираются из брифа (гостиница), услуг/мастеров/графика (салон), меню и сервис-периодов (ресторан).
- **Салон и ресторан**: «Сайт и SEO» в хабе «Доступно»; экран тот же; отказ API по направлению (403 без кода) на «Создать сайт» показывается словами «Конструктор сайтов для салонов/ресторанов подключается». После включения API правок фронта не нужно.
- **Диктовка** вынесена в `lib/use-dictation.ts`; редактор инструкции ИИ-агента переведён на хук.
