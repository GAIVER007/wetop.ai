Шаблон задаёт тему, порядок блоков главной и варианты секций; содержимое берётся из данных филиала (`starterSpecFromFacts` SITE-2), блок без данных не появляется.
- **«Создать сайт»** зовёт `POST /marketing/site/from-template { templateId }`: сервер в одной транзакции записи собирает факты филиала, документ шаблона, заводит сайт (или берёт сайт без версии) и первую версию; 201 новый, 200 сайт без версии, 409 `SITE_HAS_VERSION` (шаблон не затирает работу), 400 неизвестный шаблон или шаблон чужого сегмента, 403 без лицензии; в аудит `marketing.site.template_applied` только id шаблона и хэш. Дальше сайт правится в редакторе как любой другой.
- **«Собрать с ИИ по описанию»** (только с текстом): первая сборка ИИ с выбранным шаблоном как оформлением (`designPresetId` принимает и id шаблона).

- **Стенд** (`scripts/preview/fixture-*`): у каждого филиала свой сайт, маршрут шаблона, факты в контракте SITE-2.

**15.10.2026, вечер: простой редактор сайта и домен сайтов (поручение владельца «очень сложно там всё редактировать»).**

- **Простой редактор как у Lovable** (`simple-editor.tsx`) открывается по умолчанию: слева чат с ИИ (лента разговора, итог правки, частые просьбы, поле с голосом), справа сам сайт во всю высоту, над ним шаблон, «Фото», «Расширенный режим», «Опубликовать».
