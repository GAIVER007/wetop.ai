**17.10.2026, ветка `modest-lovelace-429ae7`: таймауты 5 с в `guard-run` и `auto-deploy` закрыты, причина в первом запуске свежих подмен.**

Симптом: в полном `unit` 16.10 (`…16-34-09Z-unit-c36b`, `…16-25-29Z-unit-9c15`, у соседей `…16-07-23Z-unit-3c0a`)
тесты `tests/unit/guard-run.test.ts` и `tests/unit/auto-deploy.test.ts` падали «Test timed out in 5000ms», отдельно
26/26. Сам `scripts/ops/guard/run.sh` с подменами идёт 70-100 мс, но первый прогон в свежей папке шёл 3 с при 3%
процессора: ждал, а не работал.

Причина: macOS проверяет каждый новый исполняемый файл при первом запуске. Замер: первый запуск только что
записанного `#!/bin/sh` 170-1000 мс, второй 7 мс, тот же файл через `sh файл` 8 мс; признаков у файла нет (`xattr`
пуст). Оба теста писали подмены (`git`, `curl`, `timeout`, `claude`, `sleep`; `docker`, `curl`, `flock`, `df`) в новую
папку на каждый тест, и каждый тест платил за 3-5 первых запусков. В полном прогоне такие подмены пишут многие файлы,
проверка идёт по очереди, и первый запуск стоит секунду и больше: тест выходит за 5 с. Улика из красного прогона:
два теста `guard-run`, которые выходят до первой подмены, шли 6-12 мс, остальные 7-12 с.

Исправление (только тесты): подмены пишутся один раз на файл в `beforeAll` и там же запускаются по разу (предел хука
60 с); своё у теста только папка, подмены берут её из `$AUDIT` и `$FAKE_CALLS`, как и раньше. Подменный `df` в
`auto-deploy` теперь общий и без `FAKE_DF_AVAIL_KB` отдаёт настоящий `/bin/df`, как было у прочих тестов.

```js
// fresh-exec-load.cjs: P циклов пишут НОВЫЙ исполняемый файл и запускают его один раз
const { mkdtempSync, writeFileSync, rmSync } = require('fs');
const { join } = require('path');
const { spawn } = require('child_process');
const root = mkdtempSync(join(require('os').tmpdir(), 'fresh-exec-'));
let n = 0;
function loop() {
  const f = join(root, `s${n++}`);
  writeFileSync(f, '#!/bin/sh\nexit 0\n', { mode: 0o755 });
  spawn(f).on('exit', () => { rmSync(f, { force: true }); loop(); }).on('error', loop);
}
for (let i = 0; i < 8; i++) loop();
```
