# 21.10.2026, ветка hermes/salon-fixb-20261021: аудит салона, разделы Клиенты, Услуги, Статистика, Склад

Источник: аудит живого сайта 21.10.2026 (пункты 1-48). Пункт 1 (высота окон) и типовая услуга из п.5 сделаны отдельно.

## Сделано
- Клиенты: GET /customers/export уводит на /customers (п.6); карточка клиента без плиток, контакты строкой, тот же сегмент, что в списке, кнопка «Записать» ведёт на /appointments?create=1&customer= и открывает новую запись с этим клиентом (п.10, п.11); пустой список это EmptyState (п.24); одна панель: поиск и сегмент слева, импорт, Excel и «Добавить клиента» справа, итог строкой под таблицей (п.44); вкладки «Клиенты | Записи» на обеих страницах (п.20).
- Записи: причина выключенной «Новой записи» всегда видна со ссылками (п.3); поиск с подсказкой «Имя или телефон», служебные строки убраны (п.19); период, фильтры и «Сбросить» одной карточкой (п.35); подзаголовок описывает раздел (п.36).
- Услуги: «Добавить услугу» из шапки по умолчанию включает услугу в филиале (флажок «Сразу в этом филиале», п.5); ссылка на настройку только пока она идёт (п.21); у типовой услуги нет второго списка (п.22); ссылка «Добавить расходник» в техкарте (п.23); панель по низу, без строки-счётчика (п.37); колонки по высоте содержимого, без стрелок (п.38); строка услуги одной строкой (п.39); на телефоне переключатель «Все услуги / В филиале» (п.47).
- Статистика: аналитика салона показывает статусы таблицей, без плиток (п.9, п.48); отчёты: один баннер при пустом периоде (п.25), обычные ссылки вместо чипов (п.26), «С … по …» (п.27), общий Tabs вместо чипов (п.33), поля Field/Input и кнопка по низу (п.34), подзаголовок без названия салона (п.36); итоги отчёта строкой вместо плиток.
- Склад: код товара из названия на клиенте и на сервере, своя ошибка при пустом названии (п.2); пять плиток обзора убраны, итоги строкой под доской, нехватка строкой-предупреждением (п.7); три плитки расходников убраны, итог строкой под таблицей (п.8); дубль «Популярные товары» убран (п.12); «Продажа» открывает окно, вкладки только у гостиницы (п.13); пустой склад даёт кнопки «Добавить товар» и «Приход по накладной» (п.14); «Новый товар», «Категории и наценка», «Новый поставщик» кнопками в шапке и окнами (п.15, п.42); цена сохраняется при уходе с поля, колонка «Подробности» убрана (п.16); код под названием отдельной строкой (п.17); внутренние вкладки операций подчёркнутые, лишний заголовок убран (п.18); месяц без text-transform (п.28); своя кнопка «Выбрать фото» (п.30); /bar шириной wide (п.32); кнопки расходников в строке поиска (п.40); без заливки ячеек (п.41); один размер заголовков карточек (п.43); кнопки прихода стандартной высоты и в линию (п.45); нижний отступ под плавающей панелью на телефоне (п.46).

## Не сделано
- п.4: API `PATCH /beauty/customers/:id` принимает только VIP и дату рождения (`parseCustomerMarks`); имя, телефон и архив требуют нового контракта API, отдельная задача.
- п.26 частично: объединить /reports и /management/analytics под одной страницей значит менять меню (`navigation.ts`, вне области этой ветки).
- п.31 частично: `lang="ru"` стоит на полях дат этих страниц, но Chrome показывает формат по языку браузера; общий компонент даты делает другая ветка.
- п.33 частично: отчёты и операции переведены на общий `Tabs`; вкладки разделов склада остаются со своим классом `bar-tabs`.
- п.29 отложен аудитом.
