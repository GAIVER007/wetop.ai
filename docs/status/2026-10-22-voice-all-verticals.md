**22.10.2026, ветка `claude/voice-all-verticals-20261022` (поверх PR 772): голосовой агент во всех направлениях.**

Поручение владельца: «почему только салону, везде должно быть, во всех вертикалях». Решение: `docs/decisions/2026-10-22-voice-all-verticals.md` (PR 783 в `main`). Причина «только салон»: это было умолчание плана (салон первый в выпуске, AGENTS.md §28), принятое владельцем; требования закрыть остальные направления не было.

Что сделано:

- стойка: `/marketing/voice` открыт гостинице, салону и ресторану (`features.ts`, таблица меню, реестр возможностей CORE-03 со снимками «до»); карточка в хабе у всех (гостиница 6 карточек, салон и ресторан по 5); тексты карточки и подзаголовок страницы по направлению;
- API: `GET /voice/profile` отдаёт `vertical` (направление бизнеса агента);
- воркер: инструменты и инструкция по направлению: салон `get_services`, ресторан `get_service_hours` (`/bot/food-service-periods`, дни с одинаковым временем объединены), гостиница без справочника (просьба перезвонить и перевод); `VOICE_VERTICAL` для запасного профиля;
- документы: `docs/voice/voice-channel.md` (таблица по направлениям), `docs/ops/voice-release.md`, вопрос Q-VOICE-8 (наличие номеров и цены по телефону у гостиницы: деньги и обещание клиенту, решение владельца).

Доказательства:

- Python: `pytest voice/tests` 177 из 177 с SDK; API: unit и сторожа; integration на одноразовом Postgres 16 `voice-journal` и `rls-isolation` 16 из 16 (профиль возвращает `vertical`); `test:record -- unit` (web, API голоса, auth, сторож выпуска) 1109 из 1109; `lint` без ошибок; `typecheck` те же 16 ошибок про отсутствующие в моей копии пакеты (`xlsx`, `qrcode-generator`, `yauzl`);
- тесты на новое поведение писались до кода и были красными (25 в Python, 10 в web); тесты API по профилю прошли сразу, потому что контроллерный тест работает на подставном репозитории, настоящий запрос проверен integration-тестом и typecheck;
- снимки CORE-03 пересняты осознанно: меню гостиницы и ресторана получили пункт «Голосовой агент» (по 4 записи на роль с правом marketing), строка маршрута `/marketing/voice` стала открытой всем направлениям.

- гостиничный агент без справочника (Q-VOICE-8), запись, бронь и стол по телефону (Q-VOICE-5), пробный звонок, ключи и номер: ждут владельца.
