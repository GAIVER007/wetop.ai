# Контент: черновики постов с ИИ (23.10.2026)

Решение: `docs/decisions/2026-10-23-content-drafts.md`. Модель: `docs/marketing/content-drafts-proposal.md` (утверждено
владельцем 23.10.2026 вместе с дополнениями по «Контент-заводу» MarkVision).

## Что сделано

- **Домен** `packages/domain/src/marketing/content-draft.ts`: 1–2 варианта (A/B), длины, хештеги, кнопка действия из
  закрытого списка; ссылки и телефоны из ответа модели вырезаются; цифры, которых нет в фактах карточки и теме,
  возвращаются как «проверьте»; факты филиала строками без float; готовый пост собирает домен.
- **Бот** `apps/ai-seller/src/ai/content_draft.py`, `POST /internal/content-draft` (служебный ключ, тот же каскад и
  учёт расхода, что у `ad-proposal/0`; данные отдельно от правил).
- **База** миграция `20261023000147_content_drafts` (+ `down.sql`, README): CHECK, триггер неизменности, FORCE RLS,
  права без DELETE. **На production не применена.**
- **API** `apps/api/src/content`: `/marketing/content/drafts` (предложение, неделя, создание по `creationId`, правка
  по `expectedRevision`, «опубликован», архив), право `marketing`.
- **Экран** «Маркетинг → Контент»: «Создать пост» (тема, канал, тон → два варианта → правка → день недели),
  «План публикаций» (неделя филиала, «Скопировать», «Отметить опубликованным», «В архив»), «Идеи», «Медиатека».
  Без ИИ: «Написать самому». В хабе «Контент» теперь «Доступно».
