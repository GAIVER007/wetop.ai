# Telegram Bot API — выжимка для будильника сторожа

**Источник:** https://core.telegram.org/bots/api (разделы «Making requests», `sendMessage`, `getUpdates`,
`Update`, `Chat`, `ResponseParameters`) и https://core.telegram.org/bots/features («Privacy mode», `/setjoingroups`, `/setprivacy`). **Снято:** 13.09.2026. Пересказ своими словами — только то, на что опирается код
`packages/integrations/src/telegram/client.ts` (срез 11, ADR-028). Полный текст — по ссылке.

## Запрос

- Адрес: `https://api.telegram.org/bot<токен>/<метод>`; методы вызываются GET или POST.
- Тело POST — `application/json` (кроме загрузки файлов).
- Ответ всегда JSON: булево `ok`; при успехе — `result`; при ошибке — `description` (текст), `error_code`
  (число) и, возможно, `parameters`.
- `parameters.retry_after` — сколько секунд подождать до повтора (превышен лимит, HTTP 429).

## `sendMessage`

| Поле | Обязательно | Что это |
|---|---|---|
| `chat_id` | да | число или строка — куда отправить |
| `text` | да | текст, **1–4096 символов** после разбора разметки |
| `parse_mode` | нет | разметка; сторож её **не использует** — заголовки неисправностей не экранируются под Markdown/HTML |
| `disable_notification` | нет | без звука; сторож для срочных шлёт со звуком |
| `link_preview_options` | нет | превью ссылок |

## Как владелец узнаёт `chat_id`

`getUpdates` возвращает массив `Update`; номер чата — в `message.chat.id`, а добавление бота в группу приходит
отдельным обновлением `my_chat_member` с тем же `chat.id`. У группы номер **отрицательный** (`-100…` у супергруппы),
у личного чата — положительный. `getUpdates` не работает, если у бота настроен webhook.

Порядок для группы дежурных:

1. @BotFather → `/setjoingroups` → выбрать бота → **Enable** (иначе бота нельзя добавить ни в одну группу).
2. В группе: «Добавить участника» → найти бота по `@имени_бота` → добавить.
3. В группе написать `/start@имя_бота`. По умолчанию у бота «режим приватности»: в группе он видит только
   команды, адресованные ему, ответы ему и служебные сообщения — обычный текст не увидит.
4. Вписать `TELEGRAM_BOT_TOKEN` в `.env` и запустить `npm run telegram:chats` — команда напечатает чаты, которые
   видит бот (номер, тип, название; токен и тексты не печатает) и строку для `TELEGRAM_CHAT_ID`.

Бот не может первым написать человеку, который его не запускал: для личного чата нужно сначала написать боту.
В документации это отдельной строкой не записано — проверяется первым пробным сообщением (`POST /guard/alert/test`).

## Что кладётся в `.env` (владелец, SECURITY.md §3)

```
TELEGRAM_BOT_TOKEN=   # от @BotFather
TELEGRAM_CHAT_ID=     # один или несколько через запятую
```
