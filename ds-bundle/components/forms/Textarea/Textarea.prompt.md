Textarea from @pms/web. Use via `window.Wetop.Textarea` (bundle loaded from the root `_ds_bundle.js`).

# Textarea — многострочное поле

Заметки смены, комментарий к брони. То же оформление, что у `Input`.

```tsx
<Field label="Заметка администратора">
  <Textarea name="note" rows={3} placeholder="Просил номер потише" />
</Field>
```
