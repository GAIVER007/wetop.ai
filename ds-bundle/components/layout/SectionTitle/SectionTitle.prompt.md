# SectionTitle — заголовок раздела внутри экрана

`h2` между блоками длинного экрана. `first` снимает верхний отступ у первого заголовка.

```tsx
<SectionTitle first>Деньги на руках</SectionTitle>
<Stats>…</Stats>
<SectionTitle>Остаток к сбору</SectionTitle>
```
