# Alert — сообщение об ошибке

Всегда `role="alert"` — на нём держатся сквозные тесты, и читалка объявляет сообщение сразу.
Только для того, что **не получилось**: успех — `Notice`, результат действия — уведомление.

**Тона:** без тона — ошибка, `warning` — предупреждение, `success` — подтверждение внутри формы.
`boxed` — баннер с рамкой над содержимым.

```tsx
<Alert>Цена не может быть 0</Alert>
<Alert tone="warning" boxed>
  Продано сверх мест: 1 проживание без ячейки на 21 сент.
</Alert>
```
