# Help — раскрывающаяся подсказка

Длинное объяснение, которое нужно не всем: «Как работать с шахматкой», «Как начислить услугу».
Свёрнута по умолчанию, раскрывается щелчком.

Раскрытая подсказка не должна лежать слоем поверх соседей — под ней оказывались фильтры, и нажать их
было нельзя (найдено обходом 17.09). Место раскрытой подсказки — своя строка.

```tsx
<Help title="Как работать с шахматкой">
  Перетащите плашку на свободную ячейку — это переселение. Меню «⋯» на плашке делает то же
  с клавиатуры и с планшета.
</Help>
```
