**Тема:** Интеграция PMS с eQonaq через API / Smart Bridge

Здравствуйте.

Мы разрабатываем собственную PMS-систему для действующего объекта размещения
в Казахстане.

Хотим реализовать автоматическую передачу уведомлений о проживании иностранных
гостей в eQonaq непосредственно из PMS.

Масштаб: объект на 88 единиц размещения в Алматы, около 1000 заездов в месяц,
значительная часть гостей — иностранные граждане. Сейчас интеграции нет,
уведомления подаются вручную.

Просим предоставить актуальную информацию по интеграции:

1. Документацию API eQonaq.
2. Порядок подключения через Smart Bridge.
3. Требования для получения API key.
4. Наличие тестового/песочного контура.
5. Нужна ли ЭЦП юридического лица при server-to-server интеграции.
6. Каким способом выполняется авторизация API.
7. Срок действия API key и порядок его обновления.
8. Какие поля гостя обязательны.
9. Как получать статус принятия/отклонения уведомления.
10. Есть ли API для повторной отправки.
11. Есть ли webhook либо необходимо запрашивать статус.
12. Требования к информационной системе/PMS перед подключением.
13. Требования по информационной безопасности.

Просим также предоставить актуальные технические документы, примеры запросов/ответов
и порядок подключения production-доступа.

Спасибо.
