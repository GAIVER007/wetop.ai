# HELD 132, Beauty reviews

Отдельный релиз для утверждённой модели BEAUTY-REVIEWS-20261018. Production application остаётся за владельцем.

Порядок: сделать backup и проверить восстановление, остановить writers Beauty, применить `migration.sql`, сгенерировать Prisma client и выложить совместимый API. Затем проверить, что приватный кабинет показывает только отзывы выбранного мастера, включая мастера из второй строки визита.

Проверки после применения: оценка только 1-5; один отзыв на пару визит и мастер; визит имеет статус DONE; мастер присутствует хотя бы в одной строке визита; `wetop_app` видит только свою организацию и не может менять отзывы; token hash приглашения уникален; средняя оценка и количество считаются по всем отзывам.

Rollback допустим только при пустых таблицах отзывов и приглашений. `down.sql` блокирует откат с данными, чтобы не потерять историю.
