# HELD 132, Beauty reviews

Отдельный релиз для утверждённой модели BEAUTY-REVIEWS-20261018. Production application остаётся за владельцем.

Зависит от Beauty appointment lines. Для текущей вершины предварительное release-имя: `20261018000134_beauty_reviews`, сразу после `20261018000133_beauty_appointment_lines`. Итоговый порядок фиксируется в `docs/ops/beauty-zapis-release.md`.

До применения нужны свежая резервная копия с проверенным восстановлением и остановленные Beauty writers. `migration.sql` выполняется в собственной транзакции. Сначала применяется схема, затем запускается совместимый API.

Проверки после применения: оценка только 1-5; один отзыв на пару визит и мастер; визит имеет статус DONE; мастер присутствует хотя бы в одной строке визита; `wetop_app` видит только свою организацию и не может менять отзывы; token hash приглашения уникален; средняя оценка и количество считаются по всем отзывам, включая мастера из второй строки визита.

Rollback empty-only. `down.sql` допускается только пока таблицы отзывов и приглашений естественно пусты. После первой ссылки или отзыва down обязан отказать; историю не удаляют ради отката. Дальше допустимы совместимый forward repair или восстановление проверенной резервной копии в отдельно согласованное окно.
