# HELD 133, Beauty materials

Отдельный релиз для утверждённой модели BEAUTY-MATERIALS-20261018. Production application остаётся за владельцем.

Порядок: сделать backup и проверить восстановление, остановить writers Beauty и stock, применить `migration.sql`, сгенерировать Prisma client, выложить совместимый API. Расширение допускает общий склад только для FOOD_SERVICE и BEAUTY, ресторанные заказы, меню и их права не расширяются.

Проверки: техкарта с optimistic revision; услуга и товар одного бизнеса и одной единицы; RLS другой организации; FIFO по непросторнированным партиям филиала; DONE списывает каждую строку один раз; недостаток блокирует весь DONE; первый DONE с пустой картой не получает заднее списание после изменения карты; orderId и appointmentLineId взаимоисключаются.

Rollback допустим только без техкарт, ревизий, Beauty movements и Beauty stock products. `down.sql` отказывает при данных, чтобы не потерять историю или не оставить Beauty rows под восстановленным FOOD-only guard.
