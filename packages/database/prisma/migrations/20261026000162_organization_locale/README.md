# 162 Язык организации

Решение владельца 26.10.2026 (DATA_MODEL `ORG-LOCALE-20261026`): салон в Катаре должен быть полностью на английском;
язык выбирается при регистрации и в настройке салона («Основные сведения»).

Аддитивно, одна колонка: `organizations.locale` (`ru`, `kk`, `en`, по умолчанию `ru`, CHECK `organizations_locale_known`).
Существующие организации получают `ru`: поведение не меняется, пока владелец не выберет другой язык.

## Применение (production)

1. Свежая резервная копия и проверка восстановления по docs/ops/backups.md.
2. `migration.sql`.
3. Проверка: `SELECT locale, count(*) FROM organizations GROUP BY 1` показывает только `ru`.
4. Новый код читает колонку, поэтому выкладка идёт после миграции (сервер сам ждёт её применения).

## Откат

`down.sql` удаляет колонку и CHECK. Выбранные языки теряются, приглашения снова на русском. Старый код колонку не читает.
