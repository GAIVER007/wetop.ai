# 163 Выезд на дом

Решение владельца 27.10.2026 (DATA_MODEL `HOME-VISIT-20261027`): «есть услуга на дому … при создании брони, выбора
услуги можно добавить галочку выезд на дом».

Аддитивно, две колонки в `appointments`: `at_home` (по умолчанию `false`) и `home_address` (до 300 знаков, только у
записи с выездом, CHECK `appointments_home_address_needs_visit`). Существующие записи получают `false` без адреса.

## Применение (production)

1. Свежая резервная копия и проверка восстановления по docs/ops/backups.md.
2. `migration.sql`.
3. Проверка: `SELECT at_home, count(*) FROM appointments GROUP BY 1` показывает только `false`.
4. Новый код читает колонки, поэтому выкладка идёт после миграции (сервер сам ждёт её применения).

## Откат

`down.sql` удаляет CHECK и обе колонки. Отметки выезда и адреса теряются, сами записи остаются. Старый код колонки
не читает.
