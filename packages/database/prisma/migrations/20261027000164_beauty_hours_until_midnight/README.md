# 164 Режим салона до 24:00

Решение владельца 27.10.2026 (DATA_MODEL `BEAUTY-HOURS-MIDNIGHT-20261027`): «график сделай везде с 10.00 до 24.00,
после 10 могут и на дом выезжать».

Код (#900) уже принимает конец смены «24:00», а база в режиме салона (`beauty_location_hours`, 20261018000137) ещё нет:
сохранение «24:00» отвечало 500. Миграция меняет только две функции:

- `beauty_location_hours_valid`: конец интервала `00:00`–`23:59` или ровно `24:00`;
- `beauty_time_in_hours`: запись может кончаться ровно в полночь (23:00–24:00), запись через полночь по-прежнему нельзя.

Таблицы и данные не меняются.

## Применение (production)

1. Свежая резервная копия и проверка восстановления по docs/ops/backups.md.
2. `migration.sql`.
3. Проверка: `SELECT beauty_location_hours_valid('[{"weekday":1,"timeFrom":"10:00","timeTo":"24:00"}]')` даёт `t`.

## Откат

`down.sql` возвращает прежние функции. До отката салонам с концом «24:00» поставить 23:59 в «Настройках салона».
