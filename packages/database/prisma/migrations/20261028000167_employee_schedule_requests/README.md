отсутствие, руководитель одобряет или отклоняет.

## Применение (production)

1. Свежая резервная копия и проверка восстановления по docs/ops/backups.md.
2. `migration.sql`.

4. Новый код читает таблицу, поэтому выкладка идёт после миграции (сервер сам ждёт её применения).
