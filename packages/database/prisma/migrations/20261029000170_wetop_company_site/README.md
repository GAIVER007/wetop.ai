# 170 wetop_company_site

Служебная запись компании WETOP и счётчик сайта wetop.ai для кабинета руководителя (владелец 29.10.2026: «посетители,
регистрации, конверсия посетитель → регистрация»).

- Что делает: если в базе есть организации (рабочая база) и сайта wetop.ai в счётчике ещё нет, заводит организацию
  «WETOP (сайт)» без людей, её бизнес, филиал `wetop.ai` и сайт счётчика с ключом из `apps/site/src/site.config.ts`,
  плюс строку журнала. Пустая база (новая установка, тесты): ничего.
- Что меняет: только добавляет строки. Схема не меняется, данные клиентов не трогаются.
- Проверка после: `SELECT name FROM organizations WHERE name = 'WETOP (сайт)'` одна строка; в кабинете на Главной
  «Посетители wetop.ai» вместо «счётчик не подключён» (после первых визитов).
- Откат: `down.sql` убирает запись, пока у неё нет людей и посетителей; иначе оставляет (данные посетителей ценнее).
- Связанный код: `companyOrganizationIds` (apps/api/src/platform/growth.controller.ts) исключает эту организацию
  из клиентов у всех главных администраторов одинаково.
