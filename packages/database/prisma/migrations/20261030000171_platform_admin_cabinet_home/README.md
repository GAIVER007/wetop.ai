# 171 Кабинет WETOP по умолчанию

Решение владельца 30.10.2026: «почта zapoinov@bk.ru видит только Кабинет WETOP по умолчанию, а Вячеслав как сейчас»
(DATA_MODEL §16.2, `PLATFORM-CABINET-HOME-20261030`). Оба главные администраторы, но вход у них разный.

Аддитивно: `platform_admins.cabinet_home BOOLEAN NOT NULL DEFAULT false` и отметка `true` у учётки компании
`zapoinov@bk.ru` (если она есть и отметка главного администратора действует). Роль `wetop_app` читает новую колонку,
как `user_id` и `revoked_at`.

## Применение (production)

1. Свежая резервная копия по docs/ops/backups.md.
2. `migration.sql`. Таблица в несколько строк.
3. Проверка: `SELECT u.email, pa.cabinet_home FROM platform_admins pa JOIN users u ON u.id = pa.user_id` показывает
   `true` только у учётки компании.
4. Новый код читает колонку, поэтому выкладка после миграции (сервер ждёт её сам).

## Откат

`down.sql` снимает колонку: все главные администраторы снова входят в свою стойку, кабинет остаётся в «Настройках».
