# 172 Партнёры WETOP и команда с цифровыми сотрудниками

Владелец 30.10.2026 («да, делай так»): в «Команде WETOP» ФИО, телефон, почта и зарплата, отдельно «цифровой сотрудник»
(имя и зарплата); раздел «Партнёры WETOP»: процент, доход, начислено, выплачено, к выплате, подключено, на пробном.
DATA_MODEL §63 и §63.1.

Аддитивно:
- `platform_team_members`: `phone`, `kind` (`PERSON` или `DIGITAL`, CHECK), `role` теперь необязательна.
- `platform_partners`: имя, телефон, почта, `percent_bp` (сотые доли процента, 0 до 10000), `active`.
- `platform_client_partners`: чей клиент (одна строка на организацию, каскад при удалении организации).
- `platform_expenses`: статья `PARTNERS` и `partner_id` (только у неё, CHECK).
Права как у 166: RLS нет, `wetop_app` без прав, `wetop_service` без DELETE.

## Применение (production)

1. Резервная копия по docs/ops/backups.md.
2. `migration.sql` (сервер: `sudo -n wetop-release-migrate`).
3. Проверка: `\d platform_partners`, у `platform_expenses` CHECK со статьёй `PARTNERS`.
4. Новый код читает новые колонки: выкладка после миграции (сервер ждёт её сам).

## Откат

`down.sql`, только пока нет партнёров, выплат партнёрам и цифровых сотрудников (иначе по копии базы).
