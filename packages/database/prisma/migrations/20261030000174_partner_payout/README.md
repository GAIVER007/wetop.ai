# 174 Выплата партнёру: разово за тариф и процент с допов

Владелец 30.10.2026: месячный тариф $19, партнёру $10; годовой $199, партнёру $100, разово с первого чека клиента;
плюс 30% с допов (ИИ-продавец, таргетолог, контент, продвижение). DATA_MODEL §63.2.

Аддитивно:
- `platform_plans.partner_payout_cents` bigint NULL ≥ 0: сколько партнёру за первый чек клиента по этому тарифу.
- `platform_payments.kind` `PLAN` или `ADDON` (CHECK, по умолчанию `PLAN`): оплата тарифа или допа.
Права как у 166: RLS нет, `wetop_app` без прав, `wetop_service` без DELETE (столбцы в тех же таблицах).

## Применение (production)

1. Резервная копия по docs/ops/backups.md.
2. `migration.sql` (сервер: `sudo -n wetop-release-migrate`).
3. Проверка: `\d platform_plans` (`partner_payout_cents`), `\d platform_payments` (`kind`, CHECK).
4. Новый код читает новые колонки: выкладка после миграции (сервер ждёт её сам).
5. После выкладки в «Подписках» у тарифов поставить «Партнёру за первый чек»: месяц 10, год 100.
