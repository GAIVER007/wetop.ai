# 180 Курсы Нацбанка РК по дням

Владелец 01.11.2026: «Все бизнесы» вариант первый, «только всё показывай в той валюте, которая в системе»; курс
«Нацбанка РК на каждый день, сам подтягивается, каждая сумма по курсу своего дня». DATA_MODEL NBK-FX-20261101,
ADR-OWNER-FX-20261101.

Аддитивно: новая таблица `exchange_rates` (день, валюта, тенге за 1 единицу в миллионных долях). Строка дня не
меняется. RLS нет: в таблице нет данных организаций. `wetop_app` только читает, `wetop_service` читает и добавляет.

## Применение (production)

1. Резервная копия по docs/ops/backups.md.
2. `migration.sql` (сервер: `sudo -n wetop-release-migrate`).
3. Проверка: `\d exchange_rates` (первичный ключ `rate_date, currency`, CHECK `exchange_rates_values`).
4. Новый код читает таблицу: выкладка после миграции. Без таблицы «Все бизнесы» показывает итог по валютам, как раньше.
5. После выкладки API за 1–2 минуты сам догрузит курсы за полгода, дальше каждый день.
