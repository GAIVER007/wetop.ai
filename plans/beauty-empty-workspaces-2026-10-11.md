# Рабочие экраны салона без данных

Дата: 11.10.2026. Статус: реализовано, четыре регрессионных теста проходят. Правки переданы владельцем сообщениями «давай» и «продолжай».

## Подтверждённая причина

`apps/web/src/app/beauty/journal.tsx` заменяет календарь на EmptyState, если нет записей и отсутствуют мастера либо услуги. API уже возвращает границы времени для пустого дня. Отсутствие данных не требует скрывать сетку.

`apps/web/src/app/customers/page.tsx` вместо пустой таблицы показывает только EmptyState. `apps/web/src/app/beauty/schedule/board.tsx` возвращает только EmptyState без выбранного мастера. Каталоги услуг и мастеров сохраняют таблицы, но добавляют крупную повторную заглушку.

## План исправления

1. Регрессионная проверка пустого календаря: временная сетка видна на компьютере и телефоне, дата переключается, фиктивных мастеров и записей нет. Сначала показать падение на текущем коде.
2. Всегда отображать временную сетку из существующих bounds. Без мастеров показывать явно обозначенную пустую область календаря и ссылки на настройку услуг и мастеров. Не выдавать её за доступные часы записи.
3. Без услуг сохранять настоящие колонки мастеров. Оставить проверку prerequisites создания записи, объяснить причину недоступности действия.
4. Сохранить заголовки таблицы клиентов и семидневную структуру графика без данных. Не включать сохранение графика без мастера.
5. Заменить повторные крупные заглушки каталогов компактными подсказками, сохранить действия добавления и права доступа.
6. Проверить существующие сценарии записи, архивных мастеров, графика, прав доступа, мобильной версии. Приложить скриншоты пустых экранов с указанием локального или рабочего адреса.
7. Публикация через PR и штатный зелёный гейт. Без изменений модели данных и production-миграций.

## Ограничение совместной работы

В основной рабочей копии есть незакоммиченные изменения другой сессии в beauty.css, masters/board.tsx, customers/page.tsx, API и UI-тестах. По AGENTS.md §17 эти файлы не изменяются до завершения той сессии или явной передачи работы владельцем. Общая база не используется.
