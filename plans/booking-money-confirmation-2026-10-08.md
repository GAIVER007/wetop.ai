# Подтверждение оплаты и возврата

Владелец подтвердил 07.10 все предложенные сценарии и 08.10 поручил продолжить.

1. Оплата и возврат используют существующие server actions, права и суммы в minor units.
2. Формы карточки: ввод, проверка данных, явное подтверждение. Изменение поля сбрасывает проверку. До подтверждения API записи не вызывается.
3. В окне календаря открыть те же формы для счёта выбранного проживания. Возврат связан с конкретным платежом и ограничен доступным остатком.
4. Незавершённый ввод защищён от закрытия; после подтверждения виден результат и обновлены суммы. Повторное нажатие во время отправки запрещено.
5. Единый вход отмены с причинами отказ/незаезд использует существующие команды и тарифный штраф. История сохраняется.
6. Red/green проверки на синтетическом API, независимое чтение результатов, проверки экрана и прав. После зелёных локальных проверок final-SHA release-checks, push и проверка условий deploy.

Финансовые правила, schema, production API и количество гостей при создании не меняются. Отдельные ручные штрафы и произвольные причины требуют уточнения и модели.
