# План: мобильная статистика календаря

Статус: утверждён владельцем сообщением «давай». Владелец поручил выбрать логику горящей брони. Основание: три скриншота владельца от 05.10.2026.

1. Верхний блок: «Загрузка на сегодня», дата объекта, крупный процент и полоса заполнения, занято и всего. Использовать существующий расчёт, не подменять сегодняшние значения выбранным периодом календаря.
2. Блок «Гости сегодня»: Заезды / Горящая бронь, Выезды, Проживания, Незаезды, Свободные номера. Убрать Дни рождения, Задачи и отдельные дубли Занято / Загрузка. Значения справа, одна строка на показатель, компактные разделители, существующие цвета статусов и токены.
3. До реализации Горящей брони уточнить бизнес-определение. Для Незаездов использовать отмеченный статус NO_SHOW, не смешивать с overdueArrivals. API desk/today сейчас исключает NO_SHOW. Не показывать отсутствующие данные как ноль. Отдельно проверить номеры и койки: текущая доступность считает инвентарные места, название не должно обещать количество номеров при счёте коек.
4. Названия категорий: переносить целые слова, убрать overflow-wrap:anywhere для названий, выделить доступную ширину. Длинные категории должны оставаться читаемыми и доступными на касании. Номер и его значки не выходят за липкую колонку; повторяющийся текст «номер» на телефоне убрать. Полное имя категории в данных сохраняется.
5. Сохранить горизонтальную прокрутку, липкие номера и даты, создание/редактирование брони, выбор периода и восстановление фокуса. Десктоп не перерабатывать, кроме состава явно запрошенной статистики.
6. Проверки: сначала красный тест переноса и состава панели, затем 360/390/430 px и 1440 px, светлая/тёмная темы, длинные названия, нулевая и полная загрузка, сегодняшний показатель при другом выбранном периоде. Изолированный синтетический API, чужие файлы и общую dev-базу не трогать.
7. После целевых проверок интегрировать в main; полная проверка release-checks на точном коммите, разрешённая выкладка и проверка фактического SHA/health/мобильного браузера. Новую модель или миграцию не вводить.

Горящая бронь: создана сегодня по поясу объекта, заезд сегодня, статус TENTATIVE/CONFIRMED/CHECKED_IN. Источник определения Exely Reception: https://exely.com/help/281526/. Получение через существующий date=created, все страницы. Незаезды: NO_SHOW с плановым заездом сегодня. Свободные номера: только ROOM; загрузка сохраняет общий фонд номеров и коек с явной подписью.
