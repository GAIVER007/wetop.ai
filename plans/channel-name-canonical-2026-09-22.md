# Один канал — два имени в статистике «Главной» (найдено 22.09.2026)

**Статус:** план, ждёт «делай» (AGENTS.md §1). Отчётность, не деньги и не модель данных: данные в базе не меняются.

## Что видно

Channex присылает имя канала (`ota_name`) одного и того же канала в разных написаниях: у Booking.com —
«Booking.com» и «BookingCom», у Expedia — «A-Expedia» и «Expedia» (по документации, список —
`packages/integrations/src/channex/channel-names.ts`). Приём ревизий сохраняет имя как пришло:
`reservations.channel = ota_name` (`apps/api/src/channels/inbound.service.ts`).

В рабочей базе после обнуления 19.09 так и есть: 7 броней «Booking.com» (20–21.09, отменены) и 1 «BookingCom»
(22.09, подтверждена) — один и тот же канал под двумя именами (запрос только на чтение, агрегаты).

## Где это ломает

- **Сопоставление ревизий** (ADR-024) приводит имя к ключу `otaChannelKey` — там верно.
- **«Главная»** группирует источники по сырому имени: ключ `source|channel` в `packages/domain/src/dashboard/metrics.ts`.
  Когда пойдёт настоящий поток, Booking.com окажется двумя строками со своими долями, и «доля канала» будет врать.
  Отменённые брони в заезды не входят, поэтому сегодня на экране видна одна строка — раздвоение проявится на
  первых же живых бронях.

## Что предлагается

1. Приводить имя к ключу **в API при чтении** (`apps/api/src/dashboard/dashboard.repository.ts`) через уже
   проверенный `otaChannelKey`, а показывать одно имя из таблицы «ключ → название» (Booking.com, Expedia,
   Trip.com, Agoda, Hostelworld, Ostrovok). Домен про Channex не знает (ADR-004), поэтому не в `@pms/domain`.
2. Red → green: модульный тест «Главной» с двумя бронями «Booking.com» и «BookingCom» ждёт одну строку источника —
   красный на нынешнем коде, зелёный после правки; прогон через `npm run test:record -- unit`.
3. Проверить остальные места, где имя канала показывается человеку (список броней, карточка), — там раздвоение
   видно, но не искажает числа; править только если владелец попросит.

**Критерий готовности:** тест красный → зелёный; на наборе с двумя написаниями «Главная» показывает одну строку
Booking.com с суммой обеих; `unit`, `typecheck`, `lint` зелёные по журналу.
