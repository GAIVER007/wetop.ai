# «Сопоставление» в модуле «Каналы продаж»: перенос из PR #110 — 28.09.2026

**Статус:** сделано поверх `main` (`e0ac75fb`) и внесено в PR #110 по решению владельца (см. «Как внесено»).

## Откуда

PR #110 (CH1 «Обзор», CH2 «Сопоставление», ADR-107 на той ветке) и PR #111 (ADR-112) — две реализации одного ТЗ
владельца «Каналы продаж v2» от 27.09.2026. В `main` влит #111: модуль `/channels` с пятью вкладками; интеграционный
проход 28.09 оставил #110 на решение владельца (CLAUDE.md §2). 28.09 владелец выбрал: #110 в прежнем виде не вливать,
отличия перенести на модуль ADR-112 («давай продолжай» на предложение в PR #110).

## Что перенесено

Только вкладка «Сопоставление» (`/channels/mapping`). Было в `main`: одна таблица сопоставленных категорий с id номера
и тарифа Channex; несопоставленные категории не видны на самой вкладке (только число на «Обзоре»).

Стало:

| Что | Как |
|---|---|
| Категории | Все категории фонда. «Номер в Channex» — название из кабинета Channex (`GET /channels/channex/content/names`), не id. Статус словом: «Сопоставлена» / «Не сопоставлена» |
| Несопоставленная категория | Предупреждение: какие категории, что остатки и цены по ним в каналы не уходят (`ari-publisher` берёт только сопоставленные) и где это исправляют — «Создать объект и категории» на «Подключениях» (владелец организации; повтор уже сопоставленное не трогает — `ChannexSyncService.setup`, поиск `have`/`sameType`) |
| Тарифы | Отдельная таблица: «сопоставлен в K из N категорий» по данным; «Выгружается» / «Не во всех категориях» / нейтрально «В каналы не выгружается». Тариф без сопоставлений — не ошибка: `setup` сопоставляет все категории с одним тарифом |
| id Channex | Раскрывашкой «Технические детали» — как на «Обзоре» и «Синхронизации» модуля |
| Сбои | Сопоставления не загрузились — `mapping-error` (как было); сводка фонда — `inventory-failed` (как было, категории кодами); названия Channex — «название в Channex недоступно»; тарифы — `mapping-plans-error`, категории остаются |
| Пусто | «Сопоставлений пока нет» — `EmptyState` со ссылкой на «Подключения» (было — строка внутри таблицы) |

Правила «что ошибка, а что нет» — в `apps/web/src/app/channels/mapping.ts` с модульными тестами.

API, модель данных, команды Channex и их `data-testid` не менялись. Новых компонентов нет (`Table`, `Badge`,
`EmptyState`, `Alert`, `details.context-help`).

- **Обзор CH1 и `/analytics/sources`.** В `main` обзор модуля и отчёт по источникам уже есть (ADR-112, ADR-114).
- **Подсветка родителя в меню на вложенных страницах.** В `main` дефекта нет: `/channels/*` и `/hotel-settings/*` —
  особые случаи `sidebar.tsx`, вкладки ИИ-продавца в каталог адресов не входят (`OFF_MENU_ROUTES`) и подсвечивают

  ничего не доказывала и убрана.
