# Шахматка — визуальная иерархия, 20.09.2026

Поручение владельца: улучшить дизайн существующей шахматки. В рамках утверждённого
UI сохраняются календарная неделя по умолчанию, 14 дней, месяц, произвольный период,
даты объекта, API и все действия размещения.

1. Отделить заголовок и главное действие от управления календарём. Период, стрелки,
   «Сегодня» и виды собрать в одну планку; даты для ручного выбора оставить доступными.
2. Выровнять поиск, категории, тип и статус; убрать техническое «единицы» из подписей.
3. Сделать шапку дней яснее: дата и день недели вместе, свободные/занятые — с подписями;
   на узкой сетке компактный вариант. Сегодня и выходные выделены сдержанно.
4. Упорядочить строки и плашки: имя первым, канал/долг/ночи вторичны; геометрия ячеек,
   меню, drag, блокировки, уборка и закрепление шапки/номеров сохраняются.
5. Статусы показать компактной легендой без открытия инструкции; инструкции оставить
   раскрываемыми. Никаких декоративных разделителей поверх структуры календаря.
6. RED→GREEN для видимой легенды; прежние тесты недели/месяца, действий и фильтров,
   скриншоты 1440/1024/768/390/320 light/dark, Axe, lint/typecheck/build. Push/PR.

Не меняются данные и правила бронирования, вместимости, денег или каналов. Тестовые
действия выполняются только на существующем синтетическом UI-стенде.
