# Шахматка: календарный месяц

Прямое поручение владельца: показывать весь месяц по дням на одном экране, начиная с первого числа.

1. Зафиксировать браузерными тестами текущий дефект: начало с сегодняшнего дня и горизонтальный выход колонок за экран.
2. Открывать календарный месяц по умолчанию, переключать стрелками целые месяцы с учётом их длины. Сохранить произвольные даты и подробные режимы 7/14 дней.
3. Распределять месячные колонки по доступной ширине. Сохранить читаемые подписи, подсветку сегодня, выходные, брони, создание, фильтры и перетаскивание. На узких экранах сохранить читаемый масштаб и прокрутку внутри доски.
4. Проверить 28/29/30/31 день, границу года, реальные переходы в карточку/форму, обе темы и размеры экрана. API и правила бронирования не изменять.
5. Сохранить доказательства, отправить проверенную правку в основной репозиторий и обновить localhost.

Уточнение после браузерной проверки: минимум 25px на день (24px для нажатия + граница). Более сильное сжатие на 768px нарушает доступность ссылок. Все 31 день помещаются при ширине окна 1280px с открытой боковой панелью и при 1024px со свёрнутой. На планшете/телефоне прокручивается только доска; правила axe не отключаются.
