# Недельная шахматка

Поручение владельца: заменить начальный месячный вид недельным, чтобы дни помещались на одном экране. Это изменение существующего UI в рамках AGENTS.md §15.

1. Зафиксировать текущую ошибку тестом: начальное окно должно содержать семь дат, понедельник–воскресенье.
2. Добавить календарную неделю, переходы на предыдущую/следующую неделю и возврат к текущей. Сохранить месяц, 14 дней, произвольные даты и существующий API.
3. Растянуть семь колонок на доступную ширину. Проверить узкие панели, телефон, обе темы, переходы года/месяца и действия с бронями.
4. Проверить типы, линтер, сборку и существующий месячный сценарий; опубликовать код в репозитории.

Дополнительное поручение в ходе работы: сохранить переданные настройки Supabase в приватном, игнорируемом Git файле `.env`. В Git попадают только пустые имена переменных. Эти API-ключи не заменяют отсутствующую строку PostgreSQL `DATABASE_URL` для Prisma; миграции и записи в базу не выполняются.

Уточнение: владелец затем передал PostgreSQL и настройки провайдеров. Сохранены в `.env`; read-only проверка PostgreSQL, Prisma и существующего API подтвердила соединение. Проверить frontend на этом источнике без записи в базу.
