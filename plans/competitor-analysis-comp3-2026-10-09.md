## COMP3.2. Редизайн (этот срез; без API, без схемы, без миграций)

1. **Название**: раздел переименовывается в «Анализ конкурентов» (меню, заголовок, карточка в «Отчётах»).
   Лендинг `apps/site` не трогаем (своя выкладка): строка «Раздел „Загрузка конкурентов“» там устареет,
   отметить владельцу.
2. **KPI, 5 плиток**: Ваша загрузка, Загрузка рынка (по N из M конкурентов), Разница с рынком,
   Ночей высокого спроса, Рыночные сигналы (число дат окна с высоким или слабым спросом либо резким
   изменением). Все из уже считаемого `MarketView`.
3. **Календарь рыночных сигналов**: сетка дат окна (7/14/30), в ячейке день, своя загрузка и цвет уровня
   рынка (высокий `--success-soft`, обычный нейтральный, слабый `--warning-soft`, резкое изменение
   `--danger-soft`, нет данных серый); цвет не единственный носитель: слово в `title` и легенда.
   Щелчок по дате открывает существующую «Историю ночи» (`?night=`).
4. **График «Сравнение загрузки»**: SVG-линии «Вы» и «Средняя по рынку» по датам окна, подсказка при
   наведении (дата, значения, по скольким конкурентам), таблица значений в `<details>`. Образец:
   `website/analytics/daily-chart.tsx`. Вкладки «Цены» нет, пока нет данных цен.
5. **Рекомендация от ИИ**: первая подсказка домена: акцентная карточка с кнопкой «Открыть тарифы»
   (`/rooms/categories`) и строкой основания («по данным N из M конкурентов, данные на дату»).
   Остальные подсказки: список рядом с таблицей конкурентов.
6. **Таблица конкурентов**: Объект (ссылка, метка ИИ), Расстояние, Загрузка за период (средняя),
   Динамика (средняя к сравнению), Статус (`Badge` словами уровня или «Недостаточно данных»),
   Данные от, Действия (внести загрузку, изменить). Действия переезжают сюда из тепловой таблицы.
   На телефоне строки складываются в карточки (CSS, образец «Категории номеров»).
7. **«По ночам»**: тепловая таблица остаётся ниже как детализация (функции не теряются, ТЗ §17.16),
   первая колонка упрощается до названия.
8. **Мобильная (390 px)**: KPI в две колонки, календарь и график во всю ширину, конкуренты карточками,
   без горизонтального вылета страницы.

Производные числа (средняя по конкуренту, сигналы календаря): модуль `apps/web/src/app/market/derive.ts`
с unit-тестом (red → green). Новых компонентов дизайн-системы нет: локальные куски раздела, как
`daily-chart` у аналитики сайта; строка реестра DESIGN.md обновляется.
