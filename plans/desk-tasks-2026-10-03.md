# Задачи стойки и дни рождения (Q-249): план срезов (03.10.2026)

Образец — Lite PMS («Новая задача», счётчики «Задачи» и «Дни рождения» в панели дня).
Модель — предложение `DATA_MODEL.md` §22 (НЕ утверждено). Владелец исключил SMS и письма (02.10);
повторы задач и уведомления в v1 не входят (§22).

## Срезы и стоп-гейты

**T0 «Дни рождения» — без модели и миграций, можно сразу.**
`guests.birth_date` уже есть. Выборка «именинники сегодня / ближайшие 7 дней» (API, право `desk`,
только чтение); строка «Дни рождения: N» в панели «Сегодня» календаря со ссылкой в «Гости» с
отбором; тот же отбор в справочнике гостей. Red → green: API-тест выборки (29 февраля, пустая
дата), UI-спек панели. Стоп-гейт: снимки владельцу.

**T1 Модель и API задач — только после «утверждаю» по §22.**
Миграция `desk_tasks` (+`down.sql`, RLS, up→down→re-up на локальном стенде), CRUD:
`GET /tasks?date|assignee|open`, `POST /tasks`, `PATCH /tasks/:id` (правка и «сделана»),
право `desk`; журнал; строки в `route-access`. Red → green: integration на локальной базе
(изоляция организаций, чужой исполнитель — 404), unit контроллера.

**T2 Экран «Задачи».**
Вход: вкладка на Главной (день смены) + «Задачи: N» в панели «Сегодня» календаря; отдельного
пункта меню не добавляем (меню только что пересобрано по частоте, ADR-134 доп. 03.10). Список
«Сегодня / Просроченные / Предстоящие / Сделанные», форма панелью (название, описание, дата,
время или «весь день», приоритет, ответственный из членов организации), «только чтение» — без
кнопок. Red → green UI-спеком; axe, 1440/390, обе темы; снимки владельцу.

**T3 Задачи в карточке брони и гостя.**
Вкладка «Задачи» в карточке брони (`RecordTabs`), создание с предзаполненной связью; в панели
брони — счётчик открытых. Отдельный стоп-гейт.
