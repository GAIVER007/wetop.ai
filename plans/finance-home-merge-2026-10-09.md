# Финансы и Главная: один раздел

Дата: 09.10.2026. Поручение владельца: «подумай как главная перенести в раздел финансы, перенести и
объединить там, сделать всё чётко, оставить всю логику, сделать это в одном разделе». Ответ владельца
«давай делай» = утверждение плана с умолчаниями (как в ADR-135).

Цель: один раздел «Финансы» вместо Главной и Кассы по отдельности. Логика обоих экранов сохраняется;
деньги показываются один раз и из одного источника, данных кассы.

## Решение

1. Экран `/finance` становится единым разделом «Финансы»: сверху блоки Главной, «Загрузка сегодня»
   с кольцом и «Ближайшие 7 дней» (раскрытие по дням, переходы в календарь), «Сегодня» (заезды,
   выезды, к оплате) и «Требуют внимания» с панелью; место блока «Деньги» занимает существующая
   сводка кассы («Всего за всё время», «За период с … по …», Поступления и Расходы, «Баланс по
   способам оплаты»). Ниже прежние фильтры, лента операций по «Показать» и свёрнутые «Отчёты и
   управление».
2. Блок «Деньги» Главной не переезжает: его единственное живое число («Поступления» из
   `/desk/dashboard`) заменяется кассовыми «Поступлениями» (`paidMinor + incomeMinor`), а заглушки
   «Нет данных» у «Расходы / Касса / Всего» уходят, эти числа давно показывает касса. Это закрывает
   отложенное решение от 05.10 («смысл остатков и источник расходов требуют отдельного решения»)
   данными DATA_MODEL §21, без новых формул: все суммы считает сервер как раньше.
3. Период денег один: существующие ссылки «Сегодня / Вчера / Неделя / Месяц / Прошлый месяц» и даты
   «С / По». Вкладки «Сегодня / 7 дней / Месяц» и «Свои даты» Главной не переезжают, их заменяют
   те же возможности кассы.
4. Меню гостиницы: вкладка «Главная» снимается, «Финансы» встаёт первой; нижняя панель телефона:
   Финансы, Календарь, Брони, Гости. `/today` для гостиницы перенаправляет на `/finance` (закладки
   живут); `landingForVertical('HOSPITALITY')` = `/finance`. Салон и ресторан не меняются, их
   «Сегодня» остаётся на `/today`.
5. Файлы блоков Главной переезжают в `apps/web/src/app/finance/` (включая `owner-dashboard.css` и
   стили «Требуют внимания» из `desk.css`); `hospitality-today.tsx` удаляется. В реестре `/today`
   подписывается «Сегодня», `/finance` подписывается «Финансы» (вместо «Оплаты»).

## Умолчания, принятые этим планом (поправляются сообщением)

- заголовок экрана «Финансы» (был «Касса»);
- на телефоне первый экран: сводка (загрузка и деньги), фильтры ниже; правило 05.10 «первый
  мобильный экран завершается фильтрами» пересматривается этим поручением;
- поиск в шапке на объединённом экране виден (правило «поиск скрыт в шапке Главной» уходит вместе
  с Главной);
- бюджет запросов `/finance` в `requests.spec.ts` поднимается до фактического числа блоков (замер
  на стенде), повторных GET по-прежнему нет;
- тур по продукту: автостарт переезжает с `/today` на `/finance`.

## Чего не делаем

API, модель данных, миграции, права маршрутов (`/finance` открывается правом `reports`, как было),
финансовые формулы, CSV, действия кассы, салон и ресторан, `release`.

## Проверка

Новый UI-контракт сначала красный (блоки Главной на `/finance`, редирект `/today`, меню без
«Главной», суммы кассы вместо «Нет данных»), затем зелёный. Правка затронутых спеков: меню,
Главная, касса, мобильные размеры, пустая база, бюджет запросов. Наборы `ui` (стойка без базы),
`unit`, `typecheck`, `lint` через `npm run test:record`. Суммы сверяются с fixture API. Коммит
только файлов задачи, push в рабочую ветку. Выкладка отдельно по AGENTS.md §18.
