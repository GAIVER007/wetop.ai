# Разделы управления гостиницей

Задание владельца: добавить управление номерами (категории, доступность, тарифы, акции),
настройку гостиницы (заезд, штрафы, услуги, описание, фото, удобства), подключения API,
управление отелем, финансовый учёт, менеджер каналов, аналитику и маркетинг.
Продолжаем ранее разрешённую реализацию фронтенда в `codex/hostel-frontend`, PR #1.

1. Добавить read-only проекции существующих Property/RatePlan и Reservation, без миграций.
   Отчёт каналов: заезды в включительном диапазоне дат, до 366 дней, фильтр статуса.
   Считать коммерческие брони, группировать источник + канал + валюту, отмены и незаезды отдельно.
   Стоимость — сохранённая стоимость выбранных броней, включая отмены при фильтре «Все»;
   это не выручка и не оплаты. Не объединять валюты, не считать webhook-ревизии заказами.
2. Вложенное меню с отдельными раскрывающими кнопками, страницами разделов и точным active state.
3. Рабочие страницы поверх существующих API: категории, доступность, услуги, политика отмен,
   настройки объекта, статистика дня, отчёты, подключения, маркетинг сайта.
   Акции, фото и удобства: страницы с явным статусом отсутствующей реализации, без фиктивного сохранения.
4. Проверить read-only контракты, фильтры, маршруты, мобильное меню и ошибки API.
   Проверки через test:record; browser → Next → synthetic API. Live DB/OTA не подключать.
5. Обновить описание реализации и PR, push в GitHub; оставить localhost открытым.

Дальнейший CRUD категорий/услуг/описания и новая модель акций/медиа/удобств требуют отдельного
среза. Новые booking/pricing/folio правила этой задачей не вводятся.
