# Понятный номерной фонд

Поручение владельца: улучшить дизайн «Номерного фонда» на присланных снимках.
Работа в рамках утверждённой UI-модели: только представление существующего фонда.

1. Заменить техническую таблицу /inventory каталогом: компактная сводка, категории
   слева, сгруппированные номера/койко-места справа. На телефоне категории — select.
2. Поиск по коду/комнате/категории, фильтры «Все / Номера / Койко-места», виды
   «Карточки / Список». Фильтры в URL, включая прежний ?category=; сброс и Back работают.
3. Ссылка всей карточки ведёт в существующую /units/[code]. Без выдуманных
   статусов занятости, кнопок добавления или новых API. Exely ID убрать из каталога.
4. Проверить RED → GREEN: поиск, пересечение фильтров, URL/reload/Back, переходы,
   пустой фонд/пустой поиск, светлая/тёмная темы, 320–1920 px и клавиатура.
5. Проверить рабочий localhost, push/PR и main. Публичный сервер обновляется только
   через существующий доступ; известный SSH-блокер не подменять локальным деплоем.

Дополнение по проверке localhost: tsx перезапускает API от событий в корневом
node_modules и обрывает чтение фонда. Исключить эту папку из watch аргументом
поддерживаемого CLI --exclude; исходники apps/packages остаются под наблюдением.
