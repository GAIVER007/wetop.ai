# MKT9.1: редактор как в Lovable (живой сайт справа, ИИ и формы слева, щелчок по блоку)

07.10.2026. Поручение владельца после слияния MKT9 (PR #287): «давай делай чёткую логику как визуально, так и
функционально». Берётся рекомендация разбора `plans/mkt-lovable-model-2026-10-07.md` §4: L1 (один экран), L3 (щелчок
по блоку), L2 в границе ТЗ MKT9 §110 (текст команды наружу не отдаётся, поэтому лента живёт в браузере).

Миграций, новых таблиц, новых маршрутов API и изменений бота нет. Публикация не меняется.

## 1. Что видит человек

Экран `/marketing/site/editor`, когда у сайта есть версия:

1. **Верхняя полоса** одна на весь экран: «Черновик, версия N», «Опубликована версия M» (или «ещё не опубликован»),
   состояние «Есть несохранённые изменения / Всё сохранено», кнопки «Сохранить» (главная, только при изменениях),
   «История», ссылки «Изображения» и «Публикация».
2. **Справа живой сайт.** Рисуется в стойке тем же рендером, что Worker (`apps/sites/src/render`), по документу на
   экране, то есть сразу после каждой правки формы и без сохранения. Над ним: выбор страницы, «Компьютер / Телефон»,
   язык (если языков больше одного), «Открыть отдельно» (подписанное превью сохранённой версии MKT7). Подсказка
   «Щёлкните блок на сайте, чтобы изменить его». Наведённый блок обведён пунктиром, выбранный сплошной рамкой.
   Ссылки на другие страницы сайта переключают страницу просмотра, наружу ничего не открывается, скрипты сайта не
   выполняются (бронь, счётчик, цены «от» в просмотре не работают, как и в превью MKT7).
3. **Слева три вкладки:**
   - **«ИИ»**: лента этой сессии (запрос человека, «ИИ работает», итог «Готово: версия N» с «Что изменилось» и
     «Вернуть как было», или ошибка словами) и строка ввода снизу «Что изменить на сайте?». Если выбран блок, над
     строкой метка «Блок: Номера» с крестиком: запрос уйдёт как `SECTION`, без метки как `PATCH`. Есть несохранённые
     правки: кнопка «Сохранить и отправить» (сначала версия, потом запрос). Ctrl+Enter отправляет.
   - **«Блоки»**: структура страниц и секций (MKT9). Выбранная страница или секция открывает свою форму с «Все блоки»
     назад; у секции кнопка «Изменить этот блок с ИИ» переводит во вкладку «ИИ» с меткой блока.
   - **«Сайт»**: настройки сайта (название, языки, тема, контакты, навигация, SEO), прежняя форма.
4. **Щелчок по блоку на сайте** выбирает эту секцию и открывает её форму во вкладке «Блоки»; рамка остаётся.
5. **До 960 px** четыре вкладки в ряд: «ИИ», «Блоки», «Сайт», «Просмотр»; просмотр отдельной вкладкой.

## 2. Как устроено

- `apps/sites/src/draft-preview.ts`: `renderDraftPreview({ spec, pageId, locale, assets })` строит `RenderContext`
  без ключа, брони, счётчика и токена, рисует `renderPage`, ставит стили рантайма внутрь страницы (`<style>` вместо
  ссылки на `/_wetop/site-*.css`) и `noindex`. Неисправимый документ: `{ ok: false }`, стойка держит прошлый кадр.
- Стойка грузит модуль лениво (свой кусок сборки) и кладёт HTML в `<iframe srcdoc sandbox="allow-same-origin">` без
  `allow-scripts`: скрипты внутри не выполняются, а стойка вешает обработчики щелчка на документ рамки сама.
- Картинки: подписанные адреса `previewUrl` библиотеки филиала (MKT8), карта `assetId → адрес`.
- Лента ИИ: состояние стойки плюс `sessionStorage` по id сайта (переживает обновление вкладки, не уходит на сервер, не
  видна другим). Текст команды по-прежнему не возвращается API (ТЗ MKT9 §110).
- «Вернуть как было» после правки ИИ: существующий `POST /marketing/site/versions/:id/restore` базовой версии запроса
  с вопросом; это новая версия, история не теряется.

## 3. Проверки (red → green)

- unit `apps/sites/src/draft-preview.test.ts`: стили внутри, нет внешнего CSS, нет скриптов WETOP, `noindex`, секции с
  `id`, неизвестная страница и сломанный документ без исключения.
- UI `tests/ui/site-editor.spec.ts`: просмотр меняется сразу после правки поля, щелчок по блоку открывает его форму,
  метка блока уходит запросом `SECTION`, «Сохранить и отправить», переход по странице сайта в просмотре, вкладки на
  телефоне, axe в двух темах на 1440 и 390.

## 4. Не входит

Закладки версий (L5), режим «План» (L6), разговор без правки (L7), правка текста прямо на сайте (L4), лента запросов
с сервера (L2 с показом текста, ждёт решения владельца по ТЗ MKT9 §110).
