# Параллельный день — четверг 17.09.2026

Одна смена ведётся в двух системах одновременно: в Exely как обычно и в новой системе рядом.
Вечером сверка обязана дать ноль по заездам, выездам и занятым койкам. Это гейт «двойной ввод»
из плана: пока сутки не сходятся, на переезд не идём.

## Кто и что делает

| Кто | Что | Когда |
|---|---|---|
| Администратор смены | Каждое действие делает сначала в Exely, потом повторяет в новой системе | вся смена |
| Управляющий | Смотрит экран «Сегодня» утром и вечером, отмечает, чего не хватает | 09:00 и 21:00 |
| Я | Утром синхронизирую брони из Exely, вечером сверяю и пишу отчёт | 08:30 и 21:30 |

Время по Алматы.

## Утро, до смены (я)

1. Подтянуть в новую систему всё, что изменилось в Exely с прошлого дня:

```bash
npx tsx scripts/imports/src/cli-sync-day.ts 2026-09-17 --since=2026-09-15
```

2. Убедиться, что сутки уже сходятся до начала смены:

```bash
npx tsx scripts/reconciliation/src/cli-double-entry.ts 2026-09-17
```

Строка `RESULT: OK` обязательна. Если нет, смена не начинается, пока не разобрано.

3. Открыть администратору экран «Сегодня» и карточку любой брони, показать пять действий ниже.

## Смена (администратор)

Действие делается в Exely, затем то же самое в новой системе. Ничего не пропускать, даже если
кажется мелочью: именно мелочь и ищем.

| Действие | Где в новой системе |
|---|---|
| Гость заехал | экран «Сегодня» → строка гостя → «Заселить». Без гражданства и документа кнопка не сработает, это правильно |
| Гость выехал | карточка брони → «Выселить». Если есть долг, система спросит подтверждение |
| Гость не приехал | карточка брони → «Незаезд» |
| Новая бронь с улицы или по телефону | шахматка → «Новая бронь» → категория, койка, имя, телефон |
| Гость продлился на ночь | карточка брони → «+ 1 ночь» |
| Гость переехал на другую койку | шахматка → перетащить клетку брони на другую строку, или карточка брони → «Переселить» |
| Оплата | карточка брони → «Счета» → «Принять оплату», способ как в Exely |
| Услуга (стирка, минибар) | карточка брони → «Счета» → «Начислить» |
| Отмена брони | карточка брони → «Отменить бронь» |

Если в новой системе чего-то нельзя сделать, записать одной строкой в бланк ниже и продолжать в Exely.
Это не ошибка администратора, это находка.

## Вечер (я)

1. Синхронизация изменений дня из Exely и сверка:

```bash
npx tsx scripts/imports/src/cli-sync-day.ts 2026-09-17 --since=2026-09-17 && npx tsx scripts/reconciliation/src/cli-double-entry.ts 2026-09-17
```

2. Отчёт `reports/double-entry-2026-09-17.md` должен показать ноль по всем строкам. Каждое расхождение
называется по номеру брони и разбирается в тот же вечер: либо не внесли в новую систему, либо не внесли
в Exely, либо система не смогла.

3. Деньги дня: `экран «Деньги за период»` за 17.09 против кассы Exely за 17.09 по способам оплаты.

## Что считается успехом

- `RESULT: OK` вечером по заездам, выездам и занятым койкам, по каждой категории.
- Оплаты дня совпадают по сумме и способам.
- Список «не получилось» разобран: каждая строка либо исправлена в системе, либо записана как правило объекта.
