# «Сколько принёс сотрудник» во всех направлениях (20.10.2026)

Поручение владельца 20.10.2026: «почему только у ресторана… чтобы видеть сколько какой сотрудник принёс… под все
вертикали». Ответы владельца через clarify 20.10.2026 (записаны в
`docs/decisions/2026-10-20-personnel-revenue.md`):

1. «Принёс» = **оплачено**, возвраты вычитаются (не начислено).
2. Период: **переключатель день / неделя / месяц** (неделя с понедельника), по часам филиала или объекта.
3. Салон: оплата записи делится между мастерами **пропорционально цене их услуг в записи**.
4. Гостиница: сотрудник = **кто создал бронь в системе** (журнал `reservation.create`, и для старых броней).
5. Гостиница: показывать в **«Персонал → Сотрудники» (/team)**, колонка «Принёс» у каждого человека с доступом.

Модель данных не меняется: всё считается из существующих таблиц, миграции нет.

## Источники денег

| Направление | Оплата (+) | Возврат (−) | Кому |
|---|---|---|---|
| Салон | `restaurant_cash_operations` INCOME с `appointment_id`, COMPLETED, не аннулирована | та же таблица EXPENSE с `appointment_id` | `appointment_lines.employee_id` пропорционально `price_minor`; строк нет → `appointments.employee_id` |
| Ресторан | `restaurant_payments` COMPLETED, не аннулирован | `restaurant_cash_operations` EXPENSE с `order_id` | `restaurant_orders.waiter_id`; без официанта → строка «Без сотрудника» |
| Гостиница | `payments` COMPLETED через `payment_allocations` → счёт → бронь | `refunds` → счёт → бронь | `audit_logs` `reservation.create` → `user_id`; нет записи (каналы, сайт) → «Каналы и сайт» |

Деньги только BigInt в тиынах (AGENTS §12). Пропорция: целые доли, остаток крупнейшим остаткам (сумма долей = платёж).
Окно периода: даты по часам филиала, моменты UTC (§13). Суммы по валютам раздельно, без пересчёта.

## Срезы

1. Домен `packages/domain/src/personnel-revenue.ts`: `revenuePeriod(kind, today)` → `{from, toExclusive}`,
   `splitByWeights(amount, weights)`, свод по сотрудникам. Unit, красный → зелёный.
2. API салона `GET /beauty/employees/revenue?period=`, ресторана `GET /food-service/employees/revenue?period=`,
   гостиницы `GET /desk/staff-revenue?period=`. Права: просмотр отчётов (`reports`). Интеграционные тесты.
3. UI: переключатель «День / Неделя / Месяц» и колонка или строка «Принёс» на `/employees` салона и ресторана и на
   `/team` гостиницы. UI-тесты, скриншоты.
