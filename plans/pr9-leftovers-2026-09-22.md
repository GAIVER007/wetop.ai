## 1. Срез «сверки и импорт не зелёные сами по себе» — код и тесты, ждёт решения владельца

Один коммит ветки — `8433c13c` «Stop the reconciliations from passing themselves» (15.09) — плюс тест
`apps/web/src/lib/display-date.test.ts` из `6eac23fb`. Ни один из этих файлов в `main` не попал ни под каким
именем (проверено: `git grep explainedByPending origin/main`, `git grep importPiiSalt origin/main` — пусто;
`scripts/reconciliation/src/double-entry.ts` в `main` нет; `cli-double-entry.ts` складывает вердикт из четырёх
чисел, как и 15.09).

| Что | Где | Зачем | Что меняет |
|---|---|---|---|
| `scripts/reconciliation/src/double-entry.ts` + `double-entry.test.ts` (7 тестов) | новые файлы, `cli-double-entry.ts` только читает данные | вердикт «сутки сошлись» требует **и** равенства чисел, **и** пустых поимённых списков; выезд считается по фактической дате с обеих сторон; незаезды — отдельным разделом. Две встречные ошибки больше не дают ноль | то, чем доказываются гейты по числам (PLAN.md Gate 8) |
| `explainedByPending()` в `system-trace.ts` + 2 теста; «без ячейки» → `fail` вместо `warning` в `cli-system-trace.ts` | правка существующих файлов | одна бронь «в пути» не объясняет любое расхождение суток; две сверки одного факта дают один вердикт | вердикт сквозной сверки |
| оговорка в `cli-balances.ts` | 4 строки текста в отчёт | «1449 из 1449 до тиына» читается как «импорт положил то, что отдал Exely», а не «суммы верны» — сверка тождественна по построению | только текст отчёта |
| `importPiiSalt()` в `scripts/imports/src/exely/anonymize.ts` + 3 теста + вызов в `cli-import-reservations.ts` | правка существующих файлов | при `PII_STORAGE=real` перенесённые гости не станут «Гость Тест-…»; сейчас соль анонимизации передаётся всегда (`cli-import-reservations.ts:28` в `main`) | поведение импорта при повторном переносе дампа 19.09 на базу в РК (Q-151) **Перенесён в `main` 23.09.2026** (ADR-064: без него вариант А не перенёс бы настоящих гостей) — тот же код и те же три теста; вызов — в обоих импортах |
| `apps/web/src/lib/display-date.test.ts` (4 теста) | новый файл | тест на функцию, которая в `main` есть без теста | ничего |

**Почему план, а не сразу код.** После ADR-052 Exely не источник: сверки с ним не гоняются, и первые три строки
таблицы сегодня ничего не измеряют. Они понадобятся, если двойной ввод вернётся (повторный импорт дампа,
сверка с Channex по той же схеме). Правка вердикта сверки — это правка того, чем доказываются гейты, поэтому
решение — за владельцем (AGENTS.md §1, §10). `importPiiSalt()` и тест `display-date` безопасны и полезны уже
сейчас; их можно перенести отдельно.

**Как переносить (S/M, один коммит):** взять файлы из вершины ветки `01519db1`, слить с текущими версиями
`main` (`cli-inventory.ts` и `read-inventory-from-db.ts` в `main` менял `c1e31128`), `unit` red → green по
7 + 2 + 3 + 4 тестам, `typecheck`, `lint`; миграций нет, правил брони и денег не касается.

## 2. `design/canvas/**` — холст макетов из токенов (20 артбордов `*.dc.html`, `build.mjs`, `canvas.json`)

В `main` ничего похожего нет: `main` пошёл путём промптов и снимков экранов (`design/reference/current/`,
40 снимков, `/design-sync`). Функционально это мёртвый груз, но единственный в репозитории готовый холст,
собранный из токенов. Решение владельца: перенести как архив (папка `design/canvas/`, без скриптов в
`package.json`) или отпустить вместе с веткой.

## 3. Чего из вершины ветки уже не достать

`npm run design:bundle` (`scripts/design/src/bundle-claude-design.ts`) и генератор проверки шрифтов
(`scripts/design/src/check-fonts.ts`) потерялись внутри самой ветки при её слияниях с `main`: в вершине их
нет, только упоминания в документах; восстанавливать пришлось бы из коммита `67f21059`. Ценность мала —
`main` перешёл на `/design-sync` и `design/font-check.md`.
