# WETOP.AI — единая UI-система

Основание: предоставленное владельцем ТЗ и прямое поручение реализовать его в существующем frontend.

1. Токены light/dark, сохранение темы/system, Lucide, общий shell, поиск, профиль, уведомления, мобильная навигация.
2. Операционный dashboard из DeskDay/Chessboard, быстрые действия, сводка помощника, графики из данных API.
3. Шахматка: тип единицы, фильтры состояния, дата, существующее перетаскивание; бронирование в доступном drawer с существующими формами.
4. Брони, гости, номера, оплаты: повторное использование DTO/API, таблицы/карточки/вкладки; общий стиль остальных страниц.
5. Отдельно включаемый деморежим, только localhost/dev, без внешних операций; явная маркировка. Рабочий режим не подменяет сбой API моками.
6. Проверки TypeScript/lint/unit и Playwright: темы, клавиатура, drawer, фильтры, формы, 320/390/768/1280/1440/1920, ошибки/пустые состояния, production build. Публикация в GitHub по действующему поручению пользователя.

Модель данных, финансовая арифметика и правила бронирований сохраняются. Неподключённые auth/LLM/messages отражаются как UI-ready интерфейсы с честным состоянием; внешние действия не симулируются как выполненные.

Реализация и проверки завершены 13.09.2026. [Отчёт, границы и инструкция запуска](../reports/premium-ui/README.md), архитектура — ADR-035. Итог: 598 unit, 31 UI, TypeScript, ESLint и production build прошли.
