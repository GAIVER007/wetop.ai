# Регистрация v2 — телефон и согласие с политикой (29.09.2026)

Поручение владельца: «сделай страницу регистрации чётко, как пример» (форма exely.com/demo). Ответы владельца 29.09.2026:

| Вопрос | Ответ |
|---|---|
| Модель | Мгновенная самостоятельная регистрация остаётся (почта + пароль → письмо → в систему), только аккуратнее |
| Новые поля | Телефон с кодом страны; согласие с политикой конфиденциальности |
| Страна и код по умолчанию | По браузеру (пояс, затем язык), иначе Казахстан +7 |
| Политика | Текста нет — подготовить черновик на `wetop.ai/privacy/` |

## Сделано

- Домен `packages/domain/src/accounts/registration-contact.ts`: список стран с кодами (Казахстан первым), `defaultPhoneCountry`
  по поясу и языку браузера, `registrationPhone` → E.164 (`+77015554433`; снимает «8» и код, набранный с «+»),
  `PRIVACY_POLICY_URL`, `PRIVACY_POLICY_VERSION`.
- API `POST /auth/register`: обязательные `phoneCountry` + `phone` и `privacyAccepted: true`; отказ словами, без записи в базу.
  **Модель данных не менялась:** телефон — контакт нового объекта `properties.phone` (и его филиала через
  `createPropertyInChain`); согласие — в журнале `user.register` с версией политики, телефона в журнале нет.
- Стойка `/login` → «Регистрация» и окно на главной `wetop.ai`: строка «страна + номер», галочка согласия со ссылкой на
  `/privacy/`; без галочки форма не уходит. Главная держит копию списка стран (`apps/site/src/lib/phone-countries.ts`),
  совпадение с доменом сторожит тест.
- Страница `wetop.ai/privacy/` — **черновик по закону РК «О персональных данных и их защите», перед выкладкой главной
  текст проверяет юрист**; редакция 29.09.2026 = `PRIVACY_POLICY_VERSION`.
- DESIGN.md §19.5: блоки `.auth-phone`, `.auth-consent`, `.legal`.
