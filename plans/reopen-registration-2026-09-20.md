# Вернуть самостоятельную регистрацию

План принят прямым поручением владельца 20.09.2026: «почему регистрация закрыта … сделай норм».
Это отменяет временное закрытие по ADR-055, а не утверждает модель изоляции организаций.

1. Вернуть открытый сценарий по умолчанию: отсутствие или пустое REGISTRATION_OPEN разрешает регистрацию; 1 разрешает явно, 0 запрещает явно. Нераспознанное непустое значение не разрешает доступ.
2. Оставить API единственным источником настройки формы через /auth/options. Сохранить вход, приглашения, восстановление пароля и отказ при явном отключении.
3. RED → GREEN для настройки по умолчанию, HTTP-регистрации и повторного входа. Проверить браузерные сценарии и сохранение в отдельной PostgreSQL на вымышленных аккаунтах.
4. Прочитать адрес существующей учётной записи Luxx Aparts из подключённой базы без паролей и токенов. Не добавлять реальные аккаунты для проверки.
5. Отправить изменения в существующий PR, сменив его название и описание. Проверить возможность выкладки на существующий сервер.

Без изменения схемы, ролей, правил бронирований или каналов. Q-152 об изоляции остаётся открытым.
