# Брони: интерфейс и выкладка, 20.09.2026

Поручение владельца: улучшить дизайн «Брони», выполнить push и deploy. Для следующих
завершённых правок также выполнять push/deploy с проверкой фактической версии.

1. Собрать поиск, даты и статусы в одну панель. На desktop статусы — ссылки с
   активным состоянием; на телефоне — доступный select в той же GET-форме.
2. Упростить заголовок, сделать имя, даты, место и деньги читаемыми. На широком
   экране — таблица, на планшете/телефоне — карточки из той же разметки.
3. Сохранить API, URL-фильтры, пагинацию, ошибки/пустоту, открытие карточки брони,
   форму создания, действия с проживанием и деньгами. Не вычислять фиктивные KPI
   по одной странице выдачи.
4. RED→GREEN для обозначения выбранного статуса. Проверить формы, фильтры,
   карточки, ошибки API, адаптивность, обе темы, Axe, типы, lint и сборку.
5. Commit, push, PR и main. На действующем сервере проверить клон/образы,
   подготовить откат, сверить отсутствие миграций, собрать и обновить только
   API/web, проверить версию и health. Настройки каналов и туннеля сохраняются.

Доступ проверен до реализации: документированный SSH-ключ отсутствует;
управление Chrome вернуло Computer Use permissions are not granted. Владелец
уведомлён через запрос доступа; разработка и локальные проверки продолжаются.
