# M4-B1: проверка CSV перед импортом

18.10.2026. Ветка codex/salons-tz4-m4b от main ef17fbda5. Продолжение утверждённого порядка работ после M4-A.

## Диагноз

Самостоятельное создание клиента уже в main. Модели фонового импорта, журнала строк и безопасного undo пока нет. Полный M4 из ТЗ требует отдельного утверждения модели и правил слияния. Переносить реальные данные через массовый вызов POST нельзя: это не обеспечивает undo и журнал импорта.

## Изменение

Первый срез: локальная проверка CSV без записи в БД. Файл, автосопоставление и ручной выбор колонок имени/фамилии/телефона, сводка готовых строк/замечаний/повторов внутри файла/пропусков. Нормализация по утверждённому M4-A. Предпросмотр прямо говорит, что данные ещё не импортированы. XLSX, сверка с БД, объединение, согласия, фоновый запуск и undo в последующих срезах после утверждения модели. Реальные данные не отправляются во внешние сервисы и не журналируются.

## Проверка

Red-before-green parser: BOM, запятая/точка с запятой/табуляция, кавычки и переносы внутри поля, CRLF, пустые значения, ошибки формата, лимит 50 000, дубли разных форм одного номера. Без имени и телефона пропуск; имя без телефона допустимо с замечанием. Неверный непустой телефон не превращать молча в карточку без телефона. Затем UI на существующих компонентах, сохранение выбранных колонок, доступный отчёт, targeted unit/browser/typecheck/lint через test:record.

## Критерий готовности

Пользователь выбирает CSV, проверяет сопоставление и получает понятный результат без записи клиентов; изменения файла/сопоставления пересчитывают результат. Никакая кнопка не обещает выполненный импорт. Некорректный/слишком большой файл даёт понятную ошибку. Права отображения совпадают с созданием клиента. Откат среза обратным коммитом, миграций нет.
