## Что входит в заход 1

Только правки, которые AGENTS.md §15 разрешает без отдельного решения: проверка ввода и фильтр доступа по
организации. Модель данных, денежная логика, правила бронирования и приём броней Channex **не меняются**.

| № в отчёте | Что | Правка | Доказательство (красный → зелёный) |
|---|---|---|---|
| В-6 | `dateRange` зацикливается на `9999-12-31`, API виснет одним запросом | `packages/domain/src/chessboard/build.ts`: перебор дат по числам (миллисекунды UTC), а не по строкам; новая `daySpan(from, to)` считает длину диапазона без построения массива; `chessboard.service` проверяет длину через неё до построения | `build.test.ts`: `dateRange('9999-12-31','9999-12-31')` в отдельном процессе с таймаутом — на старом коде процесс убит по таймауту; `daySpan` |
| В-1 | `/units/:code` находит ячейку по коду на всю базу — чужая организация видит гостей Luxx, ставит и снимает блокировки | `units.repository.ts`: `unitByCode`, `card`, `blockById` ищут в пределах объекта (`propertyIdRef` — для вошедшего это объект его организации, ADR-061); `reservations.repository.unitByCode` — в пределах `property()` | `tests/integration/organization-isolation.test.ts`: вошедший из организации B не находит ячейку, карточку и блокировку объекта A; A — находит |
| В-3 | Аналитика сайта: список, карточка, правка, удаление по голому `id` | `analytics.repository.ts`: `sites`, `site`, `updateSite`, `deleteSite` — только сайты объекта (`propertyIdRef`); `defaultBookingRatePlan` — только тарифы объекта; `linkSessionReservation` — бронь объекта сайта | тот же интеграционный тест: B не видит, не меняет и не удаляет сайт A |

Публичные пути (`/a/*`, `/w/*`, без вошедшего человека) продолжают брать объект по имени, как весь служебный
контекст (`propertyRef`, ADR-061): поведение для Luxx не меняется. Одно следствие: список доменов для CORS виджета
(`web-booking.module.ts`, публичный контекст) теперь состоит из сайтов объекта Luxx, а не всех сайтов базы. Пока объект
один, это то же самое; для второй гостиницы виджет всё равно ждёт Q-186 (В-4).
