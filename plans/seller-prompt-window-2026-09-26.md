# ИИ-продавец: одно окно промпта вместо семи шагов — план (26.09.2026)

**Основание.** Владелец 26.09: «зачем мне выбор языка, имя бота, приветствие — это всё будет в едином окне как промпт»;
выбрал вариант «одно окно промпта + защита». Код не начат: по правилу владельца — план со списком файлов, его «делай»,
потом код; новая колонка — сначала владельцу.

**Что меняется в решениях.** Сейчас у продавца промпта-текста нет намеренно (ТЗ интеграции §2.2, ADR-081/Б6,
ADR-084 «у продавца всё как было», С1 «свободный текст не становится промптом»): платформа шлёт поля, бот собирает промпт.
Нужно новое ADR-097: у продавца — текст владельца, но первыми в промпте остаются неизменяемые правила бота.

## Как будет

- Вкладка «Настройки» — одно поле «Инструкция продавцу» (до 20 000 знаков): кто он, тон, языки, правила, частые
  вопросы — своими словами. В пустом поле — черновик из шаблона `apps/ai-seller/sistemnyy-prompt.md` и того, что уже есть.
- Кнопка «Сохранить и применить». Одна строка статуса: бот подключён · инструкция у бота · данные объекта у бота.
- Семь шагов, бейджи «не заполнено», «Манера», «рассказ своими словами» — убираются.
- Остаются: «Данные объекта» (цены, заезд, номера — из стойки, руками не вводятся), «Знания», «Диалоги»,
  «Код для сайта», «Модель», «WhatsApp», «Проверка».
- Защита. Бот ставит свою часть первой: роль, границы и девять главных правил из `CORE_RULES`: не считать деньги,
  не обещать действий, звать человека, не называть остаток. Текст владельца идёт после них. Проверка на скрытые
  инструкции (`scan_document`) — как сейчас у полей: при находке 422, текст не применяется.

## Порядок и проверки

1. ADR и DATA_MODEL — владельцу. После «делай» — код, тесты сначала красные.
2. Гейты релиза: unit и integration в Linux, typecheck, lint, e2e, полный UI; бот — полный pytest.
3. Бэкап → миграция колонки (с «да» владельца) → выкладка → «Обновить код продавца».
4. Приёмка на домене: текст сохраняется и применяется; во вкладке «Проверка» бот отвечает по инструкции;
   на вопрос «сколько за 3 ночи» не считает сумму сам.

Срок — около дня с тестами.
