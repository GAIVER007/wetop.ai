# Единый мастер ИИ-продавца

План подтверждён владельцем 30.09.2026: название и объект → рассказ текстом/диктовкой с проверкой расшифровки → генерация и редактирование инструкции → тестовый чат → WhatsApp и запуск.

## Порядок реализации

1. Сохранение инструкции конкретного агента в существующий SellerProfile.promptText. Проверять организацию, выбранный Business/филиал, роль, расширение. Прежнего продавца не переписывать.
2. Генерация возвращает предпросмотр без записи. Владелец явно принимает текст; повторная генерация не заменяет текущую редакцию. Диктовка запускается только кнопкой; отказ микрофона и неподдерживаемый браузер не мешают текстовому вводу.
3. Единый интерфейс шагов, сохранение с обратным чтением, сообщение о несохранённых изменениях. Защищённые правила бронирования отдельно от пользовательского текста.
4. Тест и подключения строго в области выбранного агента. До подтверждения совместимости runtime запрещён fallback на рабочего продавца организации.
5. Бронь WhatsApp — отдельный утверждённый план whatsapp-booking-2026-09-30.md. Проверка наличия/цены и явное согласие гостя обязательны. Пока операция не реализована и проверена, не обозначать её работающей.
6. Проверки прав/изоляции/сохранения, браузерная проверка, push, обычный deploy. Production migration — отдельно после validation/rollback и разрешения.

## Доказательства

Для каждого этапа: красный/зелёный тест, сохранение и обратное чтение, отсутствие изменения другого агента. Статусы подключения и запуска отражают реальную готовность, а не завершение формы.
