# Окно поддержки — согласованный план

Владелец подтвердил 30.09.2026: компактная шапка, различимые ИИ/сотрудник, реальные статусы, обращение к сотруднику, сохранение черновика, ошибки и вложения, адаптивная версия.

Меняется `apps/ai-seller/src/site/widget.js`, браузерные тесты `tests/ui/widget-design.spec.ts`. Общий виджет сохраняет поведение продавца; запрос сотрудника доступен для поддержки. Модель данных и API не меняются.

Статусы: bot_active — отвечает ИИ; needs_human — ожидаем сотрудника, ИИ продолжает помогать; owner_takeover — диалог принят сотрудником. Неизвестный статус или ошибка опроса не обозначают человека онлайн. Автор сообщения определяется from_operator/role, время — серверным at.

Кнопка «Позвать сотрудника» отправляет явный запрос через существующий /message и сохраняет набранный текст/вложение. Это запрос в диалоге, а не обещание немедленного подключения: ожидание/принятие показываются только из сервера. Нет запроса телефона, выдуманного времени ответа или имени оператора.

Проверки: red/green статусов и черновика; отправка, сбой, повтор, авторство, экранирование; светлая/тёмная тема и узкий экран. Выкладка только JS на поддержку поверх действующего образа, без миграций и подмены runtime. Проверка live script hash, health, браузера.
