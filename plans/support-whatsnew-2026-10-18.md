# Срез SUP1: «Связаться с поддержкой» и «Что нового» (18.10.2026)

Пункты 1.1 и 1.4 плана `reports/competitors-2026-10-18/PLAN-best-platform.md`. Ни деньги, ни модель
данных, ни API, ни миграции, ни права не меняются. Код пишется только после подтверждения
владельцем (AGENTS.md §1).

## Зачем

- Жалоба номер один по рынку: поддержка (95 отзывов в 9 источниках). Больше всего хвалят за быстрый
  ответ живого менеджера в WhatsApp.
- Обновления ломают привычное: 11 отзывов в 5 источниках («Верните старую версию!»).
- В WETOP «Помощь» есть у всех трёх направлений, и её описание в меню (`navigation.ts:132`) уже
  обещает «связь с поддержкой», но связи на странице нет. ИИ-помощник есть только у гостиницы.

## Что видит пользователь

### 1. Блок «Связаться с поддержкой» на странице «Помощь»

- Блок стоит **внизу** `/help` у всех трёх направлений. Первые шаги остаются как есть.
- В блоке кнопки WhatsApp и Telegram и почта. Ведут они на контакты команды WETOP, а не на контакты
  объекта.
- Под кнопками строка о часах ответа. Пример: «Отвечает человек, ежедневно 9:00–21:00 по Алматы».
- Сообщение в WhatsApp открывается с готовым началом: «Здравствуйте! Пишу из WETOP, филиал «…».
  Вопрос: ». Название филиала берётся из оболочки, поэтому поддержке не придётся переспрашивать, о
  каком объекте речь. Секретов и личных данных в ссылке нет: только название филиала, номер телефона
  в ссылку не попадает.
- **Контакты не придумываются.** Они берутся из переменных окружения сервера:
  - `SUPPORT_WHATSAPP` (номер в формате 77001234567);
  - `SUPPORT_TELEGRAM` (имя без @);
  - `SUPPORT_EMAIL`;
  - `SUPPORT_HOURS` (строка часов ответа).

  Каких переменных нет, тех кнопок нет. Если не задана ни одна, блока нет вовсе, как у ИИ-помощника
  без `ASSISTANT_URL`. Значения вписывает владелец (ответ на Q-COMP-2).

### 2. Пункт «Связаться с поддержкой» в меню профиля

- Пункт стоит сразу под «Помощью» и ведёт на `/help#support`.
- Если блок пуст (контактов нет), пункта тоже нет.

### 3. «Что нового»

- Новая страница `/whats-new` с правом `desk`, как у «Помощи», общая для трёх направлений.
- На странице короткие записи: дата, заголовок, 1–3 строки и ссылка на экран. Запись помечается
  направлением, и каждый видит только записи своего направления плюс общие.
- Записи лежат одним файлом в коде, `apps/web/src/lib/whats-new.ts`. Каждая выкладка дописывает
  запись туда.
- Запись пишется только о том, что уже доступно на стойке. Для первых записей я предложу 3–5
  настоящих изменений октября из хроники `CLAUDE.md` §2, тексты утверждаете вы.
- В меню профиля пункт «Что нового», рядом точка, пока пользователь не открыл страницу после
  последней записи.
- Отметку «прочитано» помнит браузер (`localStorage` с `try/catch`). Это удобство одного человека:
  на другом устройстве точка покажется снова, и это не страшно. Таблиц в базе нет.

## Как сделано (коротко)

- Контакты читаются на сервере в `help/page.tsx`. В браузер уходят только готовые ссылки.
- Пункт меню профиля получает флаг «есть контакты» из оболочки (`deskShell`) и не делает своего
  запроса.
- `whats-new.ts`: массив записей `{ date, title, text, href?, vertical? }` и чистая функция
  отбора по направлению. У функции отдельный unit-тест.
- Компоненты берутся с `/design-system`: `Page`, `.btn`, `Badge`. Новых компонентов не нужно,
  токены `DESIGN.md`. Точка у пункта меню это существующий `Badge` или `--primary`, без нового
  примитива. Если окажется, что нужен новый примитив, сначала строка в `DESIGN.md` §8 (ADR-048).
- Работа идёт в отдельной копии рабочего дерева от свежего `origin/main` на ветке
  `claude/support-whatsnew`. Ветка `claude/restaurant-module-tz` отстаёт от `main` на 1285
  коммитов, поэтому в неё срез не идёт.

## Проверки (red → green)

- **unit:** отбор записей «Что нового» по направлению; сборка ссылок поддержки, включая пустые
  контакты и спецсимволы в названии филиала.
- **UI** (`tests/ui`, `--workers=1`):
  - блок есть при заданных переменных и отсутствует без них;
  - ссылки WhatsApp и Telegram правильные;
  - пункт меню профиля ведёт на `#support`;
  - страница «Что нового» показывает записи своего направления;
  - точка гаснет после открытия;
  - axe в двух темах на 1440 и 390 px.
- `npm run typecheck` в корне, lint, unit всего `apps/web`.

## Не входит

- Окно чата внутри стойки, тикеты, учёт времени ответа (это Q-COMP-2, вариант Б).
- ИИ-помощник для салона и ресторана. Это отдельный срез: нужен промпт по направлению в
  `apps/ai-seller`.
- Рассылка «что нового» по почте.

## Нужно от владельца

1. Подтвердить план.
2. Контакты поддержки: номер WhatsApp, имя в Telegram, почта и часы ответа. Можно позже: без них
   блок просто не показывается, а остальное работает.
3. Утвердить тексты первых записей «Что нового», когда я их предложу.
