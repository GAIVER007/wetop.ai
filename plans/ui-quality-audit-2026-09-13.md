# Полная проверка интерфейса WETOP

Основание: прямое поручение владельца проверить все разделы, блоки, кнопки, шрифты и исправить найденные дефекты. Проверка и исправления в существующем frontend, без изменения финансовых правил и схемы.

1. Инвентаризация маршрутов и элементов управления. Сопоставить реальные API, демонстрационные данные и неподключённые функции.
2. Расширить браузерный аудит: доступность, контраст, шрифты, клавиатура, drawer/history, фильтры, поиск, формы, мобильные размеры, печать, ошибки и длинный контент. Сначала зафиксировать дефекты.
3. Исправлять первопричины по отдельным группам, для ошибок поведения — красный/зелёный тест. Проверять данные списка и карточки, сохранение введённого и результат операции.
4. Контрольные screenshots и полный изолированный UI-набор, нужные unit/type/lint/build проверки. Не выдавать изолированный API за живую БД или production Channex.
5. Отчёт с матрицей разделов, результатами, исправлениями и оставшимися ограничениями. Публикация в GitHub main по действующему поручению владельца, рабочий локальный просмотр.
