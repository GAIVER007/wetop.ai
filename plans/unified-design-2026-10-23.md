# Единый вид разделов во всех направлениях (план, 23.10.2026)

Владелец 23.10.2026: «все разделы, блоки, страницы должны быть едины в каждой вертикали, почему они везде разные»;
образец шапки журнала — календарь гостиницы; «Быстрый отчёт» во всех направлениях; выбор периода ровно, без вылезания;
график работы гостиницы пуст при добавленных сотрудниках; аналитика гостиницы кривая.

Инвентаризация живого сайта (QA-аккаунты A салон, B ресторан, C гостиница, 1440 px): `~/inv23/{A,B,C}/`.

## Срез 0. Окно брони (сделано, PR #822)
Окно брони вариант B во всех трёх направлениях. `docs/decisions/2026-10-23-booking-window.md`.

## Срез 1. Шапка журнала одна на всех (образец: календарь гостиницы)
Один компонент `components/journal-head.tsx`:
- строка 1: иконка + заголовок, подзаголовок; справа период (кнопка с календарём + стрелки ‹ ›), «Во весь экран», «Быстрый отчёт», главная кнопка («Новая бронь» / «Новая запись»);
- строка 2: итоги дня одной строкой (`SummaryLine`), без плиток;
- строка 3 (панель): отборы раздела (категории/статусы и поиск; специалисты и вид; залы и время) и «Фильтры».
Где: гостиница `/chessboard`, салон `/calendar` (+ неделя), ресторан `/floor-plan` и `/table-reservations`.
Сегмент «День / Неделя» салона и «План зала / Расписание» ресторана переезжают в строку отборов.

## Срез 2. Выбор периода
`components/date-range-popover.tsx`: окно не выходит за край экрана (прижимается к правому краю кнопки, ширина
`min(…, 100vw - 32px)`), на телефоне на всю ширину. Салон и ресторан переходят с поля даты на тот же выбор
(один день = период из одного дня, пресеты «Сегодня», «Завтра», «7 дней»).

## Срез 3. «Быстрый отчёт» во всех направлениях
Гостиница получает `QuickReport` с отчётом дня/периода по броням (заезды, выезды, проживают, начислено, оплачено,
по источникам) из уже загружаемых данных шахматки и `/reports`.

## Срез 4. График работы гостиницы
Причина пустоты найти в данных (список сотрудников `/team` против источника графика), исправить с красным тестом.
График строится по сотрудникам филиала так же, как у салона и ресторана.

## Срез 5. Аналитика гостиницы
Убрать плитки (решение «без плиток» 20–21.10), итоги одной строкой; отборы в одну полосу (период, тип мест,
категория, шаг); мини-календари без обрезки текста. Вид как у аналитики салона и ресторана.

## Срез 6. Остальные разделы
Сверка по инвентаризации: заголовки одним шаблоном (`Page` title + subtitle + actions), одинаковые «Персонал →
График работы» (ресторан показывает h1 «Сотрудники» на `/employees/shifts`), «Клиенты» гостиницы («Гости и
бронирования»), «Записи» гостиницы («Брони»). Различие только в словах (`vertical-copy.ts`).

## Проверка и выкладка
Каждый срез: красный тест, правка, unit + UI своего направления, снимки 1440 и 390. Один поезд PR, CI до зелёного,
выкладка, снимки живого сайта трёх направлений.
