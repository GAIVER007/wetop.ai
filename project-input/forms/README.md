# project-input/forms

Печатные формы. Для каждой: **RU + KZ + текущий пример из архивный источник**.

- [ ] Договор
- [ ] Регистрационная карта
- [ ] Guest card
- [ ] Invoice
- [ ] Счёт
- [ ] Акт (если используется)
- [ ] Кассовый документ
- [ ] Шаблон подтверждения брони

Структура:

```
forms/
  dogovor/
    ru.docx
    kz.docx
    retired-source-example.pdf
  ...
```

> Примеры из архивный источник могут содержать данные реальных гостей — не коммитить,
> перед передачей агенту анонимизировать.
