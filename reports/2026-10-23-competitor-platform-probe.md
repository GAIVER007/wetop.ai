# Проба площадок: где видна загрузка соседей салона и ресторана (23.10.2026)

Шаг 0 плана `plans/2026-10-23-competitors-business-manual.md`. Обычный безголовый Chromium (тот же, что у
сборщика гостиницы), одна-две страницы на площадку, без входа, без обхода капчи и защиты, без отправки записи.
Сохранялись только код ответа, заголовок, длина текста и найденные признаки окон; имена, телефоны и отзывы не
сохранялись.

## Итог
| Площадка | Для кого | Результат | Годится для сборщика |
|---|---|---|---|
| **Dikidi** | салон | 200; каталог Алматы открыт; виджет записи `dikidi.net/ru/record/<id>` без входа: услуги → «Дата и время» → **даты со свободными окнами и сами окна** (пример: 30.10 — 07:00, 08:30, 10:00; дальше 3, 6, 11, 14, 16, 22.11). Данные приходят запросом `mobile/ajax/newrecord/get_datetimes/` | **Да.** Уровень дня = число окон на день; «нет мест» = день не предложен |
| **YCLIENTS** | салон | 200; виджет `n1.yclients.com` открыт без входа, но **общего каталога по городу нет**: нужна ссылка на виджет конкретного салона | **Да, по ссылке соседа.** Владелец вставляет ссылку «Онлайн-запись» соседа |
| **Booksy** | салон | 200; страница салона открыта, кнопка «Забронировать»; в Алматы салонов на Booksy почти нет (выдача увела на США) | Слабо для Казахстана |

| **Restoplace** | ресторан | 200; сервис брони столов («свободные столы», «свободное время» в описании); публичный виджет у каждого ресторана свой | **Да, по ссылке соседа**, если сосед принимает брони через Restoplace; проверить на 1–2 реальных ресторанах Алматы |
| **Chocolife** | ресторан | 200; купоны и акции, броней столов нет | Нет |
| **Яндекс (Еда/LeClick)** | ресторан | 403 и капча | Нет |
| **Booking.com** | гостиница | 202 и пустая оболочка, как 09.10 | Нет без партнёрского API |

## Что это значит
- **Салон:** загрузку соседа видно по числу свободных окон на день в его онлайн-записи. Работает на Dikidi
  (самая частая в Алматы) и YCLIENTS по ссылке соседа. Шкала: «Нет мест» (день не предложен), «Мало мест»
  (окон до N, порог как §23.1, предложение 3), «Есть места».
- **Ресторан:** открытого общего источника нет. Работает только там, где у соседа своя онлайн-бронь (Restoplace или
  виджет на сайте). Иначе — ручной ввод «полный зал / есть столы» по вечерам.
- **Booking для гостиницы:** без партнёрского API данных нет (повтор находки 09.10).

## Предложение к модели (DATA_MODEL §60)
`free_slots` у снимка оставить: Dikidi и YCLIENTS дают точное число окон. Площадка соседа выводится из ссылки
(как `competitorPlatform` у гостиницы): `dikidi`, `yclients`, `restoplace`, иначе «вручную».
