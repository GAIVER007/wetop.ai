## Откат и ограничения

До любых пользовательских записей допустим согласованный down.sql. После появления черновиков выключить флаг, вернуть прежний код, таблицы и данные сохранить. Не выполнять DROP с пользовательскими данными.

У Supabase сохранились default grants anon/authenticated; SECURITY.md §12 фиксирует отключённый владельцем Data API. Новые таблицы нельзя публично открывать через Data API. Этот шаг не разрешает включение Data API или изменение доступа к другим таблицам.
