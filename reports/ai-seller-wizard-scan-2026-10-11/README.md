## Что реализовано

- Мастер получает серверную готовность скана. При готовности показывает Turnstile и кнопку чтения сайта; без готовности остаётся ручной путь.
- Общие поля businessName/niche/description и до 8 FAQ. Отели, рестораны, кафе, бары, салоны красоты и произвольная ниша. Ниша черновика не назначает Business.vertical и не даёт tools.
- POST /wizard/scan проверяет bearer сессии и Turnstile (action wizard, hostname из WIZARD_PUBLIC_HOST). IP хэшируется HMAC; сырой адрес не хранится. GET /wizard/scan возвращает только задание владельца токена.
- WizardJob(kind=scan): блокировка черновика при постановке, SKIP LOCKED при обработке, lease generation, ревизия результата, срок сессии и agentId проверяются перед записью. После остановки обработчика повтор использует прежний requestId. Автоматическое восстановление через 2 минуты, до 3 попыток.
- Бот: служебный вход /internal/wizard/scan, существующий SSRF-загрузчик, scan_document, маскировка ПД, существующий run_site_model без tools, строгий формат результата. Сырой сайт не записывается.
- Redis: повторы, лимиты сессии/IP, общий аварийный дневной токенный бюджет. Вызовы сериализуются; неизвестный расход закрывает бюджет до следующих суток UTC. Потолок мягкий, как у существующего каскада: последний вызов может превысить оставшийся бюджет. Денежный лимит и цена гостя этим срезом не утверждаются.
- UI: реальные queued/running состояния, ручной ввод во время обработки, повтор через экран источника, пометка найденных полей, восстановление после перезагрузки. Устаревший результат не затирает правку.

## Что этот PR не завершает

Это первый срез M1, а не всё ТЗ MarkVision. Читается одна страница, дополнительные ссылки пока не обходятся. CAPTCHA открытия самой гостевой сессии из полного O2b ещё не добавлена; существующий лимит открытия 20/час/IP сохранён, каждый платный scan отдельно защищён CAPTCHA. Генерация инструкции/знаний O3, гостевой тест-чат O4, перенос при регистрации O5, CRM, рассылки, версии промпта и другие последующие этапы не реализованы этим PR.

Результат FAQ хранится в источниках черновика для последующей генерации; интерфейс этого среза показывает название, нишу и описание. Предметные Beauty/Food tools остаются в существующем отдельном PR #286. Консультация по бару не означает реализацию отдельного товарного учёта бара.

Не проводились реальные платные вызовы модели, production-сканы, внешние сообщения или развёртывание. Проверка браузера использует заглушку API; сохранение, конкуренция и восстановление задания отдельно доказаны настоящим PostgreSQL. Полный браузерный маршрут с настоящим платным провайдером не заявляется.
