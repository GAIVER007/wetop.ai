# Бар: ошибка загрузки при запуске через tsx

Причина подтверждена production-логом: BarController получает undefined вместо BarService.
Загрузчик tsx не генерирует design:paramtypes. В контроллере отсутствовал явный Inject,
хотя сервис и репозиторий уже используют явное внедрение зависимостей.

Исправление: Inject(BarService) в конструкторе контроллера. Финансовые правила,
схема базы и данные не меняются.

Проверки:
- Новый HTTP regression-тест без design:paramtypes: до исправления categories возвращает 500.
- После исправления: 24/24 проверки API, действий интерфейса и домена Бара.
- Отдельный запуск через node --import tsx с tsconfig API: 9/9 GET-маршрутов возвращают 200.
- Все три typecheck и lint прошли.
