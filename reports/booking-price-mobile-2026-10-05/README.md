# Мобильная бронь и явное редактирование гостя

05.10.2026. Отдельная ветка `codex/booking-price-mobile-20261005`, основание a5c5050c. Это локальный срез нового плана, не изменение уже принятого релиза.

Реализовано: кнопка с карандашом открывает существующую форму гостя прямо в карточке, сохранение обновляет сведения брони. Сохраняются ограничения хранения персональных данных, проверки API и режим просмотра. Новая бронь компактна на телефоне, в тёмной теме поля без серой рамки; фокус и ошибки остаются видимыми. Печатные документы раскрываются по отдельному действию.

- GREEN: 12 браузерных сценариев, существующие компактные формы и детализация ночей плюс новые проверки.
- Изменение гражданства синтетического гостя KAZ → KGZ сохраняется после перезагрузки, URL карточки не меняется.
- Escape закрывает только редактор гостя, оставляет панель брони и возвращает фокус.
- Read-only запрещает редактирование.
- Ширины 320, 390, 768, 1440: основные поля новой брони и создание помещаются в экран, нет горизонтального переполнения или внутреннего скролла основного состояния.
