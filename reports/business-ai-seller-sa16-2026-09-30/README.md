## Что сделано

**PMS** — миграция `20260930000035_business_agent_identity` (+ `down.sql`):
- `seller_agents.location_id` (FK на `locations`, RESTRICT); состояний четыре: `draft`, `active`, `paused`, `archived`; `active` и `paused` без филиала невозможны;
- не более одного неархивного AI-продавца (`scenario = 'sales'`) на филиал — частичный уникальный индекс; агент другого типа на занятом филиале допустим;
- триггер: филиал агента принадлежит организации агента (при вставке и смене); тот же контроль для `seller_profiles.agent_id`;
- перенос: `seller_agent_ensure(org)` и `seller_agents_backfill()` — агент с `id = organization_id`, автор — самый ранний владелец, филиал — самого раннего объекта, `active` только при принятом профиле и известном филиале; вся связь профиля с агентом;
- триггер профиля: прежний код вставляет профиль без агента — агент заводится сам, сохранение не падает;
- предпроверка: останов без изменений, если есть агенты в `preparing/ready/error` или организация с продавцом без участников;
- код: каталог SA1 берёт филиал перенесённого агента (иначе прежнее правило), перенесённый агент не дублируется черновиком и не открывается редактором мастера.

**База бота** — миграция `0008_agents`: таблица `agents` (перенос из `organizations`, `id` тот же), `agent_id` у `documents`, `clients`, `conversations`, `whatsapp_connections` (NULL-able, заполнен `= organization_id`), уникальность клиента по агенту рядом со старой; зеркало `agents` ← `organizations` ведёт слушатель модели; `X-Agent` сверяется с организацией запроса (чужой или неизвестный — 403, без заголовка — агент с `id = organization_id`).

## Что осталось за владельцем и чего нет

- Порядок выкладки — `DATA_MODEL.md` §20.7: копии баз → миграция PMS **до** кода → API и стойка → миграция бота при старте образа → проверки на Luxx до и после. Миграции применяет владелец. Образ бота пересобирать вместе с BUG-WA-1 (PR #186) или отдельно.
- Проверки на Luxx (запросы только на чтение): агентов ровно столько, сколько организаций со строкой `seller_profiles` или расширением; активных без филиала — 0; в боте нет строк без `agent_id` при заданной организации; `phone_number_id` и ключ виджета не изменились.
- «Сужение» (`agent_id NOT NULL`, смена ключа `seller_profiles`, снятие старой уникальности клиента, чтение из `agents`) — отдельным решением после релиза без происшествий.
- Не сделано, по решению владельца: мастер создания (SA2), перевод ключа модели на платформу (Q-SA-10), `owner_actions` с автором (SA8/SA9), протокол `X-Agent` со стороны платформы.

**Стоп.** SA2 — только после регрессии по этому срезу и отдельного «да».
