на подставном API UI-набора (`tests/ui/fixture-api.ts`, данные вымышленные). По ТЗ

подтверждения владельца.

**Оговорка стенда.** В подставном API `GET /channels/channex/connection` отвечает «Соединение установлено»,
а `GET /channels/channex/mapping` — пустым списком; поэтому на снимках одновременно зелёный бейдж
соединения и «Объект в Channex не создан». На рабочем сервере оба ответа строятся из одних
`channel_mappings` и так не расходятся.

Чего на снимках нет по плану CH1: вкладок, слияния пунктов меню (CH5), мастера подключения,
изменений экрана `/channels` и его кнопок.

Съёмка: стенд UI-набора (`next dev` :3100 + подставной API :4311), Chromium Playwright, тема из
`prefers-color-scheme`.
