## Как этим пользоваться

```bash
# публичный адрес на время разработки (в отдельном окне, рядом с API)
scripts/ops/channex-tunnel.sh
# состояние webhook: зарегистрирован ли, когда доставлял последний раз, не под подозрением ли
curl -s http://localhost:3001/channels/channex/webhook/status
# полная выгрузка по расписанию — проверить/пнуть
curl -s -X POST 'http://localhost:3001/channels/channex/sync/scheduled?force=1'
```
Переменные: `CHANNEX_FULL_SYNC_HOUR` (час по Алматы, по умолчанию 3), `CHANNEX_FULL_SYNC=off`, `CHANNEX_WEBHOOK_HEALTH=off`.
