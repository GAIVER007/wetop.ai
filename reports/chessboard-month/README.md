# Шахматка: весь календарный месяц

13.09.2026. Реализовано в существующем frontend, API и правила PMS сохранены.

- По умолчанию первое–последнее число текущего месяца по Алматы, включая прошедшие дни.
- Стрелки переключают целые месяцы; февраль и переход между годами учитываются. «Сегодня» возвращает текущий месяц.
- Все 31 день видны без горизонтальной прокрутки на 768/812/1024/1280/1440/1920px. На 760–1279px названия номеров размещаются над строками, освобождая ширину для календаря; сворачивать боковую панель не требуется.
- Ширина дня и зоны нажатия не меньше 24px. На телефоне прокручивается только таблица. Шапка закреплена; на широком экране номера стоят в закреплённой левой колонке. Сжатие ссылок ниже 24px давало нарушения доступности, поэтому выбрана перестановка подписей, без отключения правил axe.
- Режимы 7/14 дней, собственный диапазон, поиск, категории, статусы на первую дату, ссылки на брони и создание по выбранной дате сохранены. Имя гостя обрезается только в границах его полосы; полная подпись доступна при наведении и через карточку.

Все данные на скриншотах вымышленные. Полный общий UI-набор предыдущего аудита не повторялся: повторены затронутые сценарии.

Raw test/build logs сохраняются как выдал инструмент, включая whitespace. Проверка diff относится к коду и документам, а не к форматированию логов.
Next автоматически переключает next-env.d.ts на типы .next-ui при UI-тестах и .next при сборке; перед фиксацией восстановлен штатный .next/dev. Поэтому fingerprint журнала после сборки может отличаться от UI-прогона только из-за этого generated-файла. Первое воспроизведение, во время которого Next изменил его, не засчитано; красное доказательство взято из повторного стабильного запуска.
