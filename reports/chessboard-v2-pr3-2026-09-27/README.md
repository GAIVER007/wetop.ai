## Отменённые и незаезды

Отменённая бронь и незаезд место не занимают: запрос шахматки их не выбирает (`status notIn
['CANCELLED','NO_SHOW']` в `chessboard.repository.ts`), место возвращается в продажу — так
работает домен с первого среза и так же сверяется с Exely. Показать их плашкой на сетке значило бы
менять API и смысл сетки (ТЗ §73: domain — только по отдельно доказанному gap), поэтому в PR 3 этого
нет. На снимке R07 — строка, где у стенда лежат отменённая и незаезд: клетки свободны. Если стойке
нужно видеть их на сетке (например, бледной плашкой), это отдельное решение владельца.

## Что сделано

- **Подпись плашки по её собственной ширине** (container queries): ≥ 170 px — имя, вторая строка
  «источник · заезд/выезд сегодня · N ночей · долг суммой»; 120–169 — имя и источник, долг точкой;
  52–119 — «Имя Ф.», без глифа статуса (статус — цветом и словом в подсказке); < 52 — инициалы.
- **Источник — маленький бейдж**: канал буквами (B, A, T, HW…), прямой источник словом (Стойка,
  Сайт, WA); полное название — в подсказке и предпросмотре; плашку под канал не красим.
- **Долг** — суммой на широкой плашке, точкой на узкой; полностью оплаченная — без индикатора.
- **Длинная бронь**: «N+ ночей», если видна не вся; имя липнет к колонке мест при прокрутке вбок.
- **У однодневной плашки нет «⋯»** (во всех режимах): кнопка и ручка продления забирали 64 px из
  140 в неделе, и «Посетитель Д.» обрезался до «Посетите…»; те же действия — в предпросмотре по
  щелчку. Ручка продления осталась (это перетаскивание — PR 4). На такой узкой плашке вторая строка
  («источник, выезд сегодня») не помещается — эти факты в подсказке и в предпросмотре.
- **Одинарный щелчок — предпросмотр, двойной — полная карточка.** Предпросмотр: гость → статус →
  даты → размещение → источник → Итого / Оплачено / Долг → действия по статусу. Номера брони,
  данных канала, телефона нет. Заселить и выселить — те же команды и те же предупреждения, что
  в карточке (непроверенная ячейка — Q-156; выселение с долгом — T3); продлить — прежний путь
  с суммой до подтверждения; принять оплату и переселить — вкладки «Счета» и «Действия»
  карточки. «Только чтение» (ADR-102) — без действий.
- Данные предпросмотра — по выбранной брони (два GET, как у карточки), сетка по-прежнему одним
  ответом; отказ счёта не роняет даты (частичный сбой, §36).

DnD, продление перетягиванием, API-команды и домен не менялись.
