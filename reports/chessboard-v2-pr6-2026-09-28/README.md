## Что сделано

- **Строка над сеткой (§11).** Вместо блока «Без ячейки: N» со списком и меню «Разрешить» — одна
  строка высотой поля: значок, «2 брони без назначенного места» и справа «Разместить». Считаются брони,
  а не проживания (Q-209); у групповой брони число мест названо в ящике. Тон warning, при проданном
  сверх мест — critical. Нет таких броней — строки нет.
- **Ящик (§12).** «Разместить», «Разрешить» у плашки «Продано сверх мест» и ссылка «Назначить» с
  Главной (`#unassigned-stays`) открывают боковой ящик. Карточка на каждое проживание без ячейки: гость,
  даты с ночами, категория, слово о брони и номер; ниже — свободные места на весь срок брони чипами,
  по умолчанию выбрано первое, кнопка «Назначить R04» и «Открыть бронь».
- **Без N+1 (условие владельца).** Места грузятся только у выбранной карточки: первая выбрана сама,
  остальные — «Подобрать место». Один `GET /availability` на выбор, повторный выбор тех же дат — из
  памяти; после назначения память сбрасывается, потому что место занято. Проверено счётчиком запросов
  стенда: строка над сеткой — 0 запросов, открытие ящика — 1, выбор второй брони — ещё 1.
- **Назначение** — существующая команда `assign` с заезда брони, та же, что форма карточки. Итог
  назван строкой в ящике: уведомление в углу закрыто модальным окном. Последняя бронь размещена —
  ящик закрывается вместе со строкой.
- **Своих мест нет.** «Нет доступных мест в категории» и «Посмотреть другие категории» — места других
  категорий по порядку сетки. Размещение там переоценивает проживание (правило `assign`), поэтому
  сначала вопрос с разницей стоимости из предпросмотра переезда — как окно переселения PR 4.
- **«Только чтение»** (ADR-102) — места видны, вместо кнопки «Только чтение: назначить место нельзя».
- **API.** В ответе шахматки у брони без ячейки добавлены `itemId` (его берёт `assign`) и `guestLabel`
  (тем же правилом, что у плашек сетки). Только чтение, схема не менялась.

## Что не делалось и почему

- **Правила посадки** — свои не придуманы: места считает `/availability`, цену — предпросмотр `assign`.
- **Клавиатура шахматки** — PR 7; ящик сам по себе клавиатурный (кнопки, Escape закрывает).
- **Вопросы с прошлых гейтов** — §30 (сокращение) и показ отменённых и незаездов на сетке — владелец
  не решал; в PR 6 не трогались.
