## Что сделано

- **Строка над сеткой (§8).** Поиск, «Категория», «Места на {первую дату}» (Все / Свободные /
  Занятые / Уборка N / Недоступны), «Фильтры N», «Вид». Сегменты «Все места / Номера / Койко-места»
  и чипы состояния из строки ушли: тип места — в окошко, состояние — полем. Вторая строка появляется,
  только когда что-то отобрано: условия чипами с крестиком, «Показано N из 88 мест», «Сбросить».
- **Окошко «Фильтры» (§9).** Правится черновик: «Применить» переносит его на сетку, Escape, крестик и
  щелчок мимо закрывают без применения, «Сбросить» чистит черновик. Внизу — сколько мест подойдёт.
  Группы: «Тип места»; «Брони» — «Заезд сегодня», «Выезд сегодня», «Проживают», «С долгом»;
  «Источник» и «Статус брони» — только те, что есть на загруженной сетке. Ссылка «Брони без
  назначенного места: N» открывает ящик PR 6. У выбранного пункта галочка: выбор виден не только
  цветом.
- **Правило отбора** (`chessboard/board-filters.ts`): внутри группы «или», между группами «и»; строка
  места видна, если в окне на ней есть подходящее проживание; неподходящие плашки приглушены.
  «Заезд сегодня» — первая ночь сегодня; «Выезд сегодня» — последняя ночь вчера; «Проживают» —
  заселён; «С долгом» — остаток счёта больше нуля, то же правило, что «к оплате» на плашке.
- **Поиск (§10, §41).** Имя, телефон (цифрами, от трёх, как ни записан), номер брони, код места,
  категория. Совпавшая плашка обведена одной рамкой на весь отрезок, остальные приглушены; нашлось
  само место — выделена его колонка. Свёрнутые категории с совпадениями раскрываются (память
  свёрнутости не меняется), сетка прокручивается к первой найденной, Enter открывает её.
- **Ничего не найдено (§37)** — «Ничего не найдено», «Попробуйте изменить фильтры», «Сбросить фильтры».
- **Вид (§38)** — «Компактный / Обычный / Подробный», выбор помнится в браузере. «Обычный» — вид,
  принятый на гейтах PR 2–3; компактный — строки 32 px и только имя; подробный — 56 px, вторая строка
  плашки (источник, ночи, долг) не прячется на узких плашках.
- **Клавиатура (§40).** Escape закрывает окошки и ящик (как было); Enter на плашке — предпросмотр
  (с PR 3); Enter в поиске — первая найденная бронь; Ctrl/Cmd+K на шахматке ставит курсор в её поиск,
  второе нажатие открывает общий поиск.
- **Телефон (§45).** В строке поиск, «Фильтры» и вид; категория и места — в окошке, их условия
  чипами; окошко во весь экран без выхода за край, цели 44 px.
- **Стенд UI-тестов.** Подставной API не отдавал телефон гостя в клетке шахматки, а настоящий
  отдаёт (`chessboard.repository`) — выровнено, иначе поиск по телефону не проверить.

API, домен, модель данных и команды не менялись: всё считается по уже загруженной сетке.

## Что не делалось и почему

- **«Без оплаты»** — в клетке сетки нет оплаченной суммы, только остаток.
- **«Заблокированные» отдельно от «Недоступных»** — на сетке одно состояние BLOCKED; делить по типу
  блокировки значит придумать правило.
- **«Отмена» и «No-show» в статусах** — таких броней на сетке нет (вопрос владельцу с PR 3).
- **Память фильтров после обновления страницы** — §52, это PR 8.
- **«Выезд сегодня» на неделе, начатой сегодня** — вчерашней ночи в окне нет, и такая бронь не
  найдётся; на текущей календарной неделе со вторника и позже находится.

## Нерешённые вопросы — за владельцем, в PR 7 решений по ним не принималось

1. **Ссылка «WA» на плашке заезда.** У гостя с телефоном на первой ночи брони — ссылка «WA» (написать
   в WhatsApp). Она стоит поверх имени (`search-one.png`, `view-detailed.png`), а ТЗ §19 говорит не
   показывать телефон на плашке постоянно. До PR 7 её не было видно на снимках: стенд не отдавал
   телефон. Варианты: убрать с плашки, перенести в предпросмотр брони, оставить. Прежнее поведение,
   в PR 7 не трогалась.
2. **Сокращение проживания (§30).** У смены дат нет предпросмотра суммы, она меняет всю бронь и не
   разрешена заселённым — вопрос с PR 4.
3. **Отменённые и незаезды на сетке.** API шахматки их не отдаёт; показать — значит менять API. Вопрос
   с PR 3.
4. **Память фильтров после обновления страницы (§52).** По плану это PR 8; PR 8 не начат и без
   отдельной команды не начинается.
