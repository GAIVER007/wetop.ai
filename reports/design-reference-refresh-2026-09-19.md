# Обновление эталонов экранов `design/reference/current` — 19.09.2026

**Зачем.** Сорок снимков экранов (шаг 1 плана дизайн-системы, сырьё для макетов шага 6) были сняты 16.09 —
до срезов 7.1–7.4 и сегодняшних правок. Владелец загружает их в Claude Design и рисует макеты по ним;
устаревшие снимки дали бы макеты против экранов, которых уже нет. `DESIGN.md` §18 п. 2 требует
сравнения «до / после» — оно ниже.

**Откуда снимки.** Тот же спек `tests/ui/design-reference.spec.ts` на синтетическом API после
`POST /__test/design-seed`, из полного прогона UI-набора 19.09 (120 из 120, лог
`tests/runs/logs/2026-09-19T11-34-27Z-e2e-6f68.log`). Только псевдонимы (ADR-010, ADR-018).

**Как сравнивалось.** `npm run design:diff -- <копия 16.09> <снимки 19.09>` — попиксельно в Chromium
(`scripts/design/diff-screens.ts`), порог 24 по сумме каналов.

## Что изменилось и почему

Отличаются все 40 снимков. Три причины, по убыванию веса:

1. **«Сегодня» фикстуры сдвинулось с 16 на 19 сентября.** Синтетический API ставит брони и блокировки от
   текущей даты, поэтому на шахматке, главной, «Бронях», «Гостях» и карточках сменились даты, столбцы и
   положение плашек. Это не правка интерфейса, а живые данные — их доля в проценте самая большая
   (шахматка 18–28 %, «Брони» 8 %, главная 10 %).
2. **Срезы 7.1–7.4 (17–18.09):** на шахматке легенда с глифами `✓ • ? ✕ ▨`, на плашке канал словом
   («Booking.com», «Trip.com») и «к оплате N ₸», бейдж «грязно» в строке ячейки, плашка «входящая бронь
   требует разбора» над сеткой, «Без ячейки» с датами словами и числом ночей; на «Каналах» — таблица
   очереди отправок (`channels-full-*` выросли по высоте 1090 → 1486 px); на календаре цен — правка цены в
   ячейке и русские заголовки (`rates-full-*` 1823 → 1853 px); деньги везде «12 500 ₸» без тиынов, даты
   словами внутри `<time>`, группы меню без капса, пустые значения «—».
3. **Правки 19.09:** штриховка блокировки на шахматке (на снимках 16.09 блокировка R09 — ровная розовая
   заливка, теперь косая штриховка: `.board__free { background: transparent }` из `premium.css` гасила
   `background-image`); тип блокировки словом в подсказке.

Смена панелей карточки брони (7–12 %) — даты и деньги по п. 1–2, раскладка не менялась. `rooms-*` и формы
брони (0,2–0,6 %) — только живые часы, как в сравнении 16.09.

## Что это значит для шагов 5–6

Пакет `design/claude-design-manifest.md` ссылается на эту папку — загружать в Claude Design нужно снимки
19.09. Промпты макетов (`design/prompts/01…08`) описывают экраны словами, их править не нужно: они и так
называют плашку с каналом и долгом, легенду с глифами и очередь отправок как то, что уже есть в коде.

## Как повторить

```sh
cp -r design/reference/current /tmp/ref-before
UI_BROWSER_CHANNEL=chromium npm run test:record -- e2e --config tests/ui/playwright.config.ts --workers=1 design-reference
npm run design:diff -- /tmp/ref-before
```
