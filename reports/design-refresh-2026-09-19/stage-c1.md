# WETOP — шахматка C1

19.09.2026. Основание: утверждённый `tasks/plan.md`, продолжение «давай»,
`plans/design-and-connections-2026-09-19.md`, ADR-050. Это C1, не завершение C2 или всего редизайна.

## Изменения

- Даты «С» и «По», поиск и категория имеют видимые подписи. Для 14 дней явно обозначен текущий вид.
- Инструкции и легенда собраны в раскрываемый блок; он не выходит за экран на 1440/1024/768/390 px.
- Статус фильтров подписан конкретной датой: это состояние на начало периода, а не на все его дни.
- На телефоне дополнительные фильтры раскрываются кнопкой со счётчиком. Поиск, число найденных
  мест и сброс остаются доступны; закрытие блока не сбрасывает выбранные фильтры.
- Даты, виды, стрелки и фильтры на телефоне имеют цели касания не менее 44 px.
- Исправлено обрезание нижних строк на узких экранах: страница прокручивается, сетка сохраняет
  свой скролл и закреплённые даты/номера. На 320×844 последняя строка F36 полностью доступна.

UI/UX Pro Max использован для подписей, раскрываемых вторичных фильтров и мобильных целей касания.
Переиспользованы существующие компоненты/токены. Новых зависимостей нет.
Предикаты фильтрации, drag/preview/подтверждения, DTO, цены, деньги, модель и API не изменены.

подключений: Next сохраняет скрытый предыдущий экран. Селектор ограничен видимым `main`,
этот сценарий зелёный в повторе 22/22. Один полностью зелёный полный прогон после всех правок
пока не выполнен; контрольная точка C в задачах поэтому остаётся открытой. Проверки не отключались.

Prettier для пяти изменённых файлов проходит. Production-сборка web успешна, 25/25 статических
этапов; динамические маршруты остались request-time. Команда:

```sh
APP_UI_TEST=1 APP_API_URL=http://127.0.0.1:4319 APP_DEMO_MODE= APP_ALLOW_TEST_DATA= npm run build -w apps/web
```

Отдельный `.next-ui`, без обращения к рабочему API и без перезапуска 3000/3001.
Первый lint был заблокирован sandbox на локальном IPC `tsx` (EPERM); повтор вне sandbox прошёл.
Это не ошибка продукта.

## Оставшиеся работы и связь

Просмотр: `http://127.0.0.1:3100/chessboard`, явно обозначенный демо-режим.
C2 с доступными действиями выполняется после карточки брони B3; следующий UI-срез — список B1.
Этот агент не менял туннель, DNS, службы рабочего API, базу, архивный источник или провайдеров.
Во время финальной проверки появился отдельный коммит `ca4d478` о переносе на Hostinger
(`reports/domain-move-2026-09-19.md`). Свежие GET подтвердили 200 для сайта и публичных JS,
404 для закрытого `/reservations`, 302 на Access для кабинета. План обновлён: второй туннель
на Mac не запускать. Состояние конкретного сервера и end-to-end доставка Channex не доказаны
этими GET; детали и границы — в обновлённом плане.

Ultragoal: фактическое завершение C1 подтверждено здесь и аннотацией ledger. Учётный checkpoint
не подделывается: Codex `get_goal` продолжает возвращать ранее выставленный `blocked`, хотя
владелец разрешил UI-работу. Доступные инструменты не переводят этот статус обратно в `active`;
финальная цель и остальные разделы не объявлены завершёнными.
