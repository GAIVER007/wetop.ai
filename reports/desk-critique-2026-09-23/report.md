### Попутно: «все счета оплачены» рядом с долгом

Число «Долг уезжающих» из API — это долг тех, кто **ещё живёт** (`CHECKED_IN`). Гость, которого сегодня
выселили с долгом (в фикстуре — 16 000 ₸), в это число не входит. Поэтому полоса писала «все счета
оплачены», а блок ниже рядом показывал «К оплате 16 000 ₸».

Число, которое сверяет `cli-system-trace.ts` (`c-debt`), не менялось. Теперь под ним ссылка «выехавших с
долгом: N» (или «не заехавших с долгом: N»), она ведёт к списку задач. «Все счета оплачены» пишется только
тогда, когда долгов у уезжающих нет вовсе. Бизнес-правил это не касается: те же данные дня, другая
подпись.

### Попутно: фикстура расходилась с API

«Не заехал вовремя» в `scripts/preview/fixture-api.ts` не ограничивал дату выезда. API берёт только
проживания, которые касаются суток (`desk.repository.ts`: выезд не раньше дня). Поэтому пустой день
2027-06-01 в фикстуре показывал четыре просроченных заезда — брони, закончившиеся в сентябре. Граница
добавлена, как в API.
