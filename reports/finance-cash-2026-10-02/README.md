# Касса (DATA_MODEL §21, ADR-135) — отчёт среза K1–K3, 02.10.2026

Поручение владельца со снимками кассы старой системы; «давай делай» = утверждение §21 и умолчаний
Q-245…Q-248. План — `plans/finance-cashbox-2026-10-02.md`. Коммиты: `bdc81108`, `2c79f127` + финальный.

## Что сделано

- **K1.** Миграция `20261002000040_cashbox` (+`down.sql`): `cash_categories`, `cash_operations`,
  enum `CashOperationKind`; CHECK — сумма > 0, перевод в другой способ и без статьи,
  `EXTERNAL`/`DEPOSIT`/`CARD_GUARANTEE` не участвуют; триггер «статья своего объекта»; RLS `rls_tenant`
  (таблицы вписаны в `RLS_TENANT_TABLES` → обход изоляции покрывает их сам). Домен
  `packages/domain/src/finance/cash.ts`. Остаток по способу вычисляется — гостевые оплаты в кассу
  не дублируются.
- **K2.** `GET /finance/cash` (остатки за всё время + статьи одним ответом — бюджет 10 запросов на
  экран), `POST /finance/cash/operations|transfers` (комиссия суммой или % — связанный расход
  `related_id` одной транзакцией; статья по умолчанию «Комиссия банка»), `POST …/:id/void`
  (комиссия аннулируется с основной; комиссию отдельно — 409), `POST/PATCH /finance/cash/categories`
  (стартовый набор Q-245 при первом чтении). Права Q-247: `desk` / `refunds` / `settings`
  (`route-access`). Журнал на каждую запись. Общая лента `GET /finance/operations`: пять типов +
  отбор `source=RESERVATIONS|CASH`.
- **K3.** Вкладка «Касса» (плитки остатков, «Поступление/Расход/Перевод» панелями, статьи,
  «только чтение» — без кнопок), лента «Операции за период» (чипы источника и типов, колонка
  «Гость / статья», перевод «откуда → куда», расход с минусом, «Аннулировать» с вопросом),
  CSV + «Статья;Комментарий». Подставной API выучил кассу.
