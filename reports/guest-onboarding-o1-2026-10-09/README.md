# Гостевой мастер `/create`, срез O1 (09.10.2026)

План: `plans/guest-onboarding-ai-seller-2026-10-09.md`, раздача по сессиям: `plans/guest-onboarding-orchestration-2026-10-09.md`.

## Что сделано
- Первый экран один: сценарий, адрес сайта, «Продолжить», ссылка «или заполнить вручную, без сайта».
- Сценарий «Поддержка сайта» показан, но не выбирается («скоро»): в черновик пишется только `sales`. Снимет срез O3.
- Адрес без схемы принимается как `https://…`; домен `.kz` и `.ru` подставляют валюту и пояс.
- Проверка данных: ниша выбором, обязательны название и ниша, пометка «найдено на сайте» (наполнит O2).
- Сборка: опрос из трёх вопросов, «Пропустить» одним нажатием; «Протестировать бота» пока неактивна.
- Возврат: баннер с шагом, «← В начало». Все строки в `create/strings.ts`.
- API: `POST /wizard/survey`, `POST /wizard/event` (с браузера только `source_submitted` и `testbot_cta`).
