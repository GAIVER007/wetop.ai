# Гостевой мастер — ручной черновик, 26.09.2026

## Реализовано

Публичная страница `/create` без гостиничного кабинета: старт, ручной ввод,
живое превью, сохранение и автосохранение после паузы, восстановление после reload.
Черновик проходит через фиксированный Next proxy в Nest и PostgreSQL.
Ошибки сохранения сохраняют ввод; истёкшая сессия позволяет явно начать новый черновик.
Проверяются источник запроса, операция, формат токена и размер тела.

## Границы этапа

Это ручной черновик, а не готовый запущенный агент. Scan/generate, тестовый чат,
атомарное списание квоты, complete после регистрации, trial и каталог агентов ещё впереди.
Не включать публичные гостевые API до защиты от злоупотреблений и решения бюджета/TTL.
WIZARD_ENABLED выключен по умолчанию. Production migration не выполнялась.
Push в draft PR не означает публикацию на app.wetop.ai.

Production-сборка web: `APP_UI_TEST=1 npm run build -w apps/web` — PASS.
Флаг изолирует каталог `.next-ui` от работающего локального dev-сервера.
Next сообщает существующее предупреждение о будущем переходе middleware → proxy.
