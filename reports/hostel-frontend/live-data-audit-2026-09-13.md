# WETOP: реальные данные и проверка интерфейса

13 сентября 2026. Код подготовлен по поручению владельца. **Подключение к настоящему Channex
пока не выполнено:** в этой копии отсутствуют рабочий API, DATABASE_URL и CHANNEX_API_KEY.
У владельца запрошен адрес уже настроенного backend либо путь к его окружению, без секретов в чат.

## Что исправлено

- Обычный localhost больше не использует тестовые брони и суммы. Production запрещает синтетический
  источник даже при переданном флаге тестов; fixture API требует отдельного заголовка до обработки команд.
- Нули выводятся только из успешно полученных пустых ответов. При недоступном API показана ошибка,
  а не нулевая выручка. Реальные записи, seed-данные и счета не удалялись.
- `/connections` проверяет доступ к объекту Channex отдельным GET, показывает сопоставления и время
  последних webhook/pull. Есть кнопка повторной проверки, частичные ошибки не маскируются.
- Импорт броней обновляет отчёты и списки; изменение сайта — маркетинг и подключения.
- Исправлены отказ копирования кода без обратной связи, потеря состояния загрузки тарифов виджета,
  неверный период финансов. Для уборки/снятия блокировки добавлено ожидание; поля блокировки подписаны.
- Сокращены подписи, рекламные и повторяющиеся пояснения. Справка раскрывается по необходимости.
  Показатели центрированы; карточки и формы имеют единые отступы и выравнивание.

Это настоящий браузер и Next.js/server actions с **изолированным синтетическим HTTP API**.
Тестовые записи используются только внутри этого набора. Реальные транзакции БД, каждая комбинация
действий в карточке, OTA доставка, все печатные формы и нагрузка множества сотрудников этим
браузерным набором не доказаны. Контроллеры и доменная логика дополнительно проверены unit-тестами.

## Чего не хватает

1. Адрес рабочего backend и его настроенное окружение. Затем — проверка GET объекта Channex,
   сопоставлений всех категорий/тарифов, актуальности PMS и последней доставки событий.
2. Для приёма webhook — постоянный публичный HTTPS-адрес, секрет и регистрация callback.
   Их наличие на действующем сервере пока не проверено.
3. Редакторы акций, промокодов, фото, удобств, категорий, каталога услуг и реквизитов объекта.
   Сейчас соответствующие данные доступны для просмотра либо раздел отмечен как не подключённый.
4. Роли/права, авторизация SaaS, изоляция разных объектов и маркетинговые кампании.
5. Проверка с доступной dev/staging БД: конкурентная бронь, переселение, выезд с долгом, реальные
   расчёты и доставка Channex. Production OTA/ARI команды и действия с реальными гостями не запускались.
6. Нагрузочные измерения и проверка инфраструктуры. Скорость тестовой шахматки не заменяет эту проверку.
