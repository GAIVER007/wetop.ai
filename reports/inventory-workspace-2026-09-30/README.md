# Номерной фонд: компактный каталог и создание с нуля

30.09.2026. Согласованный план: компактная сводка и каталог; фильтры; сохранение контекста панели; создание номеров/комнат с койками/категорий; проверка пустого аккаунта, push/deploy.

## Изменения

- Компактные сводка, шапка и строки; закреплённые заголовки списка, отдельная прокрутка каталога на desktop. На телефоне обычная прокрутка и доступная горизонтальная таблица, альтернативно карточки.
- Поиск, категория, тип, корпус, этаж, состояние и уборка. URL сохраняет условия при reload и возвращении из панели. Наличие блокировки не смешивается с занятостью на даты.
- Добавление номера/коек доступно с пустого фонда: если нужной категории нет, сначала открывается её создание с правильным типом; затем переход к комнате. Исключён случай случайного выбора категории другого типа.
- В форме комнаты виден предпросмотр расположения, категории и обозначений мест.
- Используются прежние API и модель, без миграций. Создание отеля остаётся в существующем онбординге; добавление нескольких отелей не внедрялось этим UI-срезом.
