## 7. Чем доказано состояние сведённой ветки (Linux-контейнер, 16.09.2026)

Все прогоны — через `npm run test:record`, строки и логи в `tests/runs/`.

| Набор | Итог | Примечание |
|---|---|---|
| typecheck | без ошибок | |
| lint | без ошибок | |
| unit | 1116 из 1119, 3 пропущено | пропущены три случая `launchd-install`, им нужен macOS |
| миграции с откатом | 15 из 15, `RESULT: OK` | `scripts/ops/check-migrations.sh` на чистом PostgreSQL 16 |
| integration | 26, 5 пропущено | локальный PostgreSQL 16, сид из аудита (`TEST_DATA=seed`); пропущены тесты, которым нужны ключи Exely/Channex |
| e2e | 25 из 25 | тот же PostgreSQL, стойка в production-сборке; `CHROMIUM_PATH=/opt/pw-browsers/chromium` — установленный Playwright ждёт Chromium 1243, в контейнере 1194 |
| сборка стойки | проходит | после починки: `ApiError` и `apiErrorStatus` вынесены в `lib/api-error.ts` (см. ниже) |
| UI-набор (`tests/ui`, синтетический API) | 123 из 123 | `UI_BROWSER_EXECUTABLE=/opt/pw-browsers/chromium`; первый прогон 122/123 — тест экрана ошибки из PR #10 ждал падения «Главной», переведён на «Номерной фонд» |

Что нашлось и починено по дороге (по отдельности ветки были зелёными, вместе — нет):

1. **Сборка стойки падала.** Клиентский экран ошибки из PR #10 брал `apiErrorStatus` из `lib/api.ts`, а `lib/api.ts`
   из PR #11 тянет `session.ts` с `next/headers`; в клиентском бандле Turbopack это ошибка сборки. Класс ошибки и
   разбор `digest` вынесены в `lib/api-error.ts` без серверных зависимостей, `api.ts` их реэкспортирует.
2. **`desk-day` падал на двух копиях `c-arrivals`.** «Главная» после PR #11 отдаёт полосу стойки отдельным потоковым
   куском (`Suspense`), а фикстура из PR #10 ждала только скрытый сегмент со всей страницей. Фикстура ждёт ухода любого
   сегмента, тест читает счётчики внутри региона «Сегодня на стойке».
3. **Снимки экранов из контейнера в коммиты не идут** (`reports/screenshots`, `reports/ui-quality`): рендер другой,
   на них должны оставаться снимки с живых данных с машины стойки.

Не проверено отсюда: живая dev-БД Supabase, Exely, Channex, launchd, туннель — только с машины стойки.
