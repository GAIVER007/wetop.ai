24.10.2026. Изолированная ветка codex/wetop-mobile, без общей базы и чужих файлов. Регистрации нет, используются ранее выданные веб-доступы.

## Границы проверки

Fixture API и gateway unit-тесты проверены отдельно. Не выполнен сквозной вход через настоящий Nest API и базу. Не выполнены production-вход, публикация шлюза, native runtime, SecureStore на устройстве, IPA/APK. xcrun не находит simctl; adb не доступен. Наличие собранных bundles не закрывает эти проверки.

Шлюз выключен по умолчанию. До включения нужна проверка согласованного HTTPS-окружения, proxy/IP rate limiting и штатный процесс выпуска. APP_API_URL остаётся серверной настройкой, клиент не получает служебные ключи.

## Дальше

Ресторан: отдельный проверенный allowlist меню/столов/заказов и серверные права. POST orders сразу отправляет позиции, отдельного send нет. PATCH принимает полный состав и expectedStatus/expectedUpdatedAt. Автоматический повтор создания после сетевого таймаута недопустим: текущий API не принимает ключ идемпотентности. До готовности восстановительного сценария не заявлять защиту повторного создания при неопределённом исходе.
