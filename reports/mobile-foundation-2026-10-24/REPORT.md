# Mobile foundation: проверка 24.10.2026

Реализована демонстрационная основа приложения в codex/wetop-mobile от ff3e1bc211f9cb6fb23162262d799723279885ae. Полноценное приложение ещё не готово: вход, права, контекст бизнеса и реальные данные относятся к следующим модулям.

## Реализация

Отдельный пакет apps/mobile: Expo Router, Сегодня, Меню, галерея компонентов; светлая/тёмная тема из токенов WETOP; Screen, ActionButton, FormField, StateView и NavigationShell. Пять состояний: загрузка, пусто, нет сети, нет доступа, ошибка. Никаких имитаций рабочих показателей. Native зависимости отделены от web React собственным lockfile. Корневые версии зависимостей сохранены.
