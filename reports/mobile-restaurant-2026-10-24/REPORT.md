# Мобильный ресторан: чтение столов и заказов

Дата: 2026-10-24. Ветка: codex/wetop-mobile.

Добавлены защищённый экран ресторана, свои столы сотрудника, серверный список открытых заказов, постраничная загрузка, состав заказа и обновление. Смена контекста отбрасывает поздний ответ. Ответ 401 закрывает локальный доступ. Денежные строки форматируются через BigInt без потери точности; символ тенге задан явно для одинакового вида в разных локалях.

Gateway разрешает только GET tables/orders с bearer и обязательным business/location scope. Сервер сохраняет свои ограничения прав. Cookie/service key не передаются, поля ответов ограничены, размеры и время ожидания ограничены. Публичный gateway остаётся выключенным.
