# Касса ресторана на телефоне

Дата: 2026-10-24. Ветка: codex/wetop-mobile.

В защищённом кабинете ресторана добавлен просмотр остатков филиала по способам оплаты и последних 100 оплат. Суммы берутся из серверных строк minor units и показываются без вычислений через floating point. Время оплаты выводится в timezone филиала. Экран доступен для роли стойки, а окончательное право `branch.cash` проверяет сервер. Официанту и бармену с ролью EMPLOYEE пункт не показывается.

Экран намеренно не называет остатки выручкой. Последние 100 оплат не используются для расчёта дневных итогов. Оплата, возврат и закрытие смены здесь не вызываются.

Проверки: красные тесты клиента и gateway, затем 39/39 мобильных тестов (запись `2026-10-25T06-25-38Z-mobile-4b42`), 13/13 gateway (запись `2026-10-25T06-24-58Z-unit-f572`), типы mobile (запись `2026-10-25T06-27-35Z-mobile-types-a638`), типы web и целевой lint. На синтетическом локальном сервере экран проверен в браузере при 375 px, горизонтального переполнения и ошибок консоли нет. Экспорт Expo для iOS, Android и web прошёл. Native runtime и реальные права на сервере ещё не проверялись.
