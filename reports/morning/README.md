# Утренние отчёты

Одно правило: отчёт делается **каждое утро до начала работы** командой

```
npx tsx scripts/reconciliation/src/cli-morning-report.ts
```

Скрипт пишет сюда `<дата>.md` (дата — по Алматы; другую дату можно передать аргументом `YYYY-MM-DD`):
сделано вчера по git log, последние сверки и их RESULT, итог прогона тестов, открытые вопросы владельцу.
Разделы «Не сделано / перенесено» и «План на сегодня» заполняются руками сразу после запуска.

Короткая форма той же команды: `npm run morning`. Отчёт за сегодня кладётся в `reports/morning/<дата>.md`;
два последних раздела («Не сделано / перенесено», «План на сегодня») заполняются руками до начала работы.
