## 1. Кто строит навигацию

| Файл | Что делает |
|---|---|
| `apps/web/src/lib/navigation.ts` | Реестр `navigation` (пункты с `href`, подписью, иконкой, правом `requires`), состав меню `menuSections` (гостиница), `beautyMenuSections`, `foodMenuSections`; `menuSectionsFor(access, vertical)` отбирает пункты по праву; `phoneNavigationFor(vertical)` даёт 4 пункта нижней панели; `activeNavigation` (самый длинный префикс по реестру, `/ai-seller*` считается `/ai-agents`); `activeMenuRoute` сводит `/hotel-settings*`, `/rooms*`, `/channels*`, `/website` к корню; `routeRule` отдаёт право страницы для `AccessGate` |
| `apps/web/src/lib/desk-shell.ts`, `desk-person.ts` | Один `/auth/me` на отрисовку. Вертикаль из `me.context.vertical`, подтверждённая API по куке `wetop_scope`; без неё гостиница. `PENDING_ACCESS` (как администратор) пока ответа нет |
| `apps/web/src/components/top-nav.tsx` | Шапка `.workspace-header`: строка 1 (бургер до 960 px, знак WETOP, блок объекта с переключателем, кнопка поиска, «Демо», тема, профиль), строка 2 `TopMenu`; ниже нижняя панель телефона, окно «Навигация» с `Sidebar`, поиск, тур. Экран «Переключаем филиал…» при смене |
| `apps/web/src/components/shell/top-menu.tsx` | Строка вкладок от 961 px. Группа: кнопка `aria-expanded` и список (disclosure), одна открытая, Escape с возвратом фокуса, щелчок мимо закрывает. Стрелок нет. Пока `/auth/me` не ответил, строка пустая (fallback `null`) |
| `apps/web/src/components/shell/sidebar.tsx` | Меню в окне «Навигация» (до 960 px): блок объекта, разделы, пробный срок, ссылка на `/profile` внизу. Активную группу ищет только в гостиничном `menuSections` |
| `apps/web/src/components/shell/branch-switcher.tsx`, `property-block.tsx`, `app/branches/actions.ts` | Переключатель филиала: список по `GET /branches`, выбор server action `selectBranch` (кука, `revalidatePath`, переход). Вертикаль филиала и бизнес в списке не показаны |
| `apps/web/src/components/shell/account-menu.tsx` | Меню профиля: имя и почта, «Выйти». У гостиницы перед ним «Обучение работе в WETOP» |
| `apps/web/src/components/shell/search.tsx` | «Быстрый поиск» гостиницы: переход в список гостей, бронь или место по введённому, плюс «Быстрый переход» по названиям разделов |
| `apps/web/src/components/control-navigation.tsx`, `team-navigation.tsx` | Ряды подразделов на `/incidents` (Неисправности, Журнал операций) и на `/team`, `/journal` (Сотрудники, Журнал операций). Страничные, не оболочка |
| `apps/web/src/lib/vertical-guard.ts` | `requireVertical`: чужая вертикаль уходит на `/today` |
| `apps/web/src/lib/vertical-landing.ts`, `scope-resolve.ts` | Посадка `/today` для всех трёх; таблица `routes` решает только, можно ли вернуть на `next` после выбора филиала |
| `apps/web/src/middleware.ts` | Заголовки пути и безопасности. Перенаправлений нет |

Размеры: `--header-h` 100 px = `--header-row-h` 56 + `--header-menu-h` 44 (`design/tokens.json`); до 960 px шапка 60 px литералом в `workspace.css:391-405`. Шапка `sticky` со стеклом (`--glass`, blur 16 px). Ширины: до 1279 скрыта подпись профиля и свежесть каналов, до 960 нет строки вкладок (бургер), до 600 нижняя панель из 4 пунктов и «Ещё». Защиты от переполнения строки вкладок нет (у `.topmenu` намеренно нет `overflow`, иначе обрежется список группы); на 1024, 1280 и 1440 это проверено тестом только у гостиницы.
