# Справочники объекта: способы оплаты и статьи кассы (07.10.2026)

План: `plans/property-directories-2026-10-07.md`. Решение: ADR-152. Модель: `DATA_MODEL.md` §21.6 (v2.13),
миграция `20261007000062_payment_method_settings` (+`down.sql`, RLS `rls_tenant`). Ветка
`claude/youthful-wozniak-vin0pp`, PR #271. Владелец: «да давай делай дальше сам».

## Что увидит владелец

«Настройки объекта» получили четвёртую вкладку **«Справочники»** (`/hotel-settings/directories`):

1. **Способы оплаты.** Восемь системных способов таблицей: флажок «Принимаем», кнопки «Выше» и «Ниже».
   Сохранение той же кнопкой в шапке, что у «Основного» и «Проживания». Выключенный способ не предлагается
   при приёме оплаты в брони, в групповой оплате, при замене платежа, в операциях и переводах кассы и в
   запросах оплаты; API отказывает словами «Способ оплаты «Kaspi» выключен в настройках объекта». Прошлые
   платежи, отчёты, отбор операций и сверка не меняются. Внешний канал (платёж площадки) здесь не
   настраивается. Хотя бы один способ должен быть включён. Плитки кассы: четыре по умолчанию плюс способы с
   движениями, порядок по настройке; выключенный без движений плитки не получает.
2. **Статьи кассы.** Список со статусом, добавить (тип и название), переименовать строкой на месте,
   выключить и включить. Удаления нет: прошлые операции хранят статью. В «Финансы → Касса» вместо кнопки
   «Статьи» ссылка «Статьи кассы» сюда: редактор один.

Без права `settings` (администратор) раздел закрыт, как остальные «Настройки объекта»; в «только чтении»
таблицы без кнопок.
