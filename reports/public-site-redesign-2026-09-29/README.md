# Публичная страница WETOP — 29.09.2026

## Логика блоков

1. **Первый экран.** Обещание единого рабочего пространства, демонстрационный интерфейс, регистрация и переход к возможностям. Вход остаётся в шапке. Пробный срок соответствует текущему `TRIAL_DAYS=14`.
2. **Путь брони.** Пять переключаемых этапов: запрос → бронь → гость → оплата → отчёт. Каждый объясняет связь данных и результат этапа. Это иллюстрация, не запись в рабочую базу.
3. **Возможности.** Пять вкладок по задачам: брони/гости, фонд, каналы/тарифы, финансы, ИИ-продавцы. В каждой — назначение, три действия и помеченный пример интерфейса. Полная навигация стрелками/Home/End.
4. **Направления.** Hospitality с компактной шахматкой и сценариями хостела, мини-отеля, апарт-отеля. Beauty явно обозначен будущим направлением.
5. **FAQ.** Шесть ответов о размещении, текущих направлениях, агентах, каналах, браузере и начале работы. Native details работают без JS.
6. **Старт.** Три последовательных шага, регистрация, реальные контакты, ссылка на приложение. Существующие формы входа/регистрации сохранены.

Повторяющиеся статистические обещания, витрина экранов и второй список возможностей убраны из композиции. Числа демонстрационного интерфейса не выдаются за статистику клиентов WETOP. Учет оплат не описывается как эквайринг. Для AI и каналов явно указана необходимость настройки.

## Визуальная система

Крупная типографика, общий ритм отступов, семантические цвета проекта. Акцентный первый экран, двухколоночные объяснения, ограниченные переходы при смене панели и наведении. Темы: системная по умолчанию, явный выбор сохраняется в браузере. `prefers-reduced-motion` отключает переходы. Новых runtime-зависимостей нет.
