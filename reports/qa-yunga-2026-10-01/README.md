## 2. Безопасная очистка тестовых записей (запускает владелец, на сервере)

`scripts/ops/retire-test-entities.mjs`: только явные идентификаторы, по умолчанию dry-run (ROLLBACK), запись только с
`--apply`; ничего не удаляет, ставит `active=false` через существующие поля и кладёт образ «до» в `audit_logs`
(`qa.retireTestEntity`). Отклоняет запись целиком, если её что-то держит: место с размещениями; категория с бронями,
тарифами, сопоставлениями каналов или действующими местами; тариф с бронями, сопоставлениями, сайтом или
действующими производными. Брони, гости, счета, цены, блокировки и уборка не читаются и не меняются.

```
DATABASE_POOL_MAX=1 node scripts/ops/retire-test-entities.mjs \
  --unit YUNGA-TEST-20261001 \
  --category category-74665316-234f-4968-aeec-685bcefa71d4 \
  --rate-plan rate-8593e4c8
# прочитать вывод; затем то же с --apply
```

категория с действующим местом отклоняется, пока место не выключено; `--apply` выключает место, категорию и тариф,
три строки журнала, действующих мест снова 88; повтор отклоняется («уже выключено»); тариф стенда с бронями
