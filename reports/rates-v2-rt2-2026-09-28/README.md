# «Тарифы и цены» RT2 — снимки для подтверждения владельца (28.09.2026)

RT2 по слову владельца 28.09 («Вид RT1/RT1.1 подтверждаю. Начинай RT2»), план — `plans/tz-rates-v2-2026-09-27.md`
§8, решение — ADR-111. После RT2 — снова STOP: RT3 (ограничения) только после отдельного подтверждения.
Стенд — подставной API UI-набора, цены вымышленные: будни 10 000 ₸ за 2 гостей и 8 000 ₸ за 1 гостя,
выходные 3–4 окт. — 12 000 ₸.

Сохранение — существующий `POST /rates/bulk`: одна строка на меняемую вместимость, все одним запросом,
то есть одной транзакцией с журналом и очередью каналов. После успеха — уведомление на 4 с, выбор
сброшен, календарь перечитан; постоянной зелёной плашки нет.
