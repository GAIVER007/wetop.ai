# Регистрация открыта по поручению владельца — 20.09.2026

## Изменение

Владелец прямо отменил закрытие самостоятельной регистрации. Отсутствующий или
пустой REGISTRATION_OPEN теперь открывает регистрацию; 1 разрешает явно, 0 и
неизвестные непустые значения запрещают. В .env.example задано 1. API остаётся
единственным источником настройки формы через GET /auth/options; отдельного
APP_REGISTRATION_OPEN больше нет. Ошибки API не выдают пользователю сессию.

Модель аккаунтов, действующие пользователи, хеширование пароля, срок сессии,
приглашения и восстановление пароля сохранены. Миграций нет. Q-152 об изоляции
организаций остаётся открытым. ADR-055 обновлён прямым поручением владельца.
Последние изменения main 0e1d476 включены без отката обновлённого дизайна.
