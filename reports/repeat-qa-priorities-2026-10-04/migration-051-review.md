# Проверка сопутствующей миграции 051

Миграция пришла из другого изменения main, commit 70720016. Она не относится к исправлениям повторного QA.

SQL: `ALTER TYPE "BusinessVertical" ADD VALUE IF NOT EXISTS 'FOOD_SERVICE'`.
Новые таблицы, строки организаций, финансы, размещения и сопоставления не создаются и не меняются.

Локальная проверка на отдельном PostgreSQL: применение добавило значение; соседний down.sql вернул исходный тип. Число Business до и после: 1. Откат отказывается удалять тип, если появились FOOD_SERVICE Business. Схемы тестов не используют рабочие данные.

Перед рабочим применением подготовлена свежая копия `/root/backups/wetop-before-051-20261004.dump`, права 600, размер 380699 байт. `pg_restore --list` успешно прочитал 74 таблицы данных. Секреты подключения переданы окружением, в журнал и Git не выводились.

Рабочее применение ожидает отдельного ответа владельца на вопрос о миграции 051. После разрешения: проверить контрольные суммы основных таблиц и Business, применить Prisma migration deploy с точной схемой кандидата, сверить суммы и статус миграций. Продвигать release только после зелёного release-checks для точного SHA.

Обычный откат приложения: прежний образ, дополнительные значения enum сохраняются. Откат схемы: окно без записи, отсутствие FOOD_SERVICE строк, reviewed down.sql, сверка прежних значений и числа Business. Полное восстановление копии не выполнять без отдельного решения, чтобы не потерять новые записи.
