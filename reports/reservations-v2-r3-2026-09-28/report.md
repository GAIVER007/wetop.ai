# «Брони v2», срез R3 — быстрый просмотр брони (28.09.2026)

Решение — дополнение к ADR-106, план — `plans/reservations-v2-r3-2026-09-28.md` (подтверждён владельцем
28.09: «давай делай как надо»). Данные на снимках вымышленные (подставной API UI-стенда, ADR-010).

## Что изменилось

- Строка списка открывает панель брони щелчком по любой ячейке; двойной щелчок — полная страница.
- Панель — одобренная карточка B3. В ней теперь «Открыть бронь» (полная страница, «Назад» ведёт в тот же
  список), телефон скрытыми цифрами с кнопками «Позвонить» / WhatsApp / Telegram и блок «Финансы»:
  итого, оплачено, возвращено.
- На полосе фактов «Оплата» теми же словами, что колонка «Финансы» списка: у отменённой брони с деньгами
  к возврату — «к возврату N ₸», а не «оплачено». У группы с частичным размещением — «⚠ K без размещения».
- Вкладки «Счета / Действия / История» в панели остаются до R4 (решение владельца 28.09).
- API, схема, команды и формы действий не менялись.
