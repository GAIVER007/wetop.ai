# Лендинг «Для салонов красоты» (/for/salons/), 10.10.2026

Поручение владельца: подстраница для салонов красоты по макету и ТЗ «Лендинг для салонов красоты»
(версия 1.0, 09.10.2026), переход с карточки направления на главной. План: `plans/salon-landing-2026-10-10.md`.

## Что собрано (сверху вниз, по структуре ТЗ)

1. **Герой**: бейдж «Для салонов красоты», H1 «Управляйте салоном красоты в одном сервисе», лид,
   «Попробовать бесплатно» (регистрация с предвыбранным направлением «Салон красоты») и
   «Посмотреть возможности» (якорь), чипы «7 дней бесплатно / Без карты / Работает в браузере»;
   справа мокап «Записи на сегодня» с подписью «Пример интерфейса. Данные вымышленные.»
2. **Полоса фактов**: «7 дней», «3 роли», «1 окно», «0 установок» — только факты продукта.
3. **Возможности** (8 карточек): календарь записей, база клиентов, мастера, услуги и цены,
   график мастеров, команда и доступ, аналитика, филиалы.
4. **Рост**: «Больше довольных клиентов. Больше прибыли.», четыре пункта с галочками,
   кнопка «Начать бесплатно», рисунок салона на SVG.
5. **Частые вопросы**: 5 нативных details.
6. **Призыв**: регистрация + «На главную». Шапка и подвал общие.

Карточка «Салоны красоты» на главной и чип героя уже вели на `/for/salons/` — сам адрес не менялся,
страница пересобрана из общего шаблона `for/[segment]` в выделенную (`app/for/salons/page.tsx`).
