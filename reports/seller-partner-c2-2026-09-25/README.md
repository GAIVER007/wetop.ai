**1371/1371**. Что доказано: ключ в базе только шифрованным (Fernet, `LLM_KEYS_SECRET`), наружу —

проверка живым вызовом роутера (`Authorization: Bearer <ключ>`) отвечает вердиктом без ключа;
ход гостиницы с ключом идёт её ключом (`ScriptedLlm.last_api_key`), без него — ключом платформы;
каскад шлёт роутеру `Bearer partner-…` с ключом хода и `Bearer platform-…` без (MockTransport).
