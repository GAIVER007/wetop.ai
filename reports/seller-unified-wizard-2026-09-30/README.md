# Единый мастер — промежуточная проверка 30.09.2026

Диктовка через Web Speech API: https://developer.mozilla.org/en-US/docs/Web/API/SpeechRecognition — пользователь запускает её кнопкой; при неподдерживаемом браузере доступен текст. Живой микрофон пользователя не включался в автотестах.

Ограничения: новый мастер не обозначает тестовый чат/WhatsApp/запуск готовыми. Для них требуется завершить подключение отдельного агента к runtime и утверждённую операцию бронирования. Реальная бронь через WhatsApp этим срезом не создана. Production SQL 039 применён с отдельного разрешения владельца; 55 таблиц в проверенной резервной копии, digest прежних профилей не изменился.
