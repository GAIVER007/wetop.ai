# ИИ-продавец — промежуточный срез 26.09.2026

## Реализовано

Кабинет: боковые шаги, компактный статус с раскрываемыми подробностями, живое превью
имени и приветствия; существующие формы и API сохранены. Превью не имитирует ответы модели.
Серверная основа: токен сессии только как SHA-256, восстановление черновика, частичный
PATCH с revision, атомарная запись шага и события, отказ чужому/истёкшему токену.
Добавлена утверждённая схема агента/черновиков/заданий/сообщений/событий/опроса.
Новые API закрыты по умолчанию WIZARD_ENABLED. TTL нужен явно. Не включать публично.
