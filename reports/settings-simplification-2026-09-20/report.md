# Упрощение настроек WETOP, 20.09.2026

## Что изменено

В меню настроек три входа: «Гостиница», «Интеграции», «Сайт».
Сведения объекта и часы заезда/выезда собраны на общей странице. Услуги
и правила отмены доступны через внутренние вкладки. В каталоге услуг
работает поиск, у политик тарифов — поиск и фильтр статуса.

Фото, удобства и описание для каналов больше не дублируются в PMS.
Данные и API контента не удалены: старые ссылки фото/удобств направлены
к блоку Channex, описание — к сведениям объекта, расчётные часы — к
соответствующему блоку общих настроек.

На странице сайта сохранены действующие формы доменов, счётчика и
бронирования. Код установки и виджета раскрывается по запросу.
Предупреждение о настоящих бронях из демо остаётся рядом с демо-ссылкой.

## Границы данных

API и схема БД не менялись. Сведения гостиницы, часы, справочник услуг и
политики тарифов имеют в существующем API только чтение: интерфейс это
явно обозначает. Новые кнопки записи для этих данных не добавлялись.
Формы сайта используют прежние server actions. Нет миграций, внешних
записей Channex/OTA и изменений расчётов денег.

Живой локальный preview прочитал объект, часы и каталог услуг из
существующего API. Автотесты записывают только синтетические данные
в изолированный API; они не являются доказательством записи в Supabase.

## Ревью

Проверены корректность переходов и активного пункта меню, состояния
загрузки/ошибок/пустых справочников, граница server/client и отсутствие
новых зависимостей. Фильтры работают в загруженном каталоге. Чтение
зеркала Channex удалено с этих экранов, существующие API-действия сайта
и ограничения демо сохранены. CSS ограничен классами настроек и использует
текущие токены темы.
