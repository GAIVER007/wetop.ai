# Главная wetop.ai в стеклянном направлении — 23.09.2026

Поручение владельца: разобрать два снимка чужой посадочной страницы (светлая и тёмная темы одного
направления), выписать оттуда цвета, элементы и поведение и применить всё это к WETOP; лицо человека
с первого экрана не использовать.

Решение записано как **ADR-070**. Здесь — что именно перенесено, что заменено и чем доказано.

## Где сделано

Только `apps/site` — главная wetop.ai. Стойка (`apps/web`) не тронута: `DESIGN.md` §1 выводит сайт
из-под правил стойки, а сторож ИИ-слопа (`tests/unit/design-slop.test.ts`) читает только `apps/web/src`.

## Что взято со снимков

| Элемент снимка | Как сделано у нас |
|---|---|
| Матовое стекло панелей, светлая кромка, размытие фона | Один примитив `.glass` и токены `--glass-*`; без `backdrop-filter` панель становится непрозрачной |
| Подсвеченный фон: четыре пятна света и звёздная пыль | `body::before` и `body::after`, закреплены (`fixed`) — стекло всё время лежит на разном фоне |
| Металлическая надпись первого экрана (NOVA GLASS) | Слово-знак `WETOP`, `background-clip: text` по градиенту `--chrome-*`; без поддержки — обычный цвет текста |
| Портрет девушки справа на первом экране | **Не переносится.** Справа стоит макет шахматки — экран продукта |
| Круглый знак с надписью по кругу | `HeroSeal`: `textPath` с `textLength` по длине окружности, вращение под `prefers-reduced-motion` |
| Плашка «AVAILABLE FOR FREELANCE» | «Принимаем заявки» с зелёной точкой |
| Полоса из четырёх чисел и цитата справа | Полоса чисел WETOP (ниже) и правило проекта вместо отзыва |
| Три карточки «case studies» с номерами 01–03 | Витрина ключевых экранов: номер, мини-экран на SVG, метки |
| Колонка «Skills» с процентами | Колонка «Что входит в систему»: строка модуля и состояние «в системе» |
| Колонка «Tech stack» — сетка 3×3 логотипов | Сетка 3×3 каналов и подключений с буквенными плитками |
| Колонка «Design philosophy» — фигура и четыре подписи по кругу | «Принципы системы»: та же фигура, подписи — принципы WETOP, список повторён для скринридера |
| Плита призыва: заголовок капсом, контакты, QR, стеклянная фигура | Плита призыва: заголовок, контакты из `site.config.ts`, панель входа в стойку со **ссылкой словами** вместо QR |
| Нижняя строка: ©, звезда, девиз | © и год, звезда, девиз «Одно окно для всей смены» |
| Тёмная и светлая темы | Тема из настройки системы (`prefers-color-scheme`), переключателя нет — как было |

## Чего со снимков нет и не будет

Правило текстов сайта: только то, что есть в продукте на самом деле. Поэтому не перенесены:

- «5+ лет опыта», «40+ проектов», «25+ клиентов», «18 наград» — вместо них числа, названные на этой же
  странице: **6** каналов продаж, **9** способов оплаты, **3** среза шахматки, **0** расхождений при сверке;
- отзыв с именем — вместо него правило проекта о нулевом расхождении, подписанное проектом;
- проценты владения навыком — доли готовности модулей никто не считал;
- логотипы чужих сервисов — буквенные плитки;
- QR-код — ссылку на стойку видно словами и её можно проверить.

## Цвета направления

Смысловые токены текста и акцента остались прежними (`--text`, `--text-2`, `--muted`, `--primary`):
их контраст уже проверен, и сайт со стойкой остаются одним целым. Новые — только оформление.

| Токен | Светлая | Тёмная |
|---|---|---|
| `--bg` | `#e6eef8` | `#05070e` |
| `--bg-deep` | `#d6e5f4` | `#020308` |
| `--glass-bg` | `rgba(255,255,255,0.58)` | `rgba(18,29,48,0.58)` |
| `--glass-border` | `rgba(255,255,255,0.85)` | `rgba(255,255,255,0.1)` |
| `--accent-1` / `--accent-2` | `#2f7ae5` / `#5cc4f2` | `#2f6bff` / `#38bdf8` |
| `--glow-1` / `--glow-2` | голубые пятна света | синие пятна ночного неба |
| `--chrome-2` / `--chrome-3` | `#93a9c2` / `#42566e` | `#cfe0f5` / `#6f88a8` |
| `--star` | `rgba(80,125,180,0.22)` | `rgba(190,220,255,0.5)` |

При `prefers-contrast: more` стекло заменяется непрозрачной подложкой.

## Раздел «О компании» снят (23.09.2026)

По решению владельца название юридического лица на сайте не показывается: в `site.config.ts` пустые
`company.name` и `company.about`. Пустое имя прячет раздел «О компании» целиком — так и задумано в
`lib/site.ts`, — а в подвале остаётся «© 2026 WETOP». Город и почта остались: по ним пишут в разделе
«Как начать», и они стоят в контактах плиты призыва. Вернуть раздел можно одной строкой — вписать имя
обратно в `site.config.ts`.

## Правила вшиты в DESIGN.md (23.09.2026, поручение «прорисуй каждый блок»)

Направление перестало быть «как на снимке» и стало правилом: в `DESIGN.md` появился **§19 «Главная
wetop.ai — стеклянное направление»**, и заголовок файла больше не выводит `apps/site` из-под правил,
а отсылает к §19.

| Подраздел | О чём |
|---|---|
| §19.1 | Где лежат значения: какой файл за что отвечает и кто его правит |
| §19.2 | Цвет: два слоя токенов таблицами, запрет литерала, два разрешённых исключения |
| §19.3 | Лестница отступов `0/2/…/16/20/…/64` и вертикальный ритм разделов |
| §19.4 | Стекло одним примитивом `.glass`, таблица радиусов, четыре тени |
| §19.5 | **Реестр блоков:** все 54 корневых класса страницы — что это, из чего собран, правила |
| §19.6 | Шрифт: роли и размеры, запрет текста мельче 12 px, где допустим капс |
| §19.7 | Движение, наведение, фокус, доступность |
| §19.8 | Чек-лист «как добавить блок»: первым пунктом строка в §19.5 |
| §19.9 | Чего на сайте не бывает: таблица «нельзя — почему — что вместо» |

Правила держит сторож `tests/unit/site-design.test.ts` (6 проверок): цвет мимо токенов, отступ вне
лестницы, радиус числом, текст мельче 12 px, расхождение `themeColor` с `--bg` и — главное — **блок,
которого нет в реестре §19.5** (и обратно: строка реестра, которой нет в коде). Новый блок молча
добавить нельзя.

Красный → зелёный: на первой редакции сторож валился на реестре (§19.5 ещё не было) и на четырёх
цветовых литералах; после §19 и правок — 6 из 6. Заодно найдено и починено то, что чтением и видно:
`viewport.themeColor` остался от прежней палитры (`#f4f7fb` / `#060b14`) и расходился с новым фоном;
правило `.brand__mark rect` тянуло знак подвала на градиент знака шапки; два размера текста были 11 px.
