## Что за владельцем

3. Выкладка: образ бота (новый маршрут и поля) **до** стойки и API — иначе API получит от старого бота строки без
   `last_message` и «Закрыть» ответит 404. Порядок — `docs/deploy.md` и `apps/ai-seller/vykatka.md`; миграций нет.
   Из облачной сессии сервер недоступен (сеть окружения не пускает к wetop.ai).

   ИИ», «Закрыть обращение» → диалог в «Закрытых», в виджете следующее сообщение открывает новый разговор.
