# UI4.2: шахматка по эталону владельца 13.10.2026 (DESIGN.md §21)

Эталон: `design/references/01_hospitality/chessboard_owner_2026-10-13.webp` (1586×992).
Решения владельца 13.10.2026: Q-DES-1 (один контрол периода), Q-DES-2 (оболочка UI3.1, меню под ☰),
Q-DES-3 (Inter, PR #480), Q-DES-4 (360 px технический, проверка до 320).

## 1. Эталон: что повторяем и что нет

| Элемент эталона | Решение | Почему |
|---|---|---|
| Заголовок со значком и подписью, справа период, «Сегодня», «Новая бронь» | повторён | композиция |
| «Дни / Неделя / Месяц» рядом с периодом | **не повторён** | Q-DES-1: один контрол с пресетами |
| Шесть плиток «Занято, Свободно, Заезд, Выезд, Проживание, Требует внимания» | повторены на `Stat` | все числа есть в API (`/desk/today`, доска) |
| «+12 % к прошлому периоду» у «Занято» и «Свободно» | у «Занято» разница к вчерашнему дню в п.п.; у «Свободно» нет | сравнение за «прошлый период» API не отдаёт, выдумывать нельзя |
| Подписи «Гостей», «Бронирования» под числом | «брони» | счётчики считают брони, а не гостей |
| Полоса фильтров: «Все корпуса», «Все категории», «Все статусы», поиск, «Фильтры», «Сбросить», шестерёнка | категория и статус выбором, поиск, «Фильтры»; «Сбросить» при активном отборе | корпусов у объекта один; шестерёнка без действия была бы пустой кнопкой |
| Группы «Корпус А / Корпус Б» | группы по категории (как было) | у строки категории свободные места на каждую ночь, это рабочее число стойки; корпус один |
| Колонка «Статус» словом у номера | повторена («Свободно», «Занято», «Заезд сегодня», «Бронь», блок) | вычисляется из ячейки сетки на день |
| Шапка дня «Пн / 13 окт.», сегодня подсвечен, выходные красным | повторена | |
| Строка 29 px, плашка с текстом 10–11 px | **не повторена**: строка 40, плашка 34, текст 13 px | DESIGN.md §6: ничего мельче 13 px; плотный вид «Компактный» остаётся в «Фильтрах» |
| Цвет плашки по дню (заезд оранжевый, выезд красный, бронь фиолетовая) | **не повторён**: палитра по статусу брони (ADR-154) + акцентная черта статуса | смысл цвета плашки меняется только решением владельца, вопрос Q-DES-5 |
| «Легенда:» внизу карточкой | повторена | |
| «Данные обновляются в реальном времени» | не повторено | стойка не обновляется сама, обещание было бы ложным |
| Заголовок «Шахматка» | оставлен «Календарь» | раздел назван владельцем 02.10.2026; макетные надписи не переносятся (`README_FIRST.md`) |

## 2. Разметка: элемент → компонент → токены

| Элемент | Компонент | Токены |
|---|---|---|
| Заголовок | `Page` (title, subtitle, actions) | `--text-4xl`, `--weight-bold`, значок `board` `--space-8`, `--primary` |
| Период | `DateRangePopover` (UI4.2-A, перенесён из #438) | `--control-h`, `--border-input`, `--radius-control` |
| Стрелки, «Сегодня», «Новая бронь» | `icon-button`, `.btn` | `--control-h`, на телефоне `--touch-target` |
| Плитки | `Stat` со значком, вариант-ссылка | `--radius`, `--border-soft`, `--text-2xl`, тоны `--primary`/`--success`/`--danger` |
| Полоса фильтров | `.board-toolbar`, `Select`, `Input` | `--radius`, `--surface` |
| Шапка дня | `th[data-testid=date-col]` | `--text-sm`/`--text-xs`, `--primary`, `--danger` |
| Статус места | `.board-unit-state` | `--success`, `--primary`, `--warning`, `--text-2`, `--muted` |
| Акцент плашки | `td[data-status] .board__stay[data-plate-start]` | `--plate-*-ink` (ADR-154) |

Новых компонентов нет. Изменён один общий примитив: у `Stat` со значком черта тона снята
(оба эталона 13.10, шахматка и финансы), затронуты экраны с `Stat icon=`: финансы, гости, рынок,
платформа, каналы, склад ресторана, `/design-system`.

## 5. Функциональная проверка

- Регрессия UI: шахматка целиком (все `chessboard-*`), оболочка `ui31-*`, период `date-range-popover`,
  телефон `mobile-adaptation`, шрифт `app-font`, экраны с `Stat icon=` (финансы, гости, рынок, платформа,
  каналы, бар), `design-system`: **329 из 335** в общем прогоне (`…14-28-23Z-e2e-f3b7`), пять красных разобраны
  и исправлены (подписи плиток на телефоне, подсказка в имени ссылки на низком экране), повторно 56/56
  (`…14-49-51Z-e2e-4025`), планшет и телефон 29/29 (`…14-57-32Z-e2e-39dd`).
- Сторожа дизайна 62/62 (`…14-52-21Z-unit-ca1f`), typecheck и lint чисто.
- Полный unit 4703/4717 (`…14-54-02Z-unit-893e`): 10 красных только в песочницах ops-скриптов
  (`auto-deploy`, `db-backup-offsite`, `db-restore-prod`, `guard-run`, таймауты 5 с под нагрузкой),
  ветка их не трогает; отдельно 41/43 и `guard-run` один 8/8 (`…14-57-00Z-unit-dcc5`).
- Спеки, переведённые на новый контрол периода: `chessboard-month`, `-grid`, `-design` (правки из #453),
  `-card` (тест живого двойного щелчка из #449 сохранён), `-gate`, `-gate-pr3`, `-week`; на шесть плиток
  эталона: `-calendar`, `-statistics`, `-mobile`, `search-filter-recovery`; раскладка
  `booking-price-nights` переписана под композицию эталона с теми же целями (одна строка управления,
  плитки в ряд, сетка высоко).
- Бизнес-логика, API, права, модель и миграции не менялись.

## 6. Открыто

- **Q-DES-5, цвет плашек.** Эталон 13.10 красит плашку по дню (заезд, выезд, бронь, проживает), действующая
  палитра ADR-154 красит по статусу брони. Смысл цвета меняет только владелец.
- Ряд плиток на 1280–1440 пока без стрелок у ссылок (узкий контейнер), сама плитка остаётся ссылкой.
- Эталоны `-linux` дизайн-системы снимает раннер после слияния #480.
