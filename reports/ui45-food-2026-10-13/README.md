# UI4.4 и UI4.5: календарь салона и зал ресторана по эталону владельца (DESIGN.md §21)

Эталон: `design/references/05_verticals/three_calendar_concepts.png` (три календаря: гостиница,
салон, ресторан). Общая оболочка UI3.1, у каждой вертикали своя ось (ADR-104): гостиница номера и даты,
салон мастера и время, ресторан зал и столы. Данные стенда вымышленные (ADR-010), заводятся съёмщиками
`tests/beauty-ui/ref-capture.spec.ts` и `tests/food-ui/ref-capture.spec.ts` (`REF_PHASE=before|after`),
снимки в `reports/ui44-beauty-2026-10-13/` и в этой папке.

## Салон (`/calendar`)

| Элемент эталона | Было | Стало |
|---|---|---|
| Подпись «Расписание мастеров и услуг салона» | название филиала | подпись и филиал |
| Строка отборов «Все мастера / Все услуги / Все статусы» | нет | выборы, фильтруют сетку без запросов к API |
| День: «Сегодня», стрелки, дата | поле с подписью «Дата» над ним | одной строкой рядом с отборами |
| Колонка «Мастера» с аватарами и часами | нет | есть (от 1280 px); выбор сужает сетку до мастера |
| Записи мягкой заливкой с чертой статуса | белые с рамкой | тон статуса из реестра `beautyStatus` |
| Легенда статусов внизу | нет | есть |
| Неделя по дням (колонки «Пн…Вс») | день по мастерам | **не перенесено**: сетка салона это мастера и время одного дня (ADR-104); неделя потребует сводить 7 дней и делить пересекающиеся записи разных мастеров, это отдельный срез |

## Ресторан (`/floor-plan`)

| Элемент эталона | Было | Стало |
|---|---|---|
| Подпись «Бронирования столов и загрузка зала» | нет | есть |
| Смены «Завтрак 08:00–11:00 / Обед / Ужин» карточками | список «Все периоды» | карточки смен выбранного дня; на «Расписании» прежний список |
| Зоны со значком и «N столов» | имя и число справа | значок, имя, «N столов» |
| Схема зала с объёмными столами и растениями | сетка столов | **не перенесено**: рисованный план зала требует координат и формы стола (Q-REST-8), сетка по порядку остаётся |
