# Единый вход — локальная проверка 01.10.2026

Статус: реализация в `codex/unified-auth-entry`; не опубликована.
План: `plans/unified-auth-entry-2026-10-01.md`, решение ADR-131.

## Изменения

- Главная продукта открывает вход и регистрацию, старые `/login` и `/register`
  перенаправляют на неё. Письма и приглашения сохраняют технические callback-пути.
- После пароля браузер проверяет реальную сессию перед переходом. Отсутствующая
  cookie и недоступный API показывают ошибку, а не запускают цикл переходов.
- Адрес возврата ограничен внутренними страницами приложения.
- Команда, приглашения и сессии перенесены в защищённый `/profile/access` с прежними правами.
- Резервный вход возвращает полный HTML, проверяет Origin и размер POST.
- Исправлена потеря почты при раннем открытии окна регистрации и переполнение
  главной на ширине 320 px. Модель данных и production-данные не менялись.

## Выпуск

До публикации нужны успешные обязательные проверки. В общем main обнаружены
отдельные ошибки дизайн-токенов, CSS, реестра прав API и тестовых дат.
Их исправление отдельным срезом запрошено у владельца; проверки не отключались.
Незавершённая ветка филиалов не включена в этот срез.

Локальный пользовательский preview: главная `http://127.0.0.1:3002/`, приложение
`http://127.0.0.1:3000` из проверенной сборки. В отличие от тестов, пользовательский
preview подключён к существующему рабочему API-туннелю 4315. Автоматических входов,
регистраций или изменений рабочих данных через него не выполнялось.
