## Что выяснилось по дороге

- **Local Network Access в Chromium.** Страница, отданная через `page.route` (без настоящего сервера), для
  браузера «внешняя», и он запрещает ей грузить скрипт с `127.0.0.1` («Permission was denied … loopback
  address space»). Первые три прогона e2e падали на этом. Решение — настоящий HTTP-сервер теста на
  `127.0.0.1:3999` и имя `test-site.localhost` (браузер ведёт `*.localhost` на loopback). В бою API на
  публичном адресе, проверки нет.
- **Ошибка body-parser не доходит до фильтров контроллера.** Тело > 4 КБ давало 413 и стек в логе на каждый
  вызов; теперь парсер обёрнут и отвечает 204 молча.
- **`crypto.randomUUID` есть только в защищённом контексте** — на http-сайте счётчик берёт запасной генератор.
- Старый процесс API (запущен за час до среза, без модуля) пришлось перезапустить: Playwright переиспользует
  живой сервер и прогнал бы тест против кода без `/a/*`.
