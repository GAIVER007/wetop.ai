# Шаблоны выгрузок Exely

Здесь лежат только **заголовки колонок** — эталон формата.
Заполненные файлы кладутся в `project-input/exely/` и **не коммитятся** (PII).

`sell_mode` в `accommodation_types.csv`: `ROOM` | `BED` | `WHOLE_DORM`.

Если реальная выгрузка Exely не совпадает с этими колонками — **не подгонять данные
под шаблон**. Записать расхождение в `QUESTIONS.md` и обсудить.
